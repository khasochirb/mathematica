## Lesson 1 — Квадрат функцийн график (`graphs-of-quadratic-functions`)

**concreteComparison**

Бөмбөг шидээд өндрийг нь ажиглавал парабол зурна: дээшээ, хамгийн өндөр ганц
агшин, дараа нь доошоо, бүхэлдээ төгс тэгш хэмтэй. Квадрат функц бүр яг энэ нумыг (эсвэл
түүний харвасан хөндий ихрийг) зурдаг бөгөөд бүтэц нь ердөө гурван тэмдэгтэй.

**objective**

Параболын орой, тэгш хэмийн тэнхлэг, чиглэл, тэнхлэгтэй огтлолцох цэгүүдийг
тодорхойлж, оройг $x = -b/(2a)$ томьёогоор олох.

**concept**

1. $f(x) = ax^2 + bx + c$ нь **парабол** зурна: $a > 0$ бол ДЭЭШЭЭ (хөндий,
   хамгийн бага утгатай), $a < 0$ бол ДООШОО (нум, хамгийн их утгатай).
   $|a|$ том байх тусам муруй нарийсна.

2. **Орой** нь эргэх цэг бөгөөд $x = -\dfrac{b}{2a}$ **тэгш хэмийн тэнхлэг**
   дээр байрлана. Эхлээд $x$-ийг бодоод, дараа нь тэнд $f$-ийг бодож $y$-г
   гаргана. $f(x) = x^2 - 6x + 5$ дээр: $x = 3$, $f(3) = -4$, тиймээс орой $(3, -4)$.

3. Огтлолцох цэгүүд зургийг бэхэлнэ: $f(0) = c$ нь $y$-тэнхлэгтэй огтлолцоно;
   $x$-тэнхлэгтэй огтлолцох цэгүүд (байвал) нь $f(x) = 0$-ийн шийдүүд бөгөөд
   тэнхлэгийн эргэн тойронд тэгш хэмтэй суудаг. Тэгш хэм бол параболын гол
   давуу тал: мэдэгдэж буй цэг бүр тэнхлэгээр тусаж үнэгүй хос өгнө.

**keyIdea**

Параболыг гурван тэмдэг бэхэлнэ: чиглэл ($a$-ийн тэмдэг), $x = -b/(2a)$ дээрх
орой, огтлолцох цэгүүд; үлдсэнийг нь толин тэгш хэм дүүргэнэ.

**facts**

| title | latex | explanation |
|---|---|---|
| Оройн томьёо | `x_v = -\frac{b}{2a}, \quad y_v = f(x_v)` | Эхлээд тэгш хэмийн тэнхлэг, дараа нь өндрийг нь бодно. |
| Чиглэл ба өргөн | `a > 0: \cup \quad a < 0: \cap` | $a$-ийн тэмдэг хөндий эсвэл нумыг сонгоно; $\|a\|$ том бол нарийсна. |

**workedExamples**

- `al81-we1` — **statement:** $f(x) = x^2 - 4x - 5$-ийн орой, тэнхлэг,
  огтлолцох цэгүүд, чиглэлийг олоорой.
  **solution:** Дээшээ ($a = 1 > 0$). Тэнхлэг: $x = \frac{4}{2} = 2$; орой
  $(2, f(2)) = (2, -9)$. $y$-тэнхлэгтэй $(0, -5)$ дээр огтлолцоно. Тэгүүд:
  $(x-5)(x+1) = 0$ → $x = 5, -1$, өөрөөр хэлбэл 2-ын орчимд тэгш хэмтэй. ✓
- `al81-we2` — **statement:** Бөмбөгийн өндөр $t$ секундын дараа
  $h(t) = -5t^2 + 20t + 1$ метр байв. Хэзээ хамгийн өндөрт хүрэх вэ, ямар
  өндөрт хүрэх вэ?
  **solution:** Орой: $t = -\frac{20}{2(-5)} = 2$ секунд; $h(2) = -20 + 40 + 1 = 21$
  метр. Нум доошоо нээгдэж байгаа тул ($a = -5$) энэ нь хамгийн их утга.

**commonMistakes**

- **text:** Оройн томьёоны хасахыг гээх: $x_v = \frac{b}{2a}$.
  **correction:** Зөв нь $x_v = -\frac{b}{2a}$. $x^2 - 6x + 5$ дээр ($b = -6$):
  $x_v = -\frac{-6}{2} = +3$, өөрөөр хэлбэл хоёр хасах уулзаж байна.
- **text:** Оройг зөвхөн $x$-утгаар нь мэдээлэх.
  **correction:** Орой бол ЦЭГ: $f(x_v)$-г мөн бодоод $(x_v, y_v)$ гэж
  бичээрэй.

**tryIt**

- `al81-t1` — $f(x) = 2x^2 + 8x + 3$-ийн орой болон чиглэлийг олоорой.
  **solution:** Дээшээ ($a = 2$). $x_v = -\frac{8}{4} = -2$;
  $f(-2) = 8 - 16 + 3 = -5$. Орой $(-2, -5)$, өөрөөр хэлбэл хамгийн бага утга.
- `al81-t2` — Парабол $x = 1$ ба $x = 9$ дээр тэгтэй бөгөөд $(0, 18)$-аар
  дайрна. $f(x) = 2(x-1)(x-9)$ бол тэгш хэмийн тэнхлэг болон оройн $y$-утгыг
  олоорой.
  **solution:** Тэнхлэг нь тэгүүдийн дунд: $x = 5$. $f(5) = 2(4)(-4) = -32$, тиймээс
  орой $(5, -32)$. Гурав дахь цэгийг шалгавал: $f(0) = 2(-1)(-9) = 18$. ✓

## Lesson 2 — Задлах ба квадрат язгуураар бодох (`solving-by-factoring-and-square-roots`)

**concreteComparison**

Хоёр тоо үржээд тэг гарвал нэг нь заавал тэг БАЙНА, өөр арга байхгүй. Энэ ганц
баримт (тэг үржвэрийн чанар) задардаг квадрат тэгшитгэл бүрийг хоёр бяцхан
тэгшитгэл болгон хувиргана.

**objective**

Бүгдийг нэг тал руу зөөсний дараа тэг үржвэрийн чанараар, мөн квадрат
язгуураар квадрат тэгшитгэл бодох, $\pm$ хоёр хариуг хоёуланг нь хадгалах.

**concept**

1. **Тэг үржвэрийн чанар**: $A \cdot B = 0$ бол $A = 0$ эсвэл $B = 0$. Тэгэхээр
   $x^2 - 4x - 5 = 0$-ийг бодохдоо задлаад $(x-5)(x+1) = 0$, салгавал $x = 5$
   эсвэл $x = -1$. Энэ нь ЗӨВХӨН тэгийн эсрэг ажиллана, тиймээс эхлээд бүгдийг нэг тал
   руу гаргаарай.

2. $x^2 + 6x = 16$ нь задрахаасаа өмнө $x^2 + 6x - 16 = 0$ болох ёстой;
   «$= 16$»-аас салгах нь утгагүй, учир нь 16 өгөх олон хос бий.

3. **Квадрат язгуурын арга** нь дунд гишүүнгүй хэлбэрт: $x^2 = 49$ нь ХОЁР
   хариутай, $x = \pm 7$. Ороосон квадратад ч мөн адил: $(x - 3)^2 = 25$ нь
   $x - 3 = \pm 5$ өгөх тул $x = 8$ эсвэл $x = -2$. Хасах салааг мартах нь
   хариуны талыг алдах явдал.

**keyIdea**

Тэгийн эсрэг задарсан квадрат тэгшитгэл тэг үржвэрийн чанараар сална; цэвэр
квадрат нь $\pm\sqrt{\;}$-ээр тайлагдана, бараг үргэлж хоёр хариу гарна.

**facts**

| title | latex | explanation |
|---|---|---|
| Тэг үржвэрийн чанар | `AB = 0 \;\Rightarrow\; A = 0 \text{ or } B = 0` | ЗӨВХӨН тэгийн эсрэг ажиллана; 16-ийн эсрэг хэзээ ч үгүй. |
| $\pm$ тайлалт | `(x - 3)^2 = 25 \;\Rightarrow\; x - 3 = \pm 5` | Эерэг тоо бүр хоёр квадрат язгууртай; хоёуланг нь хадгалаарай. |

**workedExamples**

- `al82-we1` — **statement:** Бодоорой: $x^2 + 6x = 16$.
  **solution:** Зөөвөл: $x^2 + 6x - 16 = 0$. Оньсого (үржвэр $-16$, нийлбэр 6):
  8, $-2$ → $(x + 8)(x - 2) = 0$ → $x = -8$ эсвэл $x = 2$. Хоёулаа шалгагдана:
  $64 - 48 = 16$ ✓, $4 + 12 = 16$ ✓.
- `al82-we2` — **statement:** Бодоорой: $3(x - 4)^2 = 48$.
  **solution:** 3-т хуваавал: $(x - 4)^2 = 16$. Тайлбал: $x - 4 = \pm 4$,
  тэгэхээр $x = 8$ эсвэл $x = 0$. Шалгавал: $3(16) = 48$ ✓ хоёуланд нь.

**commonMistakes**

- **text:** Тэгээс өөр тооны эсрэг салгах: $(x-5)(x+1) = 7$-оос $x - 5 = 7$
  эсвэл $x + 1 = 7$ гэж дүгнэх.
  **correction:** 7 өгөх олон хос бий, тиймээс чанар нь зөвхөн тэгийнх. Хаалтыг
  нээгээд, 7-г нөгөө тал руу зөөгөөд дахин задлаарай.
- **text:** $x^2 = 49 \Rightarrow x = 7$, цэг.
  **correction:** $(-7)^2 = 49$ ч мөн. Квадрат язгуураар бодох нь $\pm$ өгнө:
  баруун тал тэг биш л бол хоёр хариу.

**tryIt**

- `al82-t1` — Бодоорой: $x^2 = 5x + 24$.
  **solution:** $x^2 - 5x - 24 = 0 \to (x - 8)(x + 3) = 0 \to x = 8$ эсвэл
  $x = -3$.
- `al82-t2` — Бодоорой: $(2x + 1)^2 = 81$.
  **solution:** $2x + 1 = \pm 9$: $2x = 8 \to x = 4$, эсвэл
  $2x = -10 \to x = -5$.

## Lesson 3 — Бүтэн квадрат болгох ба квадрат тэгшитгэлийн томьёо (`completing-the-square-and-the-quadratic-formula`)

**concreteComparison**

Зарим квадрат тэгшитгэл цэвэрхэн задрахаас татгалздаг, учир нь шийд нь иррационал.
Бүтэн квадрат болгох арга нь квадрат тэгшитгэл бүрийг тайлж болох боодол болгон
дахин бүтээдэг, харин тэр дахин бүтээлтийг үсгээр нэг удаа хийвэл квадрат
тэгшитгэлийн томьёо гарч ирнэ: цоож болгонд тохирох мастер түлхүүр.

**objective**

Бүтэн квадрат болгож квадрат тэгшитгэл бодох, оройн хэлбэрийг гаргах, квадрат
тэгшитгэлийн томьёог чөлөөтэй хэрэглэх.

**concept**

1. **Бүтэн квадрат болгох**: $x^2 + bx$ дээр $\left(\frac{b}{2}\right)^2$
   нэмбэл бүтэн квадрат болно. $x^2 + 6x - 7 = 0$-ийг бодохын тулд 7-г зөөж,
   хоёр талд $9$ нэмбэл $(x + 3)^2 = 16$, тайлбал $x = 1$ эсвэл $x = -7$. Ижил
   дахин бүтээлт квадрат тэгшитгэл бүрийг оройн хэлбэрт оруулна.

2. Тэр дахин бүтээлтийг $ax^2 + bx + c = 0$ дээр цэвэр үсгээр гүйцэтгэвэл
   **квадрат тэгшитгэлийн томьёо** унаж гарна:
   $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}.$$
   Энэ нь квадрат тэгшитгэл БҮРИЙГ бодно, задардаг ч бай, үгүй ч бай.

3. Томьёоны сахилга бат: $a$, $b$, $c$-г тэмдэгтэй нь ХАМТ эхлээд бичээрэй;
   $b^2 - 4ac$-г тусад нь бодоорой; бутархайн зураас ГУРАВСАН хүртэлх бүх
   хүртвэрийг, $-b$ ороод, хамарна. $2x^2 - 3x - 5 = 0$ дээр:
   $x = \frac{3 \pm \sqrt{9 + 40}}{4} = \frac{3 \pm 7}{4}$ → $x = \frac{5}{2}$
   эсвэл $-1$.

**keyIdea**

$(b/2)^2$ нэмж бүтэн квадрат үйлдвэрлэ; үүнийг үсгээр нэг удаа хийвэл квадрат
тэгшитгэлийн томьёо гарна: $x = (-b \pm \sqrt{b^2-4ac})/(2a)$, энэ нь квадрат
тэгшитгэл бүрийг онгойлгоно.

**facts**

| title | latex | explanation |
|---|---|---|
| Бүтэн болгох хөдөлгөөн | `x^2 + bx + \left(\tfrac{b}{2}\right)^2 = \left(x + \tfrac{b}{2}\right)^2` | Дунд коэффициентийн хагасыг квадратдаад ХОЁР талд нэмнэ. |
| Квадрат тэгшитгэлийн томьёо | `x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}` | Тэмдэг нь $a, b, c$-тэй хамт явна; зураас бүх хүртвэрийг хамарна. |

**workedExamples**

- `al83-we1` — **statement:** Бүтэн квадрат болгож $x^2 + 6x - 7 = 0$-ийг
  бодоорой.
  **solution:** Зөөвөл: $x^2 + 6x = 7$. 6-ын хагас нь 3; хоёр талд
  $3^2 = 9$ нэмбэл $(x + 3)^2 = 16$. Тайлбал: $x + 3 = \pm 4$ → $x = 1$ эсвэл
  $x = -7$. Хоёулаа шалгагдана.
- `al83-we2` — **statement:** Квадрат тэгшитгэлийн томьёогоор
  $2x^2 - 3x - 5 = 0$-ийг бодоорой.
  **solution:** $a = 2, b = -3, c = -5$. Дискриминант: $b^2 - 4ac = 9 + 40 = 49$.
  $x = \dfrac{3 \pm 7}{4}$: $x = \dfrac{10}{4} = \dfrac{5}{2}$ эсвэл $x = -1$.
  $-1$-ийг шалгавал: $2 + 3 - 5 = 0$. ✓

**commonMistakes**

- **text:** $(b/2)^2$-ийг зөвхөн нэг талд нэмэх.
  **correction:** Энэ бол бусадтай адил тэнцвэрийн хөдөлгөөн:
  $x^2 + 6x = 7$ нь $x^2 + 6x + 9 = 7 + 9$ болно. Хоёр тал хоёулаа өснө.
- **text:** Томьёоны тэмдгийн эмх замбараагүй байдал: $2x^2 - 3x - 5$ дээр
  $b = 3$ гэж авах.
  **correction:** $b$ нь тэмдэгтэйгээ $-3$, тиймээс $-b = +3$ бөгөөд
  $b^2 = 9$. Томьёонд хүрэхээсээ ӨМНӨ гурван утгаа бичиж аваарай.

**tryIt**

- `al83-t1` — Бүтэн квадрат болгож $x^2 - 8x + 3 = 0$-ийг яг утгаар нь
  бодоорой.
  **solution:** $x^2 - 8x = -3$; 16 нэмбэл $(x - 4)^2 = 13$; $x = 4 \pm \sqrt{13}$.
- `al83-t2` — Томьёогоор $3x^2 + 5x - 2 = 0$-ийг бодоорой.
  **solution:** $b^2 - 4ac = 25 + 24 = 49$; $x = \dfrac{-5 \pm 7}{6}$:
  $x = \dfrac{1}{3}$ эсвэл $x = -2$.

## Lesson 4 — Дискриминант ба хэрэглээ (`the-discriminant-and-applications`)

**concreteComparison**

Томьёоны квадрат язгуур дор цаг агаарын мэдээ сууж байдаг: $b^2 - 4ac$. Эерэг бол
хоёр гатлалт; тэг бол парабол тэнхлэгийг нэг л удаа үнсэнэ; сөрөг бол хэзээ ч
хүрэхгүй. Шийдийг бодохгүйгээр урьдчилан хэлж болно.

**objective**

Дискриминантаар шийдийн тоог тодорхойлж, бодит бодлогуудыг (шидсэн биетийн
хөдөлгөөн, талбай) квадрат тэгшитгэлийн бүх багажаар бодох.

**concept**

1. **Дискриминант** $D = b^2 - 4ac$ нь язгуур дорх бүхнийг шийднэ: $D > 0$ →
   хоёр бодит шийд; $D = 0$ → яг нэг (давхардсан шийд, орой тэнхлэг ДЭЭР);
   $D < 0$ → бодит шийдгүй (парабол тэнхлэгээс зайдуу хөвнө).

2. **Шидсэн биет**: өндөр нь $h(t) = -5t^2 + v t + h_0$ (метр, секунд). «Хэзээ
   газардах вэ?» → $h(t) = 0$-г бодоод эерэг шийдийг авна. «Хамгийн өндөрт?» →
   орой. «Хэзээ 20 м дээр байх вэ?» → $h(t) = 20$, ихэвчлэн хоёр удаа: нэг нь
   өгсөх үед, нөгөө нь буух үед.

3. **Геометрийн байгуулалт**: өргөнөөсөө 3-аар урт, талбай нь 40 байх тэгш
   өнцөгт нь $w(w + 3) = 40$ → $w^2 + 3w - 40 = 0$ → $w = 5$ өгнө ($-8$ гэсэн
   шийдийг хаяна, учир нь нөхцөл дахин алгебрийг тайрч байна).

**keyIdea**

$D = b^2 - 4ac$ нь шийдийг олохоос өмнө тоолж өгнө; хэрэглээнд зөв тэгшитгэлээ
(тэг, зорилтот утга, эсвэл орой) сонгоод, түүхийн зөвшөөрөхгүй шийдийг хаяарай.

**facts**

| title | latex | explanation |
|---|---|---|
| Гурван таамаг | `D > 0: 2, \quad D = 0: 1, \quad D < 0: 0` | $D = b^2 - 4ac$, томьёоны язгуур дорх илэрхийлэл. |
| Шидсэн биетийн толь | `h = 0 \to` газардалт `; \quad h = 20 \to` 20 м дээр | Асуулт нь юу асууж байгаа тэр тэгшитгэлийг сонгоно; сөрөг хугацааг хаяна. |

**workedExamples**

- `al84-we1` — **statement:** Бодохгүйгээр $2x^2 + 5x + 4 = 0$, $x^2 - 6x + 9 = 0$,
  $x^2 - x - 6 = 0$-ийн бодит шийдийн тоог тоолоорой.
  **solution:** $D_1 = 25 - 32 = -7 < 0$: байхгүй. $D_2 = 36 - 36 = 0$: нэг
  (давхардсан шийд 3). $D_3 = 1 + 24 = 25 > 0$: хоёр ($3$ ба $-2$).
- `al84-we2` — **statement:** Бөмбөгийг дээш шидэв: $h(t) = -5t^2 + 15t + 20$.
  Хэзээ газардах вэ?
  **solution:** $-5t^2 + 15t + 20 = 0$-г бодоод $-5$-д хуваавал:
  $t^2 - 3t - 4 = 0 \to (t - 4)(t + 1) = 0 \to t = 4$ эсвэл $t = -1$. Хугацаа
  сөрөг байж чадахгүй: $t = 4$ секундэд газардана.

**commonMistakes**

- **text:** Хэрэглээний квадрат тэгшитгэлийн хоёр шийдийг хоёуланг нь, боломжгүй
  нэгийг нь оруулаад, мэдээлэх.
  **correction:** $-8$ өргөн, эсвэл $-1$ секундын газардалт түүхэнд нийцэхгүй.
  Бүрэн бодоод, дараа нь нөхцөлд хаялгаарай.
- **text:** $D < 0$-ийг «энэ тэгшитгэл огт шийдгүй» гэж нэрлэх.
  **correction:** БОДИТ шийдгүй: парабол тэнхлэгийг өнгөрч байна. (Хожмын
  математик тэднийг комплекс тооноос олно; Алгебр 1-д «бодит шийдгүй» гэдэг нь
  хариу.)

**tryIt**

- `al84-t1` — $x^2 + 8x + c = 0$ яг нэг шийдтэй байхын тулд $c$ ямар утгатай
  байх вэ?
  **solution:** $D = 64 - 4c = 0 \to c = 16$. (Тэгвэл
  $x^2 + 8x + 16 = (x+4)^2$, өөрөөр хэлбэл $x = -4$ дээрх үнсэлт.)
- `al84-t2` — Тэгш өнцөгт цэцэрлэгийн урт нь өргөнөөсөө 4 м-ээр илүү, талбай нь
  60 м². Хэмжээсийг нь олоорой.
  **solution:** $w(w + 4) = 60 \to w^2 + 4w - 60 = 0 \to (w + 10)(w - 6) = 0$.
  $-10$-ийг хаяна: өргөн 6 м, урт 10 м. Шалгавал: $6 \cdot 10 = 60$. ✓

## PRACTICE

- `al8-pr-1` — $f(x) = x^2 + 10x + 21$-ийн оройг олоорой.
  **solution:** $x_v = -5$; $f(-5) = 25 - 50 + 21 = -4$. Орой $(-5, -4)$.
- `al8-pr-2` — Бодоорой: $x^2 - 9x + 18 = 0$.
  **solution:** $(x - 3)(x - 6) = 0$: $x = 3$ эсвэл $6$.
- `al8-pr-3` — Бодоорой: $(x + 5)^2 = 36$.
  **solution:** $x + 5 = \pm 6$: $x = 1$ эсвэл $x = -11$.
- `al8-pr-4` — Бодоорой: $x^2 + 4x = 21$.
  **solution:** $x^2 + 4x - 21 = 0 \to (x + 7)(x - 3) = 0$: $x = -7$ эсвэл $3$.
- `al8-pr-5` — Бүтэн квадрат болгож $x^2 + 2x - 5 = 0$-ийг яг утгаар нь
  бодоорой.
  **solution:** $(x + 1)^2 = 6$: $x = -1 \pm \sqrt{6}$.
- `al8-pr-6` — Квадрат тэгшитгэлийн томьёогоор $2x^2 + x - 6 = 0$-ийг бодоорой.
  **solution:** $D = 1 + 48 = 49$; $x = \frac{-1 \pm 7}{4}$: $x = \frac{3}{2}$
  эсвэл $-2$.
- `al8-pr-7` — $x^2 + 3x + 5 = 0$ хэдэн бодит шийдтэй вэ?
  **solution:** $D = 9 - 20 = -11 < 0$: байхгүй.
- `al8-pr-8` — Тэгш өнцөгтийн урт нь өргөнөөсөө 5-аар илүү; талбай нь 84.
  Өргөнийг нь олоорой.
  **solution:** $w^2 + 5w - 84 = 0 \to (w + 12)(w - 7) = 0$: өргөн 7 ($-12$-ийг
  хаяна); урт 12.

## TEST YOURSELF

- `al8-ty-1` — $f(x) = -2x^2 + 12x - 7$-ийн орой болон тэнхлэгийг олоод,
  хамгийн их эсвэл хамгийн бага утга эсэхийг хэлээрэй.
  **solution:** $x_v = -\frac{12}{-4} = 3$; $f(3) = -18 + 36 - 7 = 11$. Орой
  $(3, 11)$, тэнхлэг $x = 3$, ХАМГИЙН ИХ утга ($a < 0$).
- `al8-ty-2` — Бодоорой: $3x^2 = 12x$.
  **solution:** $3x^2 - 12x = 0 \to 3x(x - 4) = 0$: $x = 0$ эсвэл $x = 4$.
  ($x$-д эхлээд хуваасан бол тэг шийдийг АЛДАХ байсан.)
- `al8-ty-3` — $x^2 - 4x - 3 = 0$-ийг яг утгаар нь бодоорой (бүтэн квадрат
  болгох эсвэл томьёо).
  **solution:** $(x - 2)^2 = 7$: $x = 2 \pm \sqrt{7}$.
- `al8-ty-4` — $x^2 + kx + 25 = 0$ яг нэг шийдтэй байх $k$-ийн утгуудыг
  олоорой.
  **solution:** $D = k^2 - 100 = 0$: $k = 10$ эсвэл $k = -10$.
- `al8-ty-5` — Пуужингийн өндөр $h(t) = -5t^2 + 30t$ метр. Хамгийн их өндөр
  болон газардах хугацааг нь олоорой.
  **solution:** Орой: $t = 3$, $h(3) = -45 + 90 = 45$ м. Газардалт:
  $-5t(t - 6) = 0 \to t = 6$ сек.
- `al8-ty-6` — Дараалсан хоёр эерэг бүхэл тооны үржвэр 132. Тэднийг олоорой.
  **solution:** $n(n + 1) = 132 \to n^2 + n - 132 = 0 \to (n + 12)(n - 11) = 0$:
  $n = 11$ ($-12$-ийг хаяна). Тоонууд нь 11 ба 12.

## Notes for Khas

1. **«тэг үржвэрийн чанар» for the zero-product property — ungrounded, 0 hits.**
   The ministry, the dictionary (`z` is far past the batch you have sent) and
   the corpus are all silent. It is built from grounded parts — «тэг»,
   «үржвэр», «чанар», the last matching how the dictionary names properties
   («гишүүнчлэн үржүүлэх чанар», p. 190). The lesson also states the rule in
   plain words before naming it, so a student is not left depending on the
   label. Still my coinage, and it titles the lesson's central idea.

2. **«давхардсан шийд» for a repeated root — ungrounded, 0 hits.** «давхар
   язгуур» scores 0 as well. Used twice. If there is a standard Mongolian
   phrase for the double root at $D = 0$, this is where it belongs.

3. **A malformed English option — found here, fixed in the English too.**
   Lesson 3's sixth step was shipping this as a live answer choice:
   «$\sqrt{49}$... with $b = 5$: also 1?» — an unfinished authoring note that
   reached production on `/course/algebra-1/quadratic-equations`.

   The obvious repair, trimming it to `$\sqrt{49}$`, is wrong: option B is
   already `$7$`, and $\sqrt{49} = 7$, so the two would be the same value —

   explanation names both traps. `check[]` gained `(-5)**2 == 25`;
   `verify:genmath` passes at 34,872.
