## Lesson 1 — Гурван харьцаа (`the-three-ratios`)

**concreteComparison**

Ижил налуутай налуу зам бүр, хаалганы дэвсгэрийн шаантаг ч бай, хурдны замын
гүүр ч бай, өндөр ба хэвтээ уртынхаа харьцаагаар ижил: төстэй гурвалжин үүнийг
баталдаг. Тригонометр тэр баталгааг савлан гаргадаг: зөвхөн ӨНЦГӨӨС хамаардаг,
хэмжээнээс хэзээ ч хамаардаггүй гурван харьцаа.

**objective**

Тэгш өнцөгт гурвалжны талуудыг өнцөгтэй нь харьцуулан нэрлэж, талуудын уртаас
синус, косинус, тангенсыг олох.

**concept**

1. Тэгш өнцөгт гурвалжинд талууд таны ажиллаж буй хурц өнцөг $\theta$-тай
   ХАРЬЦАНГУЙ нэр авна. **Гипотенуз** нь үргэлж тэгш өнцгийн эсрэг талын
   (хамгийн урт) тал. **Эсрэг орших катет** нь $\theta$-ийн эсрэг талд орших
   катет. **Налсан катет** нь $\theta$-д хүрч буй катет. Нөгөө хурц өнцөг рүү
   шилжвэл эсрэг ба налсан байраа солино.

2. Гурван харьцаа: $\sin\theta = \frac{\text{эсрэг}}{\text{гипотенуз}}$,
   $\cos\theta = \frac{\text{налсан}}{\text{гипотенуз}}$,
   $\tan\theta = \frac{\text{эсрэг}}{\text{налсан}}$. Санахдаа **Э/Г · Н/Г ·
   Э/Н**. Сонгодог 3-4-5 гурвалжинд $\theta$ нь 3 урттай талын эсрэг орших бол:
   $\sin\theta = \frac{3}{5}$, $\cos\theta = \frac{4}{5}$,
   $\tan\theta = \frac{3}{4}$.

3. ЯАГААД ажилладаг вэ: $\theta$ өнцөгтэй аливаа хоёр тэгш өнцөгт гурвалжин
   төстэй тул талуудын ХАРЬЦАА нь яг таарна. Харьцаанууд зөвхөн өнцгийн шинж
   чанар. Тригонометрийн бүх эрх үүнд: $\sin 35°$ бол хэний ч гурвалжинд
   хэмжсэн ганц тодорхой тоо. Харьцаа бүр зөвхөн хоёр талыг ашигладаг тул
   дутуу гурав дахь талыг Пифагорын теорем олж өгнө.

**keyIdea**

Талуудыг $\theta$-аас нэрлэнэ (эсрэг, налсан, гипотенуз). Э/Г · Н/Г · Э/Н нь
өнцөгт өөрт нь харьяалагдах, хэмжээнээс үл хамаарах гурван харьцааг өгнө.

**facts**

- **title** Э/Г · Н/Г · Э/Н · **latex** `\sin\theta = \tfrac{\text{эсрэг}}{\text{гипотенуз}}, \quad \cos\theta = \tfrac{\text{налсан}}{\text{гипотенуз}}, \quad \tan\theta = \tfrac{\text{эсрэг}}{\text{налсан}}` · **explanation** Ашигладаг талуудаараа нэрлэгдсэн гурван харьцаа.
- **title** Хэмжээ яагаад хамаагүй вэ · **latex** `\text{ижил } \theta \Rightarrow \text{төстэй гурвалжин} \Rightarrow \text{ижил харьцаа}` · **explanation** Харьцаа гурвалжинд биш, өнцөгт харьяалагдана.
- **title** Гурав дахь тал · **latex** `a^2 + b^2 = c^2` · **explanation** Хоёр тал мэдэгдэж байвал Пифагор гурав дахийг өгнө.

**workedExamples**

- `trig11-we1` — **statement:** $ABC$ тэгш өнцөгт гурвалжны тэгш өнцөг нь
  $C$ оройд, $AC = 4$, $BC = 3$, $AB = 5$. $\sin A$, $\cos A$, $\tan A$-г
  олоорой.
  **solution:** Талуудыг $A$-аас нэрлэе: эсрэг $= BC = 3$ ($A$-ийн эсрэг
  талд), налсан $= AC = 4$ ($A$-д хүрч буй катет), гипотенуз $= AB = 5$.
  Тэгвэл $\sin A = \frac{3}{5}$, $\cos A = \frac{4}{5}$, $\tan A = \frac{3}{4}$.
  Шалгалт: $\sin^2 A + \cos^2 A = \frac{9}{25} + \frac{16}{25} = 1$ ✓.
- `trig11-we2` — **statement:** Тэгш өнцөгт гурвалжны катетууд $5$ ба $12$.
  Гипотенузыг олоод, 5 урттай талын эсрэг орших $\theta$ өнцгийн гурван
  харьцааг олоорой.
  **solution:** Эхлээд Пифагор: $c = \sqrt{25 + 144} = \sqrt{169} = 13$.
  $\theta$-аас: эсрэг $= 5$, налсан $= 12$, гипотенуз $= 13$:
  $\sin\theta = \frac{5}{13}$, $\cos\theta = \frac{12}{13}$,
  $\tan\theta = \frac{5}{12}$.

**commonMistakes**

- **text** «Эсрэг» ба «налсан»-ыг өнцгөөс биш, зурагнаас тогтоох. ·
  **correction** Нэрс ХАРЬЦАНГУЙ: $A$-ийн эсрэг орших тал $B$-д налсан байна.
  Харьцаа бичихийн өмнө ашиглаж буй өнцөг дээрээ хуруугаа тавиад, аль катет
  эсрэг талд, аль нь хүрч байгааг дахин тогтоогоорой.
- **text** Тангенст гипотенуз, синуст катет ба катетын харьцаа ашиглах. ·
  **correction** Зөвхөн тангенс л катет ба катетын харьцаа (эсрэг/налсан).
  Синус, косинус хоёулаа хуваарьтаа ГИПОТЕНУЗтай. Синус тань 1-ээс их гарвал
  катетын харьцаа нууцаар орсон байна: ямар ч катет гипотенузаас урт биш тул
  синус, косинус хэзээ ч 1-ээс хэтрэхгүй.

**tryIt**

- `trig11-t1` — **statement:** Тэгш өнцөгт гурвалжны катетууд $8$ ба $15$.
  Гипотенуз ба 8 урттай талын эсрэг орших $\theta$ өнцгийн $\tan\theta$-г
  олоорой.
  **solution:** $c = \sqrt{64 + 225} = \sqrt{289} = 17$. $\theta$-аас: эсрэг
  8, налсан 15: $\tan\theta = \frac{8}{15}$.
- `trig11-t2` — **statement:** Хурц өнцөг $\theta$-ийн хувьд
  $\cos\theta = \frac{4}{5}$. $\sin\theta$ ба $\tan\theta$-г олоорой (эхлээд
  гурвалжнаа байгуулаарай).
  **solution:** Байгуулбал: налсан 4, гипотенуз 5, эндээс эсрэг
  $= \sqrt{25 - 16} = 3$. Тиймээс $\sin\theta = \frac{3}{5}$,
  $\tan\theta = \frac{3}{4}$. Нэг харьцаа гурвалжны хэлбэрийг бүхэлд нь,
  тиймээс бусад хоёр харьцааг тогтооно.

## Lesson 2 — Дутуу талыг олох (`finding-missing-sides`)

**concreteComparison**

Шат хананд мэдэгдэх өнцгөөр налж, шатны урт мэдэгдэж байна: хананы өндөр аль
хэдийн тогтсон, та зүгээр л тооцоолоогүй байна. Нэг өнцөг ба нэг тал тэгш
өнцөгт гурвалжныг ТҮГЖИНЭ. Тригонометрийн харьцаа бол түгжигдсэн талуудыг унших
хэрэгсэл.

**objective**

Тэгш өнцөгт гурвалжны үл мэдэгдэх талыг тохирох тригонометр харьцаагаар олж,
үл мэдэгдэгчийн байрлалаас хамааруулан үржүүлэх эсвэл хуваах.

**concept**

1. Гурван алхамт жор: (1) өнцгөө тэмдэглээд оролцож буй хоёр талыг, мэдэх ба
   хайж буй талыг НЭРЛЭХ; (2) яг тэр хоёр нэрийг холбох харьцааг сонгох (эсрэг
   ба гипотенуз бол sin, налсан ба гипотенуз бол cos, эсрэг ба налсан бол
   tan); (3) тэгшитгэлээ бичээд бодох.

2. Үл мэдэгдэгчийн байрлал алгебрыг шийднэ. Үл мэдэгдэгч ДЭЭР:
   $\sin 30° = \frac{x}{10}$ бол $x = 10\sin 30° = 5$, үржүүлнэ. Үл мэдэгдэгч
   ДООР: $\sin 30° = \frac{6}{x}$ бол $x = \frac{6}{\sin 30°} = 12$, хуваана.
   Ижил харьцаа, эсрэг хөдөлгөөн.

3. Онцгой өнцөг $30°, 45°, 60°$ дээр хариу ЯГ гарна:
   $\sin 30° = \frac{1}{2}$, $\cos 60° = \frac{1}{2}$, $\tan 45° = 1$,
   $\sin 60° = \frac{\sqrt{3}}{2}$, $\sin 45° = \frac{\sqrt{2}}{2}$. Шалгалтууд
   яг үүнээс болж тэдэнд дуртай. Эдгээр утга хаанаас гардгийг 2-р нэгж
   гаргана.

**keyIdea**

Мэдэх ба хайж буй талаа нэрлээд, хоёуланг нь ашигладаг харьцааг сонгоорой.
Дараа нь үржүүлээрэй (үл мэдэгдэгч дээр) эсвэл хуваагаарай (үл мэдэгдэгч доор).

**facts**

- **title** Жор · **latex** `\text{нэрлэх} \to \text{харьцаа сонгох} \to \text{бодох}` · **explanation** Харьцаа мэдэх талыг хайж буй талтай холбох ёстой.
- **title** Байрлал шийднэ · **latex** `x = h\sin\theta \;\; \text{эсвэл} \;\; x = \tfrac{a}{\sin\theta}` · **explanation** Үл мэдэгдэгч дээр бол үржүүл, доор бол хуваа.
- **title** Онцгой өнцгийн утгууд · **latex** `\sin 30° = \tfrac{1}{2}, \; \sin 45° = \tfrac{\sqrt2}{2}, \; \sin 60° = \tfrac{\sqrt3}{2}` · **explanation** 30-45-60 өнцгийн хариу яг гарна, тооны машингүй.

**workedExamples**

- `trig12-we1` — **statement:** $ABC$ тэгш өнцөгт гурвалжинд (тэгш өнцөг $C$
  оройд) $\angle A = 30°$, гипотенуз $AB = 10$. $A$-ийн эсрэг орших $BC$ талыг
  олоорой.
  **solution:** Мэдэх: гипотенуз. Хайж буй: эсрэг. Хоёуланг нь ашигладаг
  харьцаа: синус. $\sin 30° = \frac{BC}{10}$, тиймээс
  $BC = 10\sin 30° = 10 \cdot \frac{1}{2} = 5$. Шалгалт: ХАМГИЙН БАГА өнцгийн
  эсрэг хамгийн богино тал оршино: гипотенуз 10-ын эсрэг 5 ✓.
- `trig12-we2` — **statement:** Шат газартай $60°$ өнцөг үүсгэж, суурь нь
  хананаас $3$ м зайтай. Шат ямар урттай вэ?
  **solution:** $60°$ өнцгөөс: мэдэх налсан тал (3 м), хайж буй гипотенуз,
  тэднийг косинус холбоно. $\cos 60° = \frac{3}{L}$: үл мэдэгдэгч ДООР тул
  хуваана: $L = \frac{3}{\cos 60°} = \frac{3}{1/2} = 6$ м. Шат эгц байх тусам
  косинус бага, суурийн ижил зайд шат урт болно.

**commonMistakes**

- **text** Үргэлж үржүүлэх: тэгшитгэл $\sin 30° = \frac{6}{x}$ байхад
  $x = 6\sin 30°$ гэх. · **correction** Алгебрт хүрэхээсээ өмнө үл мэдэгдэгч
  ХААНА байгааг хараарай. Доорх үл мэдэгдэгч ХУВААЛТААР гарна:
  $x = \frac{6}{\sin 30°} = 12$, 3 биш. Буруу алхам гипотенузыг катетаас
  богиносгоно: боломжгүй, шалгалт үүнийг барина.
- **text** Харьцааг оролцож буй хоёр талаар биш, зуршлаар (үргэлж синус)
  сонгох. · **correction** Харьцааг бодлогын хөндөж буй талууд ТОГТООНО:
  налсан ба гипотенузын хос синусгүй, энэ бол косинусын хос. Эхлээд мэдэх ба
  хайж буй талаа чангаар нэрлээрэй, харьцаа өөрөө сонгогдоно.

**tryIt**

- `trig12-t1` — **statement:** Тэгш өнцөг $C$ оройд, $\angle A = 60°$,
  гипотенуз $AB = 14$. $BC$-г ($A$-ийн эсрэг орших) яг олоорой.
  **solution:** $\sin 60° = \frac{BC}{14}$, эндээс
  $BC = 14 \cdot \frac{\sqrt{3}}{2} = 7\sqrt{3}$.
- `trig12-t2` — **statement:** Тугны шонгийн суурьнаас $20$ м зайтай цэгээс
  шон $45°$ өнцгөөр харагдана. Шонгийн өндрийг олоод, яагаад тооны машин
  хэрэггүй байсныг тайлбарлаарай.
  **solution:** $\tan 45° = \frac{h}{20}$, эндээс
  $h = 20\tan 45° = 20 \cdot 1 = 20$ м. $45°$ үед эсрэг ба налсан катет ТЭНЦҮҮ
  (гурвалжин адил хажуут) тул тангенс яг 1: өндөр зайтай тэнцүү, тооцоо
  шаардлагагүй.

## Lesson 3 — Дутуу өнцгийг олох (`finding-missing-angles`)

**concreteComparison**

Тэргэнцрийн налуу замын байцаагч өнцгийг тэнгэрт транспортираар хэмждэггүй:
өндөр ба хэвтээ уртыг метрээр хэмжиж, харьцааг бодоод «АЛЬ өнцөг ийм
тангенстай вэ?» гэж асууна. Тэр урвуу асуулт бол тригонометрийн урвуу функц.

**objective**

Мэдэгдэх хоёр талаас тригонометрийн урвуу функцээр үл мэдэгдэх хурц өнцгийг
олох.

**concept**

1. Шууд тригонометр «өнцөг өгөгдвөл харьцаа хэд вэ?» гэдэгт хариулна. Урвуу
   асуулт, «харьцаа өгөгдвөл өнцөг хэд вэ?», **урвуу функцээр** хариулагдана:
   $\sin^{-1}$, $\cos^{-1}$, $\tan^{-1}$ (мөн arcsin, arccos, arctan гэж
   бичнэ). $\sin\theta = \frac{1}{2}$ бол
   $\theta = \sin^{-1}\!\left(\frac{1}{2}\right) = 30°$.

2. Жор өмнөх хичээлийнхтэй адил: нууцлаг өнцгөөс мэдэгдэх ХОЁР талаа нэрлэж,
   тэр нэрсийн заасан харьцааг байгуулаад, тохирох урвуу функцийг хэрэглэнэ.
   Катетууд 3 ба 4, эсрэг нь 3 бол $\tan\theta = \frac{3}{4}$, тиймээс
   $\theta = \tan^{-1}\!\left(\frac{3}{4}\right) \approx 36.9°$.

3. Тэмдэглэгээний урхи: $\sin^{-1} x$ нь $\frac{1}{\sin x}$ БИШ. $-1$ нь
   «урвуу функц» (буцаах) гэсэн утгатай, «урвуу тоо» биш. Үнэгүй шалгалт ч
   үргэлж бий: тэгш өнцөгт гурвалжны хоёр хурц өнцгийн нийлбэр $90°$, тиймээс
   нэгийг нь олбол нөгөө нь $90° - \theta$. Хоёр замаар бодоход тэд таарах
   ёстой.

**keyIdea**

Урвуу тригонометр «аль өнцөг ийм харьцаатай вэ?» гэдэгт хариулна: мэдэгдэх
хоёр талаас харьцаа байгуулж, arcsin, arccos, arctan-ыг хэрэглээрэй. Хурц
өнцгүүдийн нийлбэр 90° байх ёстой.

**facts**

- **title** Урвуу функцүүд · **latex** `\sin\theta = k \iff \theta = \sin^{-1}(k) \;\; (0° < \theta < 90°)` · **explanation** Харьцаа оруулахад өнцөг гарна, нэг хурц хариу.
- **title** Урвуу тоо биш · **latex** `\sin^{-1} x \neq \frac{1}{\sin x}` · **explanation** $-1$ нь урвуу ФУНКЦийг (буцаалтыг) тэмдэглэнэ, хуваалтыг биш.
- **title** Үнэгүй шалгалт · **latex** `A + B = 90°` · **explanation** Тэгш өнцөгт гурвалжны хурц өнцгүүд гүйцээлт өнцгүүд.

**workedExamples**

- `trig13-we1` — **statement:** Тэгш өнцөг $C$ оройд; $A$-ийн эсрэг орших тал
  $5$, гипотенуз $10$. $\angle A$-г олоорой.
  **solution:** Мэдэх: эсрэг ба гипотенуз, тиймээс синус.
  $\sin A = \frac{5}{10} = \frac{1}{2}$, эндээс
  $A = \sin^{-1}\!\left(\frac{1}{2}\right) = 30°$. Гүйцээлтээр шалгавал:
  $\cos B = \frac{1}{2}$ нь $B = 60°$ өгөх ба $30° + 60° = 90°$ ✓.
- `trig13-we2` — **statement:** Налуу зам $4$ м хэвтээ уртад $3$ м өгсөнө.
  Налалтын өнцгийг бүхэл градус хүртэл тоймлон олоорой.
  **solution:** Өндөр нь эсрэг, хэвтээ урт нь налсан, тиймээс тангенс:
  $\tan\theta = \frac{3}{4}$. Эндээс
  $\theta = \tan^{-1}\!\left(\frac{3}{4}\right) \approx 36.9° \approx 37°$.
  Шалгалт: $\frac{3}{4} < 1 = \tan 45°$ тул өнцөг $45°$-аас бага гарах ёстой ✓.

**commonMistakes**

- **text** $\sin^{-1} x$-ийг $1/\sin x$ гэж уншиж урвуу тоо бодох. ·
  **correction** $-1$ бол урвуу функцийн тэмдэглэгээ: $\sin^{-1}(0.5)$ нь «аль
  өнцгийн синус $0.5$ вэ?» гэж асууна, хариу $30°$. Урвуу тоо
  $\frac{1}{0.5} = 2$ бол синусын боломжит утга ч биш. Эргэлзвэл arcsin гэж
  бичээрэй.
- **text** Харьцааг урвуугаар байгуулах: $\tan\theta = $ налсан/эсрэг. ·
  **correction** Урвуу функц өгсөн харьцааных тань өнцгийг үнэнчээр буцаана:
  урвуулсан харьцаа өгвөл НӨГӨӨ хурц өнцгийг авна. Эхлээд талуудыг нууцлаг
  өнцгөөс нэрлээрэй. Гурвалжны хоёр өнцгийн хариу тань $90°$ болж нийлэхгүй бол
  нэг харьцаа урвуу байна.

**tryIt**

- `trig13-t1` — **statement:** $\theta$-д налсан тал $7$, гипотенуз $14$.
  $\theta$-г олоорой.
  **solution:** $\cos\theta = \frac{7}{14} = \frac{1}{2}$, эндээс
  $\theta = \cos^{-1}\!\left(\frac{1}{2}\right) = 60°$.
- `trig13-t2` — **statement:** $12$ м шонгийн оройгоос газар хүртэл $13$ м
  татлага татжээ. Татлага ГАЗАРтай ямар өнцөг үүсгэх вэ, бэхэлгээ нь шонгийн
  суурьнаас ямар зайтай вэ?
  **solution:** Эхлээд бэхэлгээний зай: $\sqrt{13^2 - 12^2} = \sqrt{25} = 5$ м.
  Газартай үүсгэх өнцгөөс: эсрэг 12, гипотенуз 13:
  $\theta = \sin^{-1}\!\left(\frac{12}{13}\right) \approx 67.4°$. Шалгалт:
  $\frac{12}{13}$ нь 1-д ойр тул өнцөг $90°$-т ойр байх ёстой: тийм байна.

## Lesson 4 — Дээшээ ба доошоо харах өнцөг (`elevation-and-depression`)

**concreteComparison**

Дээврийг харахаар эрүүгээ өргөөрэй: хэвтээ шугамаас дээшлэх тэр хазайлт бол
ДЭЭШЭЭ харах өнцөг. Дээвэр дээр зогсоод найзыгаа доош хараарай: хэвтээ шугамаас
доошлох хазайлт бол ДООШОО харах өнцөг. Бодит ертөнцийн «хэр өндөр, хэр хол»
бодлого бүр эдгээр хоёр хазайлтын аль нэгээс эхэлнэ.

**objective**

Дээшээ болон доошоо харах өнцгийн өгүүлбэрийг тэгш өнцөгт гурвалжин болгон
хөрвүүлж, өндөр, зайг олох.

**concept**

1. Хоёр өнцгийг хоёуланг нь ХЭВТЭЭ ШУГАМААС хэмжинэ, хана, шон, налуугаас
   хэзээ ч үгүй. **Дээшээ харах өнцөг**: хэвтээ шугамаас дээш харах.
   **Доошоо харах өнцөг**: хэвтээ шугамаас доош харах. Ажиглагчийн хэвтээ шугам
   үргэлж өнцгийн суурь тал.

2. Хөрвүүлэх жор: ажиглагчийн нүдний түвшинд хэвтээ шугам татаж, өнцгийг
   тэмдэглээд тэгш өнцөгт гурвалжнаа гүйцээнэ (өндөр нь босоо катет, газрын зай
   нь хэвтээ катет). Дараа нь өмнөх хичээлийн механизм: нэрлэсэн хоёр тал ба
   нэг өнцөг, харьцаа сонгох, бодох.

3. Доошоо харах өнцгийн товчлол: ажиглагчийн хэвтээ шугам газартай ПАРАЛЛЕЛЬ
   тул орой дээрх доошоо харах өнцөг нь газрын цэгээс харсан дээшээ харах өнцөгтэй
   ТЭНЦҮҮ: Геометрийн сэдвийн эсрэг талын дотоод өнцгүүд. Практикт: доошоо харах
   өнцгийг гурвалжнынхаа ДООД оройд тэмдэглээд цааш явна.

**keyIdea**

Дээшээ, доошоо харах өнцөг хоёулаа ХЭВТЭЭ шугамаас хэмжигдэнэ: хэвтээ шугамаа
татаж, тэгш өнцөгт гурвалжнаа гүйцээгээрэй. Орой дээрх доошоо харах өнцөг
доод цэг дээрх дээшээ харах өнцөгтэй тэнцүү (эсрэг талын дотоод өнцөг).

**facts**

- **title** Хэвтээ шугамаас · **latex** `\text{дээшээ: хэвтээгээс дээш;} \;\; \text{доошоо: хэвтээгээс доош}` · **explanation** Хэвтээ шугам бол суурь тал, хана хэзээ ч биш.
- **title** Солилцоо · **latex** `\text{орой дээрх доошоо} = \text{доод цэг дээрх дээшээ}` · **explanation** Параллель хэвтээ шугамуудын хоорондох эсрэг талын дотоод өнцгүүд.
- **title** Түгээмэл харьцаа · **latex** `\tan\theta = \frac{\text{өндөр}}{\text{газрын зай}}` · **explanation** Өндөр ба газрын зай бол хоёр катет: тангенсын нутаг.

**workedExamples**

- `trig14-we1` — **statement:** Цамхгийн суурьнаас $30$ м зайтай цэгээс оройг
  нь $60°$ дээшээ харах өнцгөөр харна. Цамхгийн өндрийг яг олоорой.
  **solution:** Газрын зай 30 (налсан), өндөр $h$ (эсрэг):
  $\tan 60° = \frac{h}{30}$, тиймээс $h = 30\tan 60° = 30\sqrt{3} \approx 52$ м.
  Шалгалт: $45°$ үед өндөр 30 байх байсан; илүү эгц $60°$ илүү их өгөх ёстой ✓.
- `trig14-we2` — **statement:** $40$ м өндөр хадны оройгоос завийг $30°$
  доошоо харах өнцгөөр харна. Завь хадны ёроолоос ямар зайтай вэ, яг олоорой.
  **solution:** Өнцгийг завь руу шилжүүлье: завинаас харах дээшээ харах өнцөг
  мөн $30°$. Завинаас: эсрэг $=$ хад $= 40$, налсан $=$ зай $d$:
  $\tan 30° = \frac{40}{d}$, тиймээс
  $d = \frac{40}{\tan 30°} = 40\sqrt{3} \approx 69$ м. Намхан өнцөг, хол завь:
  геометр санал нийлнэ.

**commonMistakes**

- **text** Доошоо харах өнцгийг хэвтээ шугамаас биш, хадны хана эсвэл цамхгаас
  хэмжих. · **correction** Доошоо харах өнцөг бол ХЭВТЭЭГЭЭС ДООШ: тэгш харц ба
  хазайсан харцын хоорондох өнцөг. Босоо хананаас хэмжвэл хариу бүр гүйцээлт
  өнцгөөр гарна ($90° - \theta$ болж буруудна). Үргэлж эхлээд хэвтээ тасархай
  шугамаа татаарай.
- **text** Доошоо харах өнцгийг шилжүүлэлгүйгээр гурвалжны дээд оройн дотор
  тавих. · **correction** Доошоо харах өнцөг гурвалжны ГАДНА (хэвтээ шугам ба
  гипотенузын хооронд) оршино. Эсрэг талын дотоод өнцгөөр түүнийг холын орой
  руу шилжүүлээрэй, тэнд тэр цэгийн дээшээ харах өнцөг болно. Зөвхөн дараа нь
  Э/Г · Н/Г · Э/Н-ийг хэрэглээрэй.

**tryIt**

- `trig14-t1` — **statement:** Нарны дээшээ харах өнцөг $45°$ үед мод $9$ м
  сүүдэр тусгана. Мод ямар өндөр вэ?
  **solution:** $\tan 45° = \frac{h}{9}$, эндээс $h = 9 \cdot 1 = 9$ м. $45°$ үед
  биет бүр сүүдрийнхээ урттай яг тэнцүү өндөр.
- `trig14-t2` — **statement:** Дрон газраас $50$ м өндөрт эргэлдэж байна.
  Удирдагч түүнийг $30°$ дээшээ харах өнцгөөр харна. Удирдагч дроны яг доорх
  цэгээс ямар зайтай вэ, яг олоорой.
  **solution:** $\tan 30° = \frac{50}{d}$, эндээс
  $d = \frac{50}{\tan 30°} = 50\sqrt{3} \approx 87$ м. Намхан өнцөг газрын зайг
  өндрөөс нэлээд урт болгоно.

## PRACTICE

- `trig1-pr-1` — **statement:** $ABC$ тэгш өнцөгт гурвалжинд (тэгш өнцөг $C$
  оройд) $AC = 12$, $BC = 5$, $AB = 13$. $\sin A$, $\cos A$, $\tan A$-г
  бичээрэй.
  **solution:** $A$-аас: эсрэг $= BC = 5$, налсан $= AC = 12$, гипотенуз
  $= 13$. $\sin A = \frac{5}{13}$, $\cos A = \frac{12}{13}$,
  $\tan A = \frac{5}{12}$.
- `trig1-pr-2` — **statement:** Хурц өнцөг $\theta$-ийн хувьд
  $\tan\theta = \frac{8}{15}$. $\sin\theta$ ба $\cos\theta$-г олоорой.
  **solution:** Гурвалжнаа байгуулбал: эсрэг 8, налсан 15, гипотенуз
  $\sqrt{64 + 225} = 17$. $\sin\theta = \frac{8}{17}$,
  $\cos\theta = \frac{15}{17}$.
- `trig1-pr-3` — **statement:** Тэгш өнцөг $C$ оройд, $\angle A = 30°$,
  гипотенуз $AB = 26$. Хоёр катетыг яг олоорой.
  **solution:** Эсрэг: $26\sin 30° = 13$. Налсан:
  $26\cos 30° = 26 \cdot \frac{\sqrt3}{2} = 13\sqrt{3}$. Шалгалт:
  $13^2 + (13\sqrt3)^2 = 169 + 507 = 676 = 26^2$ ✓.
- `trig1-pr-4` — **statement:** Цаасан шувууны утас $50$ м урт бөгөөд газартай
  $60°$ өнцөг үүсгэнэ. Цаасан шувуу ямар өндөрт байгааг яг олоорой.
  **solution:** Өндөр нь эсрэг, утас нь гипотенуз:
  $h = 50\sin 60° = 25\sqrt{3} \approx 43$ м.
- `trig1-pr-5` — **statement:** $\theta$-ийн эсрэг орших тал $9$, налсан тал
  $9\sqrt{3}$. $\theta$-г яг олоорой.
  **solution:**
  $\tan\theta = \frac{9}{9\sqrt3} = \frac{1}{\sqrt3} = \frac{\sqrt3}{3}$,
  эндээс $\theta = 30°$.
- `trig1-pr-6` — **statement:** $10$ м шат хананд $8$ м өндөрт хүрнэ. Шат
  ГАЗАРтай ямар өнцөг үүсгэх вэ (бүхэл градус хүртэл), суурь нь хананаас ямар
  зайтай вэ?
  **solution:** Суурь: $\sqrt{100 - 64} = 6$ м. Газартай үүсгэх өнцөг:
  $\sin\theta = \frac{8}{10}$, $\theta = \sin^{-1}(0.8) \approx 53°$.
- `trig1-pr-7` — **statement:** $45$ м зайнаас хөшөөний орой $45°$, мөн
  цэгээс түүн дээрх тугны үзүүр $60°$ дээшээ харах өнцөгт харагдана. Хөшөөний
  өндөр ба тугны үзүүрийн өндрийг яг олоорой.
  **solution:** Хөшөө: $45\tan 45° = 45$ м. Тугны үзүүр:
  $45\tan 60° = 45\sqrt{3} \approx 78$ м. (Туг өөрөө тэдгээрийн ялгавар:
  $45\sqrt3 - 45 \approx 33$ м.)
- `trig1-pr-8` — **statement:** $60$ м цамхгийн оройгоос машиныг $60°$ доошоо
  харах өнцгөөр харна. Машин цамхгийн суурьнаас ямар зайтай вэ, яг олоорой.
  **solution:** Машин руу шилжүүл: тэнд дээшээ харах өнцөг $60°$.
  $\tan 60° = \frac{60}{d}$, эндээс
  $d = \frac{60}{\sqrt3} = 20\sqrt{3} \approx 35$ м. Эгц өнцөг, ойр машин.

## TEST YOURSELF

- `trig1-ty-1` — **statement:** Тэгш өнцөгт гурвалжны гипотенуз $25$, нэг
  катет $7$. Нөгөө катет ба 7 урттай катетын эсрэг орших $\theta$ өнцгийн
  гурван харьцааг олоорой.
  **solution:** Нөгөө катет: $\sqrt{625 - 49} = \sqrt{576} = 24$.
  $\sin\theta = \frac{7}{25}$, $\cos\theta = \frac{24}{25}$,
  $\tan\theta = \frac{7}{24}$.
- `trig1-ty-2` — **statement:** Хурц өнцөг $\theta$-ийн хувьд
  $\sin\theta = \frac{3}{5}$. $\frac{\sin\theta}{\cos\theta}$-г бодоод
  $\tan\theta$-тай тэнцүү гэдгийг батлаарай.
  **solution:** Гурвалжин: 3-4-5, тиймээс $\cos\theta = \frac{4}{5}$.
  $\frac{\sin\theta}{\cos\theta} = \frac{3/5}{4/5} = \frac{3}{4} = \tan\theta$ ✓.
  Синусыг косинуст хуваахад үргэлж тангенс гарна (хоёулаа эсрэг ба налсан
  талыг гипотенузад хуваасан).
- `trig1-ty-3` — **statement:** Тэгш өнцөг $C$ оройд, $\angle B = 45°$,
  $BC = 6$. $AC$ ба $AB$-г яг олоорой.
  **solution:** $B$-ээс: $AC$ эсрэг, $BC = 6$ налсан: $AC = 6\tan 45° = 6$.
  Гипотенуз: $AB = \frac{6}{\cos 45°} = 6\sqrt{2}$. 45°-ын гурвалжин: катетууд
  тэнцүү, гипотенуз нь катетаас $\sqrt2$ дахин урт.
- `trig1-ty-4` — **statement:** Дүүжин замын татлага $30$ м өндөр тавцангаас
  газар хүртэл сунаж, газартай $30°$ өнцгөөр тулна. Татлага ямар урт вэ?
  **solution:** Өндөр нь эсрэг, татлага нь гипотенуз:
  $L = \frac{30}{\sin 30°} = \frac{30}{1/2} = 60$ м.
- `trig1-ty-5` — **statement:** Налуу зам $2$ м өгсөх ёстой бөгөөд налалт нь
  $30°$-аас хэтрэх ёсгүй. Зөвшөөрөгдөх ХАМГИЙН БОГИНО хэвтээ урт хэд вэ (яг),
  $3$ м хэвтээ урт шаардлага хангах уу?
  **solution:** Яг $30°$ үед: $\tan 30° = \frac{2}{\text{урт}}$, эндээс
  $\text{урт} = \frac{2}{\tan 30°} = 2\sqrt{3} \approx 3.46$ м: хамгийн богино
  зөвшөөрөгдөх урт. 3 м урт үүнээс БОГИНО тул налуу $30°$-аас эгц болно:
  шаардлага хангахгүй.
- `trig1-ty-6` — **statement:** Хоёр барилга $24$ м зайтай. Намхан ($18$ м)
  барилгын дээврээс өндөр барилгын орой $30°$ дээшээ харах өнцөгт харагдана.
  Өндөр барилгын өндрийг яг олоорой.
  **solution:** Намхан барилгын дээврээс өндөр барилга хүртэл хэвтээ 24 м:
  нэмэлт өндөр $= 24\tan 30° = 8\sqrt{3}$. Нийт: $18 + 8\sqrt{3} \approx 31.9$ м.
