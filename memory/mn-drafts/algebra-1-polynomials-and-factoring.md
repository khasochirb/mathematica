**Three notes on the spelling.** The book sets these compounds solid —
«олонгишүүнт», «хоёргишүүнт», «нэггишүүнт» — and flags its own habit at
p. 222: *usually* written apart. The ministry writes «олон гишүүнт» apart
fourteen times and the shipped corpus ninety-nine times, so this draft writes
them apart throughout. That is the ministry outranking the dictionary on a
point the dictionary itself concedes.

**FOIL is dropped, not translated.** The book does carry it — «Хоёр хоёргишүүнт
үржүүлэх арга», p. 163 — but it is an English mnemonic for the order of four
letters, and the Mongolian rendering is just a description of what it does. The
English lesson says so itself: «for binomials this is nicknamed FOIL, but the
rule is just double distribution». The Mongolian keeps the rule and drops the
acronym, which is the rewrite doing its job.

## Lesson 1 — Олон гишүүнтийн арифметик (`polynomial-arithmetic`)

**concreteComparison**

Таван хошуу мал тоолж байна гэж бодоорой: адуу адуутайгаа, хонь хоньтойгоо.
Хонийг адуутай нэмж болохгүй — өөр төрөл. Олон гишүүнт яг ийм: $x^2$ нь
$x^2$-тэйгээ, $x$ нь $x$-тэйгээ нийлнэ. Харин үржүүлэх нь цагаан сарын золголт
— эхний олонлогийн гишүүн бүр хоёр дахийн гишүүн бүртэй золгох ёстой.

**objective**

Олон гишүүнтийг нэмж, хасаж, үржүүлэх; хасахдаа тэмдэг бүрийг мөрдөж, үржвэрт
гишүүн бүрийг хосоор нь тааруулах.

**concept**

1. **Олон гишүүнт** гэдэг нь бүхэл тоон илтгэгчтэй $ax^n$ гишүүдийн нийлбэр;
   түүний **зэрэг** нь хамгийн том илтгэгч. $3x^2 - 5x + 7$ бол 2-р зэргийн,
   гурван гишүүнтэй. **Стандарт хэлбэр** нь илтгэгчийг буурах дарааллаар бичнэ.

2. **Нэмэхдээ** ижил гишүүдийг нэгтгэнэ. **Хасахдаа** хасах тэмдэг хоёр дахь
   олон гишүүнтийн БҮХ гишүүнд хүрнэ — эхлээд тэр мөрийг нь тусад нь бичээрэй:
   $(3x^2 + 2x) - (x^2 - 5x + 4) = 3x^2 + 2x - x^2 + 5x - 4 = 2x^2 + 7x - 4$.

3. **Үржүүлэхдээ** гишүүн бүрийг гишүүн бүрээр үржүүлнэ. $(x + 3)(2x - 5)$
   дөрвөн золголт өгнө: $2x^2 - 5x + 6x - 15 = 2x^2 + x - 15$. Хоёр гишүүнтийн
   хувьд үүнийг англиар FOIL гэж нэрлэдэг ч дүрэм нь ердөө л давхар задлалт.

**keyIdea**

Нэмэх нь ижил гишүүдийг ялгах, хасах нь хоёр дахийн тэмдэг бүрийг эргүүлэх,
үржүүлэх нь гишүүн бүрийг гишүүн бүртэй хослуулах.

**facts**

| title | latex | explanation |
|---|---|---|
| Хасалт бүгдийг эргүүлнэ | `-(x^2 - 5x + 4) = -x^2 + 5x - 4` | Хасах тэмдэг бол гурван гишүүнд тараагдсан $(-1)$. |
| Гишүүн бүр гишүүн бүртэй | `(a + b)(c + d) = ac + ad + bc + bd` | 2 гишүүн × 2 гишүүн = 4 үржвэр; 2 × 3 = 6. Нэгтгэхээсээ өмнө тоолоорой. |

**workedExamples**

- `al71-we1` — **statement:** Хасаарай: $(4x^2 - 3x + 6) - (x^2 + 5x - 2)$.
  **solution:** Хоёр дахийн гурван тэмдгийг бүгдийг нь эргүүлье:
  $4x^2 - 3x + 6 - x^2 - 5x + 2 = 3x^2 - 8x + 8$. $x = 1$ дээр шалгавал:
  $(7) - (4) = 3$ бөгөөд $3 - 8 + 8 = 3$. ✓
- `al71-we2` — **statement:** Үржүүлээрэй: $(x + 3)(2x^2 - x + 4)$.
  **solution:** Зургаан золголт: $x(2x^2 - x + 4) = 2x^3 - x^2 + 4x$;
  $\;3(2x^2 - x + 4) = 6x^2 - 3x + 12$. Нийлбэр нь $2x^3 + 5x^2 + x + 12$.
  $x = 1$ дээр: $(4)(5) = 20$ бөгөөд $2 + 5 + 1 + 12 = 20$. ✓

**commonMistakes**

- **text:** Зөвхөн эхний гишүүнийг хасах:
  $(4x^2 \ldots) - (x^2 + 5x - 2) = 3x^2 + 5x - 2 \ldots$
  **correction:** Хасах тэмдэг хоёр дахийн БҮХ гишүүнд хүрнэ: $-x^2 - 5x + 2$.
  Нэгтгэхээсээ өмнө тэмдэг бүрийг эргүүлээрэй.
- **text:** Хоёр гишүүнтийг эхнийх×эхнийх нэмэх сүүлийнх×сүүлийнх гэж үржүүлэх:
  $(x+3)(x+5) = x^2 + 15$.
  **correction:** Энэ нь хөндлөн хоёр гишүүнийг алгасчээ:
  $x^2 + 5x + 3x + 15 = x^2 + 8x + 15$. Хоёр биш, дөрвөн хос золгоно.

**tryIt**

- `al71-t1` — Хялбарчлаарай: $(2x^2 + x - 7) + (x^2 - 4x + 3) - (x^2 - 5)$.
  **solution:** Эхний хоёрыг нэмбэл $3x^2 - 3x - 4$; гурав дахийг хасахдаа
  тэмдгийг эргүүлбэл $3x^2 - 3x - 4 - x^2 + 5 = 2x^2 - 3x + 1$. $x = 2$ дээр:
  $(8+2-7)+(4-8+3)-(4-5) = 3 + (-1) - (-1) = 3$; мөн $8 - 6 + 1 = 3$. ✓
- `al71-t2` — Үржүүлээрэй: $(3x - 2)(x + 5)$.
  **solution:** $3x^2 + 15x - 2x - 10 = 3x^2 + 13x - 10$. $x = 1$ дээр:
  $(1)(6) = 6$ бөгөөд $3 + 13 - 10 = 6$. ✓

## Lesson 2 — Онцгой үржвэрүүд (`special-products`)

**concreteComparison**

Гурван үржүүлэлт хэтэрхий олон давтагддаг тул тэднийг бодох биш, таних ёстой:
хоёр бүтэн квадрат $(a \pm b)^2$ ба хосмог хос $(a+b)(a-b)$. Квадрат, давхар
үржвэр, квадрат — мөн квадрат хасах квадрат.

**objective**

$(a+b)^2$, $(a-b)^2$, $(a+b)(a-b)$-ийг томьёогоор задалж, толгойн тооллогод
болон дараагийн хичээлийн задралд ашиглах.

**concept**

1. **Нийлбэрийн квадрат**: $(a + b)^2 = a^2 + 2ab + b^2$ — квадрат, дээр нь
   ДАВХАР үржвэр, дээр нь квадрат. Сонгодог алдаа нь $a^2 + b^2$ гэж бичих:
   энэ нь $2ab$ гэсэн тэгш өнцөгт хоёр хэсгийг гээж байгаа хэрэг.

2. **Ялгаврын квадрат**: $(a - b)^2 = a^2 - 2ab + b^2$ — ижил ястай, дунд
   тэмдэг нь сөрөг. Анзаараарай: $(a-b)^2 = (b-a)^2$, квадрат дараалал арчина.

3. **Хосмог хос**: $(a + b)(a - b) = a^2 - b^2$ — хөндлөн гишүүд $+ab$ ба $-ab$
   бие биеэ устгаад квадратын ялгавар үлдэнэ. Эндээс $102 \times 98 = 100^2 - 2^2 = 9996$
   гэх толгойн арга гарах ба ухраад уншвал алгебрийн хамгийн ашигтай задралын
   хэлбэр болно.

**keyIdea**

$(a \pm b)^2 = a^2 \pm 2ab + b^2$ ба $(a + b)(a - b) = a^2 - b^2$ — рефлекс
болтлоо хурдан гурван үржвэр.

**facts**

| title | latex | explanation |
|---|---|---|
| Бүтэн квадратууд | `(a \pm b)^2 = a^2 \pm 2ab + b^2` | Квадрат, давхар үржвэр, квадрат — дунд гишүүнийг л хүн бүр мартдаг. |
| Хосмог хос | `(a + b)(a - b) = a^2 - b^2` | Хөндлөн гишүүд хоорондоо хорогдож, зөвхөн квадратууд үлдэнэ. |

**workedExamples**

- `al72-we1` — **statement:** $(3x + 4)^2$ ба $(2x - 5)^2$-ийг задлаарай.
  **solution:** $(3x + 4)^2 = 9x^2 + 2(3x)(4) + 16 = 9x^2 + 24x + 16$.
  $(2x - 5)^2 = 4x^2 - 20x + 25$. Эхнийхийг $x = 1$ дээр шалгавал:
  $7^2 = 49 = 9 + 24 + 16$. ✓
- `al72-we2` — **statement:** $102 \times 98$-ийг тооны машингүйгээр бодоорой.
  **solution:** $102 \times 98 = (100 + 2)(100 - 2) = 100^2 - 2^2 = 10000 - 4 = 9996$.

**commonMistakes**

- **text:** $(a + b)^2 = a^2 + b^2$.
  **correction:** Шалгаад үзээрэй: $(3 + 4)^2 = 49$ атал $9 + 16 = 25$. Дутуу
  байгаа $2ab = 24$ нь яг тэр зөрүү. Нийлбэрийн квадрат ГУРВАН гишүүнтэй.
- **text:** $(a - b)^2 = a^2 - b^2$.
  **correction:** Квадрат нь квадратын ялгавар байж чадахгүй: $(5-2)^2 = 9$
  атал $25 - 4 = 21$. Зөв хэлбэр нь $a^2 - 2ab + b^2$.

**tryIt**

- `al72-t1` — $(x + 6)^2$, $(4x - 3)^2$, $(5x + 2)(5x - 2)$-ийг задлаарай.
  **solution:** $x^2 + 12x + 36$; $\;16x^2 - 24x + 9$; $\;25x^2 - 4$.
- `al72-t2` — $97^2$-ийг онцгой үржвэр ашиглан толгойдоо бодоорой.
  **solution:** $97^2 = (100 - 3)^2 = 10000 - 600 + 9 = 9409$.

## Lesson 3 — ХИЕХ ба гурван гишүүнтийг задлах (`gcf-and-factoring-trinomials`)

**concreteComparison**

Задлах гэдэг нь үржүүлэлтийг ухраах: 391 гэсэн үржвэрийг өгөөд $17 \times 23$-ийг
олуул. Гурван гишүүнтийн хувьд энэ нь жижиг оньсого — үржвэр нь $c$, нийлбэр нь
$b$ болох хоёр тоог олох — тэгээд ухарсан үржүүлэлт хорин асуултын тоглоом
болон хувирна.

**objective**

Хамгийн их ерөнхий хуваагчийг гаргаж авах, $x^2 + bx + c$ гурван гишүүнтийг
үржвэр-нийлбэрийн оньсогоор задлах, хайлтаа тэмдгээр нарийсгах.

**concept**

1. **Эхлээд үргэлж ХИЕХ-ээ хараарай**: $6x^2 + 15x = 3x(2x + 5)$ — хамгийн том
   ерөнхий тоо, хамгийн бага ерөнхий зэргийг гаргаж авна. Өөр ямар ч багаж
   барихаасаа өмнө ухраан задлаад, буцаан үржүүлж ШАЛГААРАЙ.

2. **Гурван гишүүнт** $x^2 + bx + c$ нь $(x + p)(x + q)$-оос гардаг бөгөөд
   $pq = c$, $p + q = b$. Задлах нь урвуу оньсого: үржвэр нь $c$, нийлбэр нь
   $b$ болох хоёр тоо. $x^2 + 7x + 12$ дээр: үржвэр 12, нийлбэр 7 → 3 ба 4 →
   $(x + 3)(x + 4)$.

3. **Тэмдэг хайлтыг нарийсгана**: $c > 0$ бол $p, q$ ижил тэмдэгтэй (хоёулаа
   $b$-ийн тэмдэгтэй); $c < 0$ бол эсрэг тэмдэгтэй бөгөөд абсолют утгаараа ИХ
   нь $b$-ийн тэмдгийг үүрнэ. $x^2 - 2x - 15$ дээр: үржвэр $-15$, нийлбэр $-2$
   → $-5$ ба $3$ → $(x - 5)(x + 3)$.

**keyIdea**

Эхлээд үргэлж ХИЕХ; дараа нь $x^2 + bx + c = (x + p)(x + q)$, энд $pq = c$,
$p + q = b$ — $b$, $c$-ийн тэмдэг хаана хайхыг тань хэлж өгнө.

**facts**

| title | latex | explanation |
|---|---|---|
| Эхлээд ХИЕХ | `6x^2 + 15x = 3x(2x + 5)` | Хамгийн том ерөнхий коэффициент, хамгийн бага ерөнхий зэрэг — ухраан задлаад дахин шалгана. |
| Үржвэр-нийлбэрийн оньсого | `x^2 + bx + c = (x + p)(x + q), \;\; pq = c, \; p + q = b` | $c > 0$ бол ижил тэмдэг. $c < 0$ бол эсрэг тэмдэг, том нь $b$-ийн тэмдгийг авна. |

**workedExamples**

- `al73-we1` — **statement:** $x^2 + 7x + 12$ ба $x^2 - 9x + 20$-ийг задлаарай.
  **solution:** Эхнийх: үржвэр 12, нийлбэр 7 → 3, 4: $(x+3)(x+4)$. Хоёр дахь:
  үржвэр $+20$, нийлбэр $-9$ → хоёулаа сөрөг: $-4, -5$: $(x-4)(x-5)$. Хоёр
  дахийг $x = 1$ дээр задлаж шалгавал: $(-3)(-4) = 12$ бөгөөд $1 - 9 + 20 = 12$. ✓
- `al73-we2` — **statement:** Гүйцэд задлаарай: $3x^3 - 3x^2 - 36x$.
  **solution:** Эхлээд ХИЕХ: $3x(x^2 - x - 12)$. Оньсого: үржвэр $-12$, нийлбэр
  $-1$ → $-4, 3$: $3x(x - 4)(x + 3)$. $x = 5$ дээр шалгавал:
  $3(125) - 75 - 180 = 120$ бөгөөд $15 \cdot 1 \cdot 8 = 120$. ✓

**commonMistakes**

- **text:** ХИЕХ-ээ алгасах: $2x^2 + 10x + 12$-ийг шууд $(2x + 4)(x + 3)$ болгох
  эсвэл гацах.
  **correction:** Эхлээд 2-ыг гаргаж аваарай: $2(x^2 + 5x + 6) = 2(x + 2)(x + 3)$.
  ХИЕХ-ийг түрүүлж авах нь хүнд оньсогыг амархан болгодог.
- **text:** Оньсого дээр тэмдгийг үл тоох: $x^2 - 2x - 15$-ийг $+5, -3$-аар
  задлах.
  **correction:** $5 + (-3) = +2$ — нийлбэр буруу. Үржвэр сөрөг байна гэдэг нь
  эсрэг тэмдэг, мөн ИХ тоо ($5$) нь $b$-ийн тэмдгийг (сөрөг) авна: $-5, +3$.

**tryIt**

- `al73-t1` — $x^2 + 3x - 28$-ийг задлаарай.
  **solution:** Үржвэр $-28$, нийлбэр $3$ → $7, -4$: $(x + 7)(x - 4)$. $x = 1$
  дээр: $8 \cdot (-3) = -24$ бөгөөд $1 + 3 - 28 = -24$. ✓
- `al73-t2` — Гүйцэд задлаарай: $2x^3 + 2x^2 - 40x$.
  **solution:** ХИЕХ нь $2x$: $2x(x^2 + x - 20) = 2x(x + 5)(x - 4)$.

## Lesson 4 — $ax^2 + bx + c$ ба онцгой хэлбэрүүд (`factoring-ax2-and-special-patterns`)

**concreteComparison**

Тэргүүлэх коэффициенттэй болоход оньсого эрчлэгддэг: $2x^2 + 7x + 3$ дээр
үржвэр нь $a \cdot c = 6$, нийлбэр нь 7 болох хоёр тоог хайгаад дунд гишүүнийг
хувааж, бүлэглэнэ. Дээр нь: 2-р хичээлийн онцгой үржвэрүүд одоо ухарч ажиллана.

**objective**

$ax^2 + bx + c$-ийг дунд гишүүнийг хуваах аргаар задлах, квадратын ялгавар ба
бүтэн квадрат гурван гишүүнтийг таних, багажуудаа хослуулан гүйцэд задлах.

**concept**

1. **$ac$-арга** нь $ax^2 + bx + c$-д зориулагдсан: үржвэр нь $ac$, нийлбэр нь
   $b$ болох хоёр тоог олоод, тэднээр дунд гишүүнийг ХУВААЖ, БҮЛЭГЛЭН задална.
   $2x^2 + 7x + 3$ дээр: $ac = 6$, нийлбэр 7 → 1, 6 →
   $2x^2 + x + 6x + 3 = x(2x + 1) + 3(2x + 1) = (2x + 1)(x + 3)$.

2. **Онцгой хэлбэрүүд ухарсан байдлаар**: $a^2 - b^2 = (a+b)(a-b)$ — хоёр
   квадратын ялгавар агшин зуур хуваагдана: $9x^2 - 25 = (3x+5)(3x-5)$. Бүтэн
   квадрат гурван гишүүнт буцаж эвхэгдэнэ: $x^2 + 10x + 25 = (x+5)^2$, учир нь
   дунд гишүүн нь квадрат язгууруудын үржвэрийг хоёр дахин авсантай тэнцүү —
   үүнийг шалгаарай.

3. **Гүйцэд задлах** гэдэг нь юу ч задрахаа болих хүртэл үргэлжлүүлэх:
   $2x^4 - 32 = 2(x^4 - 16) = 2(x^2+4)(x^2-4) = 2(x^2+4)(x+2)(x-2)$. $x^2 + 4$
   мэт квадратуудын НИЙЛБЭР байрандаа үлдэнэ — бодит тоон дээр үл задрах.

**keyIdea**

$a \ne 1$ үед: үржвэр нь $ac$, нийлбэр нь $b$ болох хоёр тоогоор $bx$-ийг
хувааж, дараа нь бүлэглээрэй; ухарсан онцгой үржвэрүүдийг цэнэглэсэн байлгаж,
юу ч хөдлөхөө болих хүртэл задлаарай.

**facts**

| title | latex | explanation |
|---|---|---|
| $ac$-арга | `2x^2 + 7x + 3: \; ac = 6, \; 7 = 1 + 6` | Үржвэр $ac$, нийлбэр $b$ — дараа нь бүлэглэлт өөрөө задарна. |
| Ухарсан хэлбэрүүд | `a^2 - b^2 = (a+b)(a-b), \quad a^2 \pm 2ab + b^2 = (a \pm b)^2` | Квадратын ялгавар хуваагдана; бүтэн квадрат гурван гишүүнт эвхэгдэнэ. Квадратуудын нийлбэр задрахгүй. |

**workedExamples**

- `al74-we1` — **statement:** $3x^2 - 10x + 8$-ийг задлаарай.
  **solution:** $ac = 24$, нийлбэр $-10$ → $-4, -6$. Хуваавал:
  $3x^2 - 4x - 6x + 8 = x(3x - 4) - 2(3x - 4) = (3x - 4)(x - 2)$. $x = 1$ дээр
  шалгавал: $3 - 10 + 8 = 1$ бөгөөд $(-1)(-1) = 1$. ✓
- `al74-we2` — **statement:** Гүйцэд задлаарай: $50x^2 - 8$ ба $4x^2 + 12x + 9$.
  **solution:** $50x^2 - 8 = 2(25x^2 - 4) = 2(5x + 2)(5x - 2)$ — эхлээд ХИЕХ,
  дараа нь квадратын ялгавар. $4x^2 + 12x + 9$ дээр хоёр үзүүр нь квадрат
  ($2x$, 3), дунд нь $2(2x)(3) = 12x$ ✓ — бүтэн квадрат: $(2x + 3)^2$.

**commonMistakes**

- **text:** Квадратуудын нийлбэрийг «задлах»: $x^2 + 16 = (x + 4)(x - 4)$ эсвэл
  $(x+4)^2$.
  **correction:** Буцаан задлах нь хоёуланг нь устгана:
  $(x+4)(x-4) = x^2 - 16$; $(x+4)^2 = x^2 + 8x + 16$. Квадратуудын нийлбэр
  бодит тоон дээр задрахгүй.
- **text:** Зөвхөн үзүүрийг хараад бүтэн квадрат гэж зарлах:
  $x^2 + 7x + 25 = (x+5)^2$.
  **correction:** Дунд гишүүн яг $2ab = 10x$ байх ёстой, $7x$ биш. Үзүүрүүд нь
  квадрат байх нь зайлшгүй нөхцөл ч хангалттай нөхцөл биш — дундыг нь үргэлж
  нягтлаарай.

**tryIt**

- `al74-t1` — $2x^2 + 11x + 12$-ийг задлаарай.

## TEST YOURSELF

- `al7-ty-1` — Үржүүлээрэй: $(2x - 3)(x^2 + 4x - 1)$.
  **solution:** $2x^3 + 8x^2 - 2x - 3x^2 - 12x + 3 = 2x^3 + 5x^2 - 14x + 3$.

- `al7-ty-2` — $(3x - 5)^2$-ийг задлаад, $103^2$-ийг толгойдоо бодоорой.
  **solution:** $9x^2 - 30x + 25$; $103^2 = (100 + 3)^2 = 10000 + 600 + 9 = 10609$.
- `al7-ty-3` — $x^2 - 13x + 40$-ийг задлаарай.
