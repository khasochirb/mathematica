## Lesson 1 — Логарифм гэж юу вэ (`meet-logarithms`)

**concreteComparison**

Та $2^5 = 32$-ыг урагшаа мэднэ: «хоёрын тавдугаар зэрэг хэд вэ?» **Логарифм**
үүнийг ухраан асууна: «$2$-ыг ЯМАР зэрэгт дэвшүүлбэл $32$ болох вэ?», бичвэл
$\log_2 32 = 5$. Таны мэдэх илтгэгчийн баримт бүр нууцаараа хоёр баримт
байдаг бөгөөд логарифм нь банк, биологич, газар хөдлөл судлаачдын үнэндээ
асуудаг асуултад хариулдаг тэр нэг нь юм: хэр удаан, хэдэн дахин, хэр хүчтэй?

**objective**

Логарифмыг «ямар илтгэгч вэ?» гэсэн асуулт болгон унших, бичих, мөн
$b^y = x$ ба $\log_b x = y$ хоёрын хооронд чөлөөтэй хөрвүүлэх.

**concept**

1. **Тодорхойлолт**: $\log_b x = y$ гэдэг нь яг $b^y = x$ гэсэн үг. Логарифм
   бол ИЛТГЭГЧ: $2^5 = 32$ учраас $\log_2 32 = 5$.

2. $\log_2 32$-ыг асуулт болгон чангаар уншаарай: «2-ыг ямар зэрэгт дэвшүүлбэл
   32 гарах вэ?». Логарифмын утга бодох бүр бол илтгэгчийн ан юм.

3. Хоёр хэлбэр нь өөр хувцас өмссөн нэг л баримт: $3^4 = 81 \iff \log_3 81 = 4$.
   Тэдний хооронд хөрвүүлэх нь энэ хичээлийн бүхий л булчин.

4. Гэрийн дүрэм (илтгэгчээс өвлөсөн): $b$ суурь эерэг бөгөөд $\neq 1$ байх
   ёстой, мөн та зөвхөн ЭЕРЭГ тооны логарифмыг авч чадна, учир нь $b^y$ хэзээ ч
   тэг эсвэл сөрөг гаргадаггүй тул «$b$-г ямар зэрэгт дэвшүүлбэл $-8$ болох вэ?»
   гэсэн асуулт хариугүй.

**keyIdea**

log_b x = y ⟺ b^y = x, өөрөөр хэлбэл логарифм нь ӨӨРӨӨ илтгэгч. Зөвхөн эерэг
оролт логарифмтай.

**facts**

| title | latex | explanation |
|---|---|---|
| Тодорхойлолт | `\log_b x = y \iff b^y = x` | Нэг баримт, хоёр хувцас. |
| Асуулт | `\log_2 32 = \text{«2-ыг ямар зэрэгт дэвшүүлбэл 32 вэ?»}` | Логарифм бүр бол илтгэгчийн ан. |

**workedExamples**

- `lg1-we1` — **statement:** $\log_2 32$ ба $\log_3 81$-ийн утгыг олоорой.
  **solution:** $2^5 = 32$ → $5$; $3^4 = 81$ → $4$.
- `lg1-we2` — **statement:** $5^3 = 125$-ыг логарифм хэлбэрт, $\log_4 64 = 3$-г
  илтгэгч хэлбэрт хөрвүүлээрэй.
  **solution:** $\log_5 125 = 3$; мөн $4^3 = 64$.
- `lg1-we3` — **statement:** $x$-ийн хувьд бодоорой: $\log_2 x = 6$.
  **solution:** Илтгэгч хэлбэрт: $x = 2^6 = 64$.

**commonMistakes**

- **text:** $\log_2 32$-ыг $32 \div 2$ эсвэл $2 \times 32$ гэж унших.
  **correction:** Аль нь ч биш, энэ бол ИЛТГЭГЧ: 2-ыг 32 хүртэл өргөх зэрэг.
  16 ч биш, 64 ч биш, $\log_2 32 = 5$.
- **text:** Сөрөг тоо эсвэл тэгийн логарифмыг авах.
  **correction:** $\log_2(-8)$ нь «2-ыг ямар зэрэгт дэвшүүлбэл $-8$ болох вэ?»
  гэж асууж байна, гэтэл ямар ч бодит зэрэг үүнийг хийхгүй ($2^y > 0$ үргэлж).
  Логарифмын оролт эерэг байх ёстой.

**tryIt**

- `lg1-t1` — $\log_5 125$ ба $\log_{10} 1000$-ийн утгыг олоорой.
  **solution:** $3$ ба $3$.
- `lg1-t2` — $\log_3 x = 4$-ийг бодоорой.
  **solution:** $x = 3^4 = 81$.

## Lesson 2 — Логарифмын утга олох (`evaluating-logarithms`)

**concreteComparison**

Кассчин $7 \times 8$-ыг дахин боддоггүй, тэр зүгээр мэднэ. Логарифмд ч мөн адил
үржүүлэхийн хүснэгт шиг мөчүүд бий: $\log_b 1 = 0$ үргэлж, $\log_b b = 1$
үргэлж, бутархай оролт СӨРӨГ гардаг ($\log_2 \tfrac18 = -3$). Онцгой утгуудыг
нэг удаа ачаалчихвал логарифмын ихэнх асуулт шууд уншигдана.

**objective**

Онцгой утгууд дээр (1, суурь өөрөө, суурийн зэрэг ба урвуу зэрэг) логарифмын
утгыг шууд олох, сөрөг ба бутархай хариуг оролцуулан.

**concept**

1. Үргэлж үнэн хоёр зангуу: $\log_b 1 = 0$ ($b^0 = 1$ учраас) ба
   $\log_b b = 1$ ($b^1 = b$ учраас). Ямар ч суурьт, тэр бүрд.

2. Урвуу тоо сөрөг болно: $\log_2 \tfrac18$ нь «2-ыг ямар зэрэгт дэвшүүлбэл
   наймны нэг болох вэ?» гэж асууна, $2^{-3} = \tfrac18$ тул $-3$. 0-ээс 1-ийн
   хоорондох оролт сөрөг логарифмтай.

3. Язгуур бутархай болно: $4^{1/2} = 2$ учраас $\log_4 2 = \tfrac12$;
   $\log_8 2 = \tfrac13$. 10-р ангийн рационал илтгэгч ашгаа өгч байна.

4. **Аравтын логарифм** $\log x$ (суурийг нь бичээгүй) нь 10 суурийг заана,
   мөн арвын зэрэг дээр тэгүүдийг нь л тоолно: $\log 1000 = 3$,
   $\log 0.01 = -2$.

**keyIdea**

Зангуу: log_b 1 = 0, log_b b = 1; урвуу тоо сөрөг, язгуур бутархай; суурьгүй
log нь 10 суурьтай.

**facts**

| title | latex | explanation |
|---|---|---|
| Зангуунууд | `\log_b 1 = 0 \qquad \log_b b = 1` | b⁰ = 1 ба b¹ = b-ээс. |
| Аравтын логарифм | `\log x \text{ нь } \log_{10} x` | Арвын зэрэг дээр тэгүүдийг тоолно. |

**workedExamples**

- `lg2-we1` — **statement:** $\log_7 1$, $\log_7 7$, $\log_7 49$-ийн утгыг
  олоорой.
  **solution:** $0$, $1$, $2$, өөрөөр хэлбэл зангууны шат.
- `lg2-we2` — **statement:** $\log_2 \tfrac{1}{8}$ ба $\log_5 \tfrac{1}{25}$-ийн
  утгыг олоорой.
  **solution:** $2^{-3} = \tfrac18$ → $-3$; $5^{-2} = \tfrac{1}{25}$ → $-2$.
- `lg2-we3` — **statement:** $\log_9 3$ ба $\log 100000$-ийн утгыг олоорой.
  **solution:** $9^{1/2} = 3$ → $\tfrac12$; 10 суурьтай: $10^5$ → $5$.

**commonMistakes**

- **text:** $\log_b 1 = 1$ гэж таах.
  **correction:** Суурь БҮРД $b^0 = 1$ тул $\log_b 1 = 0$. «1 оролт» үргэлж
  тэгээр хариулна, учир нь энэ бол илтгэгчийн эхлэлийн шугам.
- **text:** $\log_2 \tfrac18$-ийг «бутархай учраас тодорхойлогдоогүй» гэх.
  **correction:** Эерэг бутархай бол зүгээр, тэдний логарифм зүгээр л СӨРӨГ
  байна: $\log_2 \tfrac18 = -3$. Зөвхөн тэг ба сөрөг тоо л хилийн гадна.

**tryIt**

- `lg2-t1` — $\log_3 \tfrac19$ ба $\log_{12} 1$-ийн утгыг олоорой.
  **solution:** $-2$ ба $0$.
- `lg2-t2` — $\log_{16} 4$ ба $\log 0.001$-ийн утгыг олоорой.
  **solution:** $16^{1/2} = 4$ → $\tfrac12$; $10^{-3} = 0.001$ → $-3$.

## Lesson 3 — Логарифмын чанар (`log-laws`)

**concreteComparison**

Илтгэгч чанартай байсан: зэргүүдийг үржүүлбэл илтгэгчүүдийг НЭМНЭ. Логарифм
нь ӨӨРӨӨ илтгэгч учраас илтгэгчийн чанар бүр логарифмын сүүдэр тусгана:
$\log(ab) = \log a + \log b$, өөрөөр хэлбэл доод давхрын үржүүлэх нь дээд
давхарт нэмэх болно. Гурван чанар, бүгд өвлөгдсөн, бүгд нэг л ажил хийдэг:
хэцүү үйлдлийг хялбар болгон хувиргана.

**objective**

Үржвэр, ногдвор, зэргийн чанарыг хэрэглэн логарифм илэрхийллийг задлах,
хураах, утгыг нь олох.

**concept**

1. **Үржвэрийн чанар**: $\log_b(xy) = \log_b x + \log_b y$.
   $b^m \cdot b^n = b^{m+n}$-ийн сүүдэр. Шалгалт:
   $\log_2(8 \cdot 4) = \log_2 32 = 5 = 3 + 2$ ✓.

2. **Ногдворын чанар**: $\log_b \tfrac{x}{y} = \log_b x - \log_b y$.
   $b^m / b^n = b^{m-n}$-ийн сүүдэр.

3. **Зэргийн чанар** (ажлын морь): $\log_b(x^n) = n \log_b x$, өөрөөр хэлбэл
   логарифмын ДОТОРХ илтгэгч үржүүлэгч болон урагшаа гарна.
   $(b^m)^n = b^{mn}$-ийн сүүдэр.

4. Хэрэглэх хоёр чиглэл: **задлах**
   ($\log_2 \tfrac{x^3 y}{z} = 3\log_2 x + \log_2 y - \log_2 z$) ба **хураах**
   ($2\log 5 + \log 4 = \log 100 = 2$). Хураах нь муухай нийлбэрийг гэнэт
   бодогдохоор болгодог.

**keyIdea**

Логарифм ×-ийг +, ÷-ийг −, зэргийг үржүүлэгч болгоно, өөрөөр хэлбэл
илтгэгчийн чанарыг доороос нь харсан нь.

**facts**

| title | latex | explanation |
|---|---|---|
| Гурван чанар | `\log xy = \log x + \log y \quad \log \tfrac{x}{y} = \log x - \log y \quad \log x^n = n\log x` | Илтгэгчийн чанараас өвлөсөн. |
| Сэрэмжлүүлэг | `\log(x + y) \neq \log x + \log y` | Логарифмын доторх НИЙЛБЭРийг задлах чанар байхгүй. |

**workedExamples**

- `lg3-we1` — **statement:** $\log_2(8 \cdot 4)$ дээр үржвэрийн чанарыг
  шалгаарай.
  **solution:** $\log_2 32 = 5$ ба $\log_2 8 + \log_2 4 = 3 + 2 = 5$ ✓.
- `lg3-we2` — **statement:** $\log_3 54 - \log_3 2$-ын утгыг олоорой.
  **solution:** Ногдворын чанар: $\log_3 \tfrac{54}{2} = \log_3 27 = 3$.
- `lg3-we3` — **statement:** $2\log 5 + \log 4$-ийн утгыг олоорой (10 суурьтай).
  **solution:** Зэргийн чанараар дотогш: $\log 25 + \log 4 = \log 100 = 2$.

**commonMistakes**

- **text:** Нийлбэрийг задлах: $\log(x+y) = \log x + \log y$.
  **correction:** Үржвэрийн чанар зөвхөн ҮРЖВЭРийг задална. Тоо үүнийг алдаг:
  $\log_2(8+8) = 4$, гэтэл $\log_2 8 + \log_2 8 = 6$. $\log(x+y)$-д ямар ч
  чанар хүрэхгүй.
- **text:** $\log x^n$-ийг $(\log x)^n$ гэж унших.
  **correction:** $\log_2(8^2) = \log_2 64 = 6 = 2\log_2 8$, өөрөөр хэлбэл
  зэрэг нь үржүүлнэ. $(\log_2 8)^2 = 9$: өөр тоо, өөр утга.

**tryIt**

- `lg3-t1` — $\log_2 6 + \log_2 \tfrac{32}{6}$-ын утгыг чанар ашиглан олоорой.
  **solution:** Үржвэр: $\log_2 (6 \cdot \tfrac{32}{6}) = \log_2 32 = 5$.
- `lg3-t2` — $\log_5 \sqrt{5}$-ын утгыг зэргийн чанараар олоорой.
  **solution:** $\log_5 5^{1/2} = \tfrac12$.

## Lesson 4 — Илтгэгч тэгшитгэл бодох (`solving-exponential-equations`)

**concreteComparison**

10-р анги нэг асуултыг өлгөөтэй орхисон: мөнгө $A = 100 \cdot 2^t$-ээр хоёр
дахин нэмэгдэнэ, хэзээ 3200 болох вэ? Та жил бүрээр алхаж ч болно… эсвэл
хоригдсон илтгэгчийг нэг хөдөлгөөнөөр чөлөөлж болно. Логарифм бол яг энэ
цоожинд зориулж хийсэн түлхүүр: $2^t = 32 \to t = \log_2 32 = 5$. Илтгэгч
дотроо хувьсагчтай байх бодлого эцэст нь таах биш, машинаар бодогдлоо.

**objective**

Суурийг тааруулах эсвэл логарифм авах замаар илтгэгч тэгшитгэлийг бодох, мөн
илтгэгчийг эхлээд тусгаарлах.

**concept**

1. **Ижил суурийн арга**: хэрэв хоёр тал нэг суурь өмсөж чадвал илтгэгчүүд нь
   таарах ёстой. $2^{x+1} = 32 = 2^5 \to x + 1 = 5 \to x = 4$.

2. **Логарифмын арга** (үргэлж ажиллана): $b^x = c$-г $x = \log_b c$ гэж дахин
   бичээрэй. $2^x = 32 \to x = \log_2 32 = 5$, өөрөөр хэлбэл тодорхойлолт
   өөрөө бодож байна.

3. **Эхлээд тусгаарлаарай**: $5 \cdot 2^x = 40$-д логарифм авахаас ӨМНӨ 5-д
   хуваагаарай: $2^x = 8 \to x = 3$. Илтгэгч ганцаараа үлдэх ёстой, яг 10-р
   ангийн язгуурт тэгшитгэл дэх язгуур шиг.

4. Хариу бүхэл тоо гарахгүй байсан ч яг нарийн хэвээрээ:
   $2^x = 10 \to x = \log_2 10$ ($2^3 = 8 < 10 < 16$ тул 3-аас бага зэрэг
   дээгүүр). Бүхэл илтгэгчүүдийн хооронд хашиглах нь ямар ч логарифм хариуг
   эрүүл ухаанаар шалгана.

**keyIdea**

Боломжтой бол суурийг тааруул; үгүй бол b^x-ийг тусгаарлаад x = log_b c
хэрэглэ. Хариуг бүхэл зэргүүдийн хооронд хашиглаарай.

**facts**

| title | latex | explanation |
|---|---|---|
| Ижил суурь | `b^m = b^n \Rightarrow m = n` | Нэг суурь → илтгэгчийг тэнцүүлнэ. |
| Түлхүүр | `b^x = c \Rightarrow x = \log_b c` | Тодорхойлолт, бодогч болж ажиллаж байна. |

**workedExamples**

- `lg4-we1` — **statement:** $2^{x+1} = 32$-ыг бодоорой.
  **solution:** $32 = 2^5$: $x + 1 = 5 \to x = 4$. Шалгалт: $2^5 = 32$ ✓.
- `lg4-we2` — **statement:** $5 \cdot 2^x = 40$-ийг бодоорой.
  **solution:** Тусгаарлаарай: $2^x = 8 \to x = 3$. Шалгалт: $5 \cdot 8 = 40$ ✓.
- `lg4-we3` — **statement:** $9^x = 27$-ыг бодоорой (3-аар дамжуулан суурийг
  тааруулаарай).
  **solution:** $(3^2)^x = 3^3 \to 2x = 3 \to x = \tfrac32$. Шалгалт:
  $9^{3/2} = 27$ ✓.

**commonMistakes**

- **text:** Тусгаарлахаас өмнө логарифм авах: $5 \cdot 2^x = 40$-ийн логарифмыг
  гишүүн тус бүрээр авах.
  **correction:** ЭХЛЭЭД 5-д хуваагаарай: $2^x = 8$. (Үржвэрийн логарифмыг
  чанараар авч ч болно, $\log 5 + x\log 2 = \log 40$, гэхдээ эхлээд тусгаарлах
  нь хоёр алхмаар богино бөгөөд алдаанаас хамгаална.)
- **text:** ӨӨР суурьтай илтгэгчүүдийг тэнцүүлэх.
  **correction:** $2^x = 3^x$ нь «$x = x$, үргэлж үнэн» гэж өгөхгүй, учир нь
  $x \neq 0$ үед хоёр тал зөрнө. Ижил суурийн богино зам ИЖИЛ суурь шаардана;
  үгүй бол логарифм.

**tryIt**

- `lg4-t1` — $3^{2x} = 81$-ийг бодоорой.
  **solution:** $81 = 3^4$: $2x = 4 \to x = 2$.
- `lg4-t2` — $4 \cdot 5^x = 500$-ийг бодоорой.
  **solution:** $5^x = 125 \to x = 3$.

## Lesson 5 — Логарифм тэгшитгэл бодох (`solving-log-equations`)

**concreteComparison**

Язгуурт тэгшитгэл танд дадлыг нь заасан: тусгаарла, буцаа, хуурамчийг нь
ШАЛГА. Логарифм тэгшитгэл мөн тэр дадлыг шинэ буцаалттайгаар явуулна:
$\log_2 x = 4$-ийг илтгэгчийн хувцсаар дахин бичвэл ($x = 16$) бараг боллоо.
Логарифм сөрөг оролтыг хүлээж авдаггүй тул хураасан тэгшитгэл анхных нь хэзээ ч
хүлээж авахгүй нэр дэвшигч төрүүлж чадна. Шалгалт эргэж ирлээ, мөн шүдтэй.

**objective**

Логарифм тэгшитгэлийг илтгэгч хэлбэрт хөрвүүлэх (эсвэл доторхыг нь тэнцүүлэх)
замаар бодож, тодорхойлогдох мужаас гадуурх нэр дэвшигчийг хасах.

**concept**

1. **Ганц логарифм**: түүнийг тусгаарлаад хувцсыг нь солиорой.
   $\log_3(x+2) = 2 \to x + 2 = 3^2 \to x = 7$. Шалгалт: $\log_3 9 = 2$ ✓.

2. **Логарифм = логарифм**: хоёр талд ижил суурь → доторх нь тэнцүү.
   $\log_5(2x-1) = \log_5(x+3) \to 2x - 1 = x + 3 \to x = 4$.

3. **Эхлээд хураагаарай**: $\log_2 x + \log_2(x-2) = 3$ →
   $\log_2[x(x-2)] = 3$ → $x^2 - 2x = 8$ → $x = 4$ эсвэл $x = -2$.

4. **Шалгалт хазна**: $x = -2$ нь $\log_2(-2)$ болгож байна, хууль бус оролт.
   Хасаарай: зөвхөн $x = 4$ амьд үлдэнэ. Нэр дэвшигч бүр анхны логарифм бүрийн
   доторхыг ЭЕРЭГ байлгах ёстой.

**keyIdea**

Тусгаарла → илтгэгчийн хувцас (эсвэл доторхыг тэнцүүл). Дараа нь шалга:
логарифм бүрийн доторх эерэг байх ёстой, хуурамч нь хасагдана.

**facts**

| title | latex | explanation |
|---|---|---|
| Буцаалт | `\log_b(\text{зүйл}) = y \Rightarrow \text{зүйл} = b^y` | Хувцас солих нь бодогч болсон нь. |
| Хазалт | `\text{доторх} \le 0 \Rightarrow \text{нэр дэвшигч хасагдана}` | Логарифм тэг, сөрөгийг хэзээ ч хүлээж авахгүй. |

**workedExamples**

- `lg5-we1` — **statement:** $\log_3(x+2) = 2$-ыг бодоорой.
  **solution:** $x + 2 = 3^2 = 9 \to x = 7$. Шалгалт: доторх $= 9 > 0$ ✓.
- `lg5-we2` — **statement:** $\log_5(2x-1) = \log_5(x+3)$-ыг бодоорой.
  **solution:** Доторх нь тэнцүү: $2x - 1 = x + 3 \to x = 4$. Шалгалт: хоёулаа
  $= 7 > 0$ ✓.
- `lg5-we3` — **statement:** $\log_2 x + \log_2(x-2) = 3$-ыг бодоорой.
  **solution:** Хураах: $x(x-2) = 2^3 = 8 \to x^2-2x-8 = 0 \to x = 4$ эсвэл
  $-2$. $-2$-ыг хасна (доторх сөрөг). Хариу: $x = 4$.

**commonMistakes**

- **text:** Хураасны дараа тодорхойлогдох мужийн шалгалтыг алгасах.
  **correction:** Алгебр $x = -2$-ыг дуртайяа гаргана, гэтэл $\log_2(-2)$ утга
  учиргүй. Хоёр язгуур нь ХУРААСАН тэгшитгэлийг бодно; анхныхыг нь зөвхөн
  доторх нь эерэг байгаа нь бодно.
- **text:** $\log_3(x+2) = 2$-ыг $x + 2 = 2^3$ болгон хөрвүүлэх.
  **correction:** СУУРЬ нь суурь хэвээрээ үлдэнэ: $x + 2 = 3^2 = 9$. Суурь,
  хариу хоёрыг сольж тавих нь хувцасны сонгодог эвдрэл.

**tryIt**

- `lg5-t1` — $\log_2(x-3) = 4$-ийг бодоорой.
  **solution:** $x - 3 = 16 \to x = 19$. Доторх $16 > 0$ ✓.
- `lg5-t2` — $\log_7(3x) = \log_7(x+8)$-ыг бодоорой.
  **solution:** $3x = x + 8 \to x = 4$. Доторх нь $12 > 0$ ✓.

## Lesson 6 — Логарифм хэмжүүр (`log-scales`)

**concreteComparison**

7 магнитудын газар хөдлөлт 5-аас «арай дор» биш, тэр $10^2 = 100$ дахин
хүчтэй доргино. Рихтер, децибел, рН бол **логарифм хэмжүүр**: дээшээ алхам бүр
бодит хэмжигдэхүүнийг тогтмол үржүүлэгчээр үржүүлнэ. Эдгээр нь байгалийн
хүрээ утгагүй өргөн учраас оршдог, өөрөөр хэлбэл шуугиж байгаа навчнаас тийрэлтэт
хөдөлгүүр хүртэл сая саяар зөрдөг бөгөөд зөвхөн логарифм л тэр их зөрүүг ээлтэй
0-ээс 120 болгон нугалж чадна.

**objective**

Логарифм хэмжүүрийн хэмжилтийг (Рихтер, децибел, рН) унших, харьцуулах, мөн
хэмжүүрийн ялгаварыг бодит ертөнцийн харьцаа болгон хөрвүүлэх.

**concept**

1. **Дүрэм**: логарифм хэмжүүр дээр заалтын ЯЛГАВАР нь бодит байдал дээрх
   ХАРЬЦАА болно. Рихтер: бүхэл алхам бүр газрын хөдөлгөөнийг ×10 болгох тул
   7 магнитуд 5-тай харьцуулахад $10^{7-5} = 100×$.

2. **Децибел**: дуу чимээний эрчим, 10 дБ = ×10. 90 дБ-ийн тоглолт 60 дБ-ийн
   яриатай харьцуулахад: $10^{(90-60)/10} = 10^3 = 1000×$ эрчим.

3. **рН**: хүчиллэг, доошоо алхам бүр ×10 илүү хүчиллэг. рН 3 ундаа рН 7 устай
   харьцуулахад: $10^{7-3} = 10^4 = 10{,}000×$ илүү хүчиллэг.

4. Логарифм хэмжүүр яагаад байдаг вэ: түүхий хүрээ нь $10^{12}$ ба түүнээс их
   дахин зөрдөг. Шугаман хуваарьт километр урт зураас хэрэгтэй болно; логарифм
   хуваарь ×10 бүрийг нэг алхам болгон нугална. Тэднийг унших нь энэ бүлгийн
   математик өөрөө: дээр нь ялгавар, доор нь харьцаа.

**keyIdea**

Логарифм хэмжүүр харьцааг ялгавар болгоно: алхам бүр нэг × үржүүлэгч. d алхмын
ялгавар нь бодит байдал дээр 10^d (Рихтер, рН; децибел 10-ын алхамтай).

**facts**

| title | latex | explanation |
|---|---|---|
| Дүрэм | `\Delta \text{заалт} = d \Rightarrow \text{харьцаа} = 10^d` | Дээр нь ялгавар, доор нь харьцаа. |
| Хэмжүүрүүд | `\text{Рихтер} \cdot \text{дБ} \cdot \text{рН}` | Газар хөдлөлт, дуу, хүчиллэг, бүгд логарифм. |

**workedExamples**

- `lg6-we1` — **statement:** 7 магнитудын газар хөдлөлт 5 магнитудынхаас хэр
  дахин хүчтэй доргих вэ?
  **solution:** $10^{7-5} = 10^2 = 100$ дахин.
- `lg6-we2` — **statement:** Тоглолт 90 дБ; яриа 60 дБ. Эрчмийн харьцаа нь?
  **solution:** $(90-60)/10 = 3$ арав: $10^3 = 1000×$.

## Notes for Khas

**1. «логарифмын чанар» is the ministry's own phrase, and it comes with its
parent.** А/492 writes «Зэрэг ба логарифмын харилцан хамаарлыг ойлгох,
**логарифмын чанаруудыг** мэдэх, хэрэглэх» — so what the English calls *the log
laws* has a ready-made name. Better still, the standard uses **«зэргийн чанар»**
for the exponent laws, which is exactly the relationship lesson 3 is built on:
the log laws are the exponent laws seen from below. The Mongolian says that
relationship out loud where the English has to explain it.

**One consequence worth your eye.** I named the three laws «**үржвэрийн**
чанар», «**ногдворын** чанар», «**зэргийн** чанар». The third collides by name
with the ministry's «зэргийн чанар» for the *exponent* laws — same two words,
different subject. In context it reads fine («логарифмын зэргийн чанар» is
what the lesson is about) and the collision is arguably the point, since the
one is the shadow of the other. **But if you would rather the power law had a
distinct name, say so** — it is three occurrences in one lesson.

**2. Two calques, and one of them has a false friend in the exam.** Neither
*common logarithm* nor *natural logarithm* is named by А/492 or the dictionary's
a–i range, so both follow the Russian tradition:

- *common log* → **«аравтын логарифм»** (Russian *десятичный*). «аравтын» is
  grounded as **decimal** — the bank writes «аравтын бутархай» ten times.
- *natural log* → **«натурал логарифм»** (Russian *натуральный*). **Here is the
  trap: in the ЭШ bank «натурал» means *natural number*, 29 times** («хэдэн
  натурал шийдтэй вэ?»), never a logarithm.

I used both anyway, because they are the international forms a Mongolian
textbook almost certainly prints and because the collision is only in the
adjective. **If you know the textbooks say something else, this is a
find-and-replace.** Note lesson 2 only needs «аравтын логарифм»; «натурал
логарифм» appears in the topic BLURB's neighbourhood and in
`algebra-2/exponentials-and-logarithms`, the next draft, where $\ln$ is taught —
so a ruling now saves that one too.

**3. Lesson 6's real-world vocabulary is the thinnest in the topic, and it is
not mathematics.** *decibel*, *acidity*, *Richter* all score 0 in every source.
The draft writes **«децибел»** (transliteration), **«хүчиллэг»** and
**«Рихтерийн хэмжүүр»** («хэмжүүр» corpus 21). These are chemistry and
seismology words, not maths words, so А/492's silence is expected rather than
informative — but they appear in a lesson that is 40% real-world context, so a
Mongolian science teacher's eye would be worth more than mine here.

«рН» is kept in Latin script as the international symbol, matching how the
drafts keep HH/HT/TH/TT and point names Latin (the `mn-translation` skill's
rule 2).

**4. Six bare-imperative advisories, judged and kept.** All six are the
lesson's own drill chants, and each matches an English chant beside it:
«Тусгаарла, буцаа, шалга» for "isolate, un-do, check"; «Хураа, бод, ХАС» for
"Condense, solve, REJECT"; «Тусгаарла, тааруул эсвэл логарифм ав, хашиглаж
шалга» for "Isolate, match or log, bracket-check". Turning these into polite
imperatives would make a four-word checklist into a fourteen-word sentence and
lose the thing that makes it memorable. Same judgement as the earlier drafts;
recorded so it moves with review pile 1a.

**5. One gate catch worth recording, because it was mine.** I wrote the piano's
lowest note as «$27{,}5$ герц» — applying the decimal comma **inside** `$...$`,
which is exactly what review pile 2d says is NOT applied. The gate caught it
(the check compares against the English, which writes `27.5`). Reverted to
