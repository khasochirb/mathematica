## Lesson 1 — Хавтгай дээрх зай ба дундаж цэг (`distance-and-midpoint`)

**concreteComparison**

Утасны газрын зураг дээр Сүхбаатарын талбай, Зайсан хоёрыг тэмдэглэхэд хэн ч тэр хоёрын хооронд алхаж хэмжилгүйгээр хэр хол болохыг утас тэр дороо хэлж өгдөг. Утас координатуудыг хасаж, квадрат зэрэгт дэвшүүлж, нэмээд квадрат язгуур авдаг, өөрөөр хэлбэл хэн ч зураагүй тэгш өнцөгт гурвалжинд Пифагорын теоремыг хэрэглэдэг. Цэгүүд координаттай болсон цагт зай бол зүгээр л арифметик.

**objective**

Хоёр цэгийн хоорондох зай (distance between two points) болон хэрчмийн дундаж цэгийг (midpoint) координатаар нь олох, томьёо бүр яагаад ажилладгийг тайлбарлах, мөн тэдгээрээр олон өнцөгтийн периметрийг олох.

**concept**

1. **Зай бол далдалсан Пифагор.** $(x_1, y_1)$ ба $(x_2, y_2)$ цэгийн хооронд тэгш өнцөгт гурвалжны хэвтээ ба босоо катетыг зураарай. Катетуудын урт нь $|x_2 - x_1|$ ба $|y_2 - y_1|$ бөгөөд хоёр цэгийг холбосон хэрчим нь гипотенуз болно: $$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}.$$ Үүнийг зайн томьёо (distance formula) гэдэг. Энэ бол цээжлэх шинэ томьёо биш, катетуудыг нь координатаас бодсон $a^2 + b^2 = c^2$ юм.

2. **Хасах дараалал хамаагүй.** Квадрат зэрэгт дэвшүүлэхэд тэмдэг арилдаг тул $(x_2 - x_1)^2$ ба $(x_1 - x_2)^2$ тэнцүү. Иймд налалтаас (slope) ялгаатай нь цэгүүдийг аль дарааллаар авсан ч зай буруу гарахгүй. Энэ бол жинхэнэ хөнгөвчлөлт.

3. **Дундаж цэг бол дундаж.** Хэрчмийн дундаж цэгийн $x$ координат нь төгсгөлүүдийн $x$ координатын дундаж, $y$ координат нь тэдний $y$ координатын дундаж байна: $$M = \left(\frac{x_1 + x_2}{2}, \ \frac{y_1 + y_2}{2}\right).$$ Үүнийг дундаж цэгийн томьёо (midpoint formula) гэнэ. Дундаж цэг хэвтээ чиглэлд ч, босоо чиглэлд ч яг хагаст нь суудаг бөгөөд координат бүрийг дунджлахад яг ийм цэг гарна.

4. **Дундаж цэг НЭМНЭ, зай ХАСНА.** Урьдчилан сэрэмжлүүлэх ёстой андуурал энэ. Дундаж цэг дунджилдаг тул нэмээд хагаслана. Зай завсрыг хэмждэг тул хасна. Хэрэв таны олсон дундаж цэг төгсгөлийн аль нэгээс цааш гарсан бол нэмэх ёстой газраа хассан байна.

5. **Дундаж цэгээс ухраах нь.** Хэрэв $M$ нь $AB$ хэрчмийн дундаж цэг бөгөөд $A$, $M$ хоёр мэдэгдэж байвал $A$ нь $M$-ээс нэг тийш хэдий хол байна, $B$ нь $M$-ээс нөгөө тийш яг төдий хол байна: $B = (2M_x - A_x, \ 2M_y - A_y)$. Энэ нь дундаж цэгийн томьёог хувиргахад шууд гарна, өөрөөр хэлбэл 1-р бүлгийн үсгэн тэгшитгэлийн ур чадвар.

6. **Координатаас периметр ба талбай.** Олон өнцөгтийн периметр нь талуудын уртын нийлбэр бөгөөд тал бүрийг зайн томьёогоор олно. Хэрэв талууд хэвтээ эсвэл босоо бол талбай олоход амархан. Гурвалжны хувьд ихэнхдээ хэвтээ эсвэл босоо талыг суурь болгон авч, эсрэг оройгоос түүнд татсан перпендикулярын уртыг өндөр болгож болно.

**keyIdea**

Зай бол $\sqrt{(\Delta x)^2 + (\Delta y)^2}$, өөрөөр хэлбэл катетууд дээрх Пифагор. Дундаж цэг бол координат бүрийн дундаж. Зай хасна, дундаж цэг нэмнэ.

**facts**

**workedExamples**

- `im1-u8-l1-we1` — **statement:** $A(2, 3)$ ба $B(7, 15)$ цэгийн хоорондох зайг олоорой.
  **solution:** **Катетуудыг олъё.** Хэвтээ зөрүү $7 - 2 = 5$, босоо зөрүү $15 - 3 = 12$. **Пифагорын теоремыг хэрэглэе.** $$d = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13.$$ **Дараалал хамаагүйг шалгая.** Цэгүүдийг эсрэг дарааллаар авбал $2 - 7 = -5$ ба $3 - 15 = -12$ гарах бөгөөд $\sqrt{(-5)^2 + (-12)^2} = \sqrt{25 + 144} = 13$ ✓, квадрат зэрэгт дэвшүүлэхэд хоёр тэмдэг хоёулаа арилсан. **Хариу боломжийн эсэх.** Гипотенуз хамгийн урт тал тул зай катет бүрээс их, харин тэдний нийлбэрээс бага байх ёстой: $12 < 13 < 17$ ✓
- `im1-u8-l1-we2` — **statement:** $P(-4, 9)$ ба $Q(6, 1)$ цэгийг холбосон хэрчмийн дундаж цэгийг олоод, тэр нь хоёр төгсгөлөөс ижил зайд байгааг шалгаарай.
  **solution:** **Координат бүрийг дунджилъя.** $$M = \left(\frac{-4 + 6}{2}, \ \frac{9 + 1}{2}\right) = \left(\frac{2}{2}, \ \frac{10}{2}\right) = (1, 5).$$ **Зайгаар шалгая.** $M$ цэгээс $P$ цэг хүртэл: $$\sqrt{(1 - (-4))^2 + (5 - 9)^2} = \sqrt{25 + 16} = \sqrt{41}.$$ $M$ цэгээс $Q$ цэг хүртэл: $$\sqrt{(6 - 1)^2 + (1 - 5)^2} = \sqrt{25 + 16} = \sqrt{41}.$$ Тэнцүү ✓, дундаж цэг гэдэг нь угаасаа энэ. **Бүтэн хэрчим.** $PQ = \sqrt{100 + 64} = \sqrt{164} = 2\sqrt{41}$, өөрөөр хэлбэл хагас бүрээс яг хоёр дахин урт ✓
- `im1-u8-l1-we3` — **statement:** $AB$ хэрчмийн дундаж цэг нь $M(3, -2)$, $A$ нь $(-1, 4)$ цэг бол $B$ цэгийг олоорой.
  **solution:** **Дундаж цэгийн томьёог хувиргая.** $M_x = \frac{A_x + B_x}{2}$ гэдгээс: $$B_x = 2M_x - A_x = 2(3) - (-1) = 6 + 1 = 7.$$ $$B_y = 2M_y - A_y = 2(-2) - 4 = -4 - 4 = -8.$$ Иймд $B = (7, -8)$. **Дундаж цэгийг дахин бодож шалгая.** $$\left(\frac{-1 + 7}{2}, \ \frac{4 + (-8)}{2}\right) = \left(\frac{6}{2}, \ \frac{-4}{2}\right) = (3, -2) \ \checkmark$$ **Зөн совингоор.** $A$ нь $M$-ээс $4$ нэгжээр зүүн тийш байгаа тул $B$ нь $M$-ээс $4$ нэгжээр баруун тийш байх ёстой: $3 + 4 = 7$ ✓. Мөн $A$ нь $M$-ээс $6$ нэгжээр дээр байгаа тул $B$ нь $6$ нэгжээр доор байна: $-2 - 6 = -8$ ✓. Томьёо бол энэ бодлыг л бичиж үлдээсэн хэлбэр.
- `im1-u8-l1-we4` — **statement:** $A(0, 0)$, $B(6, 0)$, $C(6, 8)$ оройтой гурвалжны периметр ба талбайг олоорой.
  **solution:** **Талуудын урт.** $$AB = \sqrt{(6-0)^2 + (0-0)^2} = 6 \quad \text{(хэвтээ)}$$ $$BC = \sqrt{(6-6)^2 + (8-0)^2} = 8 \quad \text{(босоо)}$$ $$CA = \sqrt{(6-0)^2 + (8-0)^2} = \sqrt{36 + 64} = \sqrt{100} = 10$$ **Периметр.** $$6 + 8 + 10 = 24.$$ **Талбай.** $AB$ хэвтээ, $BC$ босоо тул тэд $B$ орой дээр тэгш өнцгөөр огтлолцоно. Иймд гурвалжин тэгш өнцөгт бөгөөд хоёр катет нь суурь ба өндөр болно: $$\text{Талбай} = \frac{1}{2}(6)(8) = 24.$$ **Тэгш өнцгийг өөр аргаар батлая.** $AB$ хэрчмийн налалт $0$, $BC$ босоо (налалт нь тодорхойгүй) тул тэд перпендикуляр ✓. Пифагорын теорем ч биелнэ: $6^2 + 8^2 = 100 = 10^2$ ✓ **Анзаарах ёстой санамсаргүй давхцал.** Периметр ч, талбай ч $24$ гарсан боловч нэгж нь өөр: нэг нь урт, нөгөө нь талбай. Тэднийг харьцуулах утгагүй бөгөөд тэнцсэн нь эдгээр тоонуудын санамсаргүй таарал.

**commonMistakes**

- **text:** Зайн томьёоны төгсгөлд квадрат язгуур авахаа мартах.
  **correction:** √(25 + 144) = √169 = 13 болохоос 169 биш. Томьёо эхлээд d²-г бодож өгдөг, харин танд хэрэгтэй нь d.
- **text:** Дундаж цэгийн томьёонд нэмэхийн оронд хасах.
  **correction:** Дундаж цэг ДУНДЖИЛДАГ: координатуудыг нэмээд хагаслана. Хасвал хэрчмээс хол газар цэг гарна.
- **text:** Координатуудын зөрүүний биш, координатуудын өөрсдийнх нь квадратыг нэмэх.
  **correction:** (x₂ − x₁)² + (y₂ − y₁)² байх ёстой, x₂² + y₂² биш. Томьёо ЗАВСАР хэмждэг тул эхлээд зөрүүг олно.
- **text:** Дундаж цэг олохдоо зөвхөн нэг координатыг хагаслах.
  **correction:** Хоёр координатыг хоёуланг нь дунджилна. Зөвхөн нэгийг нь хагасалбал цэг хэрчмээс бүр гадна гарна.

**tryIt**

- `im1-u8-l1-t1` — $(-3, 2)$ ба $(5, 8)$ цэгийн хоорондох зайг олоорой.
  **solution:** Катетууд нь $5 - (-3) = 8$ ба $8 - 2 = 6$ тул $d = \sqrt{64 + 36} = \sqrt{100} = 10$.
- `im1-u8-l1-t2` — $(7, -5)$ ба $(-1, 11)$ цэгийн дундаж цэгийг олоорой.
  **solution:** $$M = \left(\frac{7 + (-1)}{2}, \ \frac{-5 + 11}{2}\right) = \left(\frac{6}{2}, \ \frac{6}{2}\right) = (3, 3).$$
- `im1-u8-l1-t3` — $(1, 1)$, $(9, 1)$, $(9, 7)$, $(1, 7)$ оройтой тэгш өнцөгтийн периметр, талбай, диагоналийн уртыг олоорой.
  **solution:** Өргөн нь $9 - 1 = 8$, өндөр нь $7 - 1 = 6$. Периметр $= 2(8 + 6) = 28$; талбай $= 8 \times 6 = 48$. Диагональ нь $\sqrt{64 + 36} = \sqrt{100} = 10$.

## Lesson 2 — Налалтаар параллель ба перпендикуляр шулууныг таних нь (`parallel-and-perpendicular-lines`)

**concreteComparison**

Хананд хоёр тавиур хадаж байгаа мужаан тэдгээр ижил хазайлттай эсэхийг шалгахдаа ижил хөндлөн зайд тавиур бүр хэр өндөрсөж байгааг харьцуулна. Харин тулгуур нь тэгш өнцөгтэй эсэхийг шалгах нь огт өөр шалгалт. Координатын хавтгай дээр энэ хоёр шалгалт хоёулаа хоёрхон тооны арифметик болно: налалтууд тэнцүү бол параллель; налалтуудын үржвэр $-1$ бол перпендикуляр.

**objective**

Хоёр шулуун параллель, перпендикуляр эсвэл аль нь ч биш болохыг налалтаар нь тогтоох; өгсөн шулуунтай параллель эсвэл перпендикуляр, өгсөн цэгийг дайрсан шулууны тэгшитгэл бичих; мөн эдгээр нөхцөлөөр дөрвөн өнцөгтийг ангилах.

**concept**

1. **Параллель гэдэг нь тэнцүү налалт.** Хэрэв ялгаатай хоёр шулуун яг ижил хурдаар өгсөж байвал тэд хэзээ ч огтлолцохгүй. Энэ бол 5-р бүлгийн ангиллыг нөгөө талаас нь харсан хэрэг. Хэрэв $y$ тэнхлэгтэй огтлолцох цэгүүд нь ч тэнцүү бол шулуунууд параллель биш, давхцана.

2. **Перпендикуляр гэдэг нь налалтуудын үржвэр хасах нэг.** Хэрэв нэг шулуун $k$ налалттай бол түүнтэй тэгш өнцгөөр огтлолцох дурын шулуун $-\frac{1}{k}$ налалттай байна. Үүнийг ЭСРЭГ ТЭМДЭГТЭЙ УРВУУ (negative reciprocal) гэнэ: бутархайг эргүүлээд тэмдгийг нь солино. Энэ хоёр үйлдлийн зөвхөн нэгийг хийх нь энэ сэдвийн хамгийн түгээмэл алдаа.

3. **Тэр үржвэр хаанаас гардаг вэ.** Шулууныг координатын эхийн хувьд $90°$ эргүүлэхэд 7-р бүлгийн эргүүлэлтийн дүрмээр $(a, b)$ чиглэлийн алхам $(-b, a)$ болно. Анхны налалт $\frac{b}{a}$, эргүүлсэн налалт $\frac{a}{-b} = -\frac{a}{b}$ бөгөөд $$\frac{b}{a} \times \left(-\frac{a}{b}\right) = -1.$$ Энэ нөхцөл бол эргүүлэлтийн үр дагавар болохоос хаанаас ч юм гарч ирсэн дүрэм биш.

4. **Хоёр онцгой шулуун.** Хэвтээ шулуун (налалт $0$) ба босоо шулуун (налалт тодорхойгүй) перпендикуляр боловч тэдний налалтыг үржүүлж болохгүй: $0 \times$ тодорхойгүй гэдэг утгагүй. Энэ хосыг томьёогоор биш, харангуутаа таниарай.

5. **Параллель эсвэл перпендикуляр шулууныг бичих нь.** Өгсөн шулууны налалтыг аваад тохируулаарай (параллель бол хэвээр нь, перпендикуляр бол эсрэг тэмдэгтэй урвууг нь), дараа нь өгсөн цэгээр шулуун өнцгийн коэффициенттэй тэгшитгэл (point-slope form) бичээрэй. Хоёр алхам, хоёулаа 4-р бүлгээс.

6. **Координатаар дөрвөн өнцөгтийг ангилах нь.** Дөрвөн талын налалтыг бодоорой. Хэрэв эсрэг орших талуудын хоёр хос хоёулаа тэнцүү налалттай бол параллелограмм. Түүн дээр зэргэлдээ талууд перпендикуляр бол тэгш өнцөгт. Харин зэргэлдээ талуудын УРТ тэнцүү бол ромб; хоёулаа биелбэл квадрат. Ингэснээр дүрсийн тухай асуулт арифметик болж хувирах бөгөөд энэ бүлэг бүхэлдээ яг үүний төлөө.

**keyIdea**

Параллель ⟺ тэнцүү налалт. Перпендикуляр ⟺ налалтууд эсрэг тэмдэгтэй урвуу, үржвэр нь $-1$. Хэвтээ ба босоо шулуун бол үржвэрийн шалгуурт баригдахгүй цорын ганц перпендикуляр хос.

**facts**

| title | latex | explanation |
|---|---|---|
| Параллель | `k_1 = k_2 \ \text{(огтлолцох цэг нь өөр)}` | Ижил хурдаар өгсөх тул зөрүү хэзээ ч хаагдахгүй. Огтлолцох цэг нь ч тэнцүү бол хоёр биш, нэг шулуун. |
| Перпендикуляр | `k_1 \cdot k_2 = -1 \quad \Longleftrightarrow \quad k_2 = -\frac{1}{k_1}` | Бутархайг эргүүлээд БАС тэмдгийг нь солино. Зөвхөн нэгийг нь хийх нь түгээмэл алдаа. |
| Онцгой тохиолдол | `\text{хэвтээ } (k = 0) \perp \text{босоо (тодорхойгүй)}` | Перпендикуляр боловч үржвэрийн шалгуур хэрэглэгдэхгүй: энэ хосыг харангуутаа таниарай. |

**workedExamples**

- `im1-u8-l2-we1` — **statement:** $y = \frac{2}{3}x + 5$ ба $2x - 3y = 12$ шулуунууд параллель, перпендикуляр, эсвэл аль нь ч биш үү?
  **solution:** **Хоёр налалтыг олъё.** Эхнийх нь аль хэдийн $y = kx + b$ хэлбэртэй: $k_1 = \frac{2}{3}$. Хоёр дахийг нь хувиргая: $$2x - 3y = 12 \quad\Longrightarrow\quad -3y = -2x + 12 \quad\Longrightarrow\quad y = \frac{2}{3}x - 4,$$ тэгэхээр $k_2 = \frac{2}{3}$. **Харьцуулъя.** Налалтууд тэнцүү, огтлолцох цэгүүд нь өөр ($5$ ба $-4$) тул шулуунууд **параллель**. **Хэзээ ч огтлолцохгүйг баталгаажуулъя.** $x = 0$ үед тэд $5$ ба $-4$ дээр байх бөгөөд зөрүү нь $9$. $x = 30$ үед $25$ ба $16$ дээр, зөрүү нь дахиад л $9$. Зөрүү тогтмол бол огтлолцол байхгүй ✓ **Перпендикуляр биш.** $\frac{2}{3} \times \frac{2}{3} = \frac{4}{9}$ бөгөөд энэ нь $-1$ биш.
- `im1-u8-l2-we2` — **statement:** $(4, -1)$ цэгийг дайрсан, $y = \frac{3}{5}x + 2$ шулуунд перпендикуляр шулууны тэгшитгэлийг бичээрэй.
  **solution:** **Перпендикуляр налалтыг олъё.** Өгсөн налалт $\frac{3}{5}$ тул эсрэг тэмдэгтэй урвуу нь $$k = -\frac{5}{3}.$$ Бутархайг эргүүлэх БА тэмдгийг солих, хоёр үйлдлийг хоёуланг нь хийнэ. **Үржвэрийг шалгая.** $$\frac{3}{5} \times \left(-\frac{5}{3}\right) = -\frac{15}{15} = -1 \ \checkmark$$ **$(4, -1)$ цэгээр шулуун өнцгийн коэффициенттэй тэгшитгэл бичье.** $$y - (-1) = -\frac{5}{3}(x - 4) \quad\Longrightarrow\quad y + 1 = -\frac{5}{3}x + \frac{20}{3}.$$ $$y = -\frac{5}{3}x + \frac{20}{3} - 1 = -\frac{5}{3}x + \frac{17}{3}.$$ **Цэгийг шалгая.** $x = 4$ үед: $-\frac{20}{3} + \frac{17}{3} = -\frac{3}{3} = -1$ ✓
- `im1-u8-l2-we3` — **statement:** $A(1, 1)$, $B(5, 2)$, $C(6, 6)$, $D(2, 5)$ оройтой дөрвөн өнцөгтийг налалт ба уртаар нь ангилаарай.
  **solution:** **Дөрвөн талын налалт.** $$k_{AB} = \frac{2 - 1}{5 - 1} = \frac{1}{4}, \qquad k_{BC} = \frac{6 - 2}{6 - 5} = 4,$$ $$k_{CD} = \frac{5 - 6}{2 - 6} = \frac{-1}{-4} = \frac{1}{4}, \qquad k_{DA} = \frac{1 - 5}{1 - 2} = \frac{-4}{-1} = 4.$$ **Параллелограмм уу?** $k_{AB} = k_{CD}$ ба $k_{BC} = k_{DA}$: эсрэг орших талуудын хоёр хос хоёулаа параллель тул тийм. **Тэгш өнцөгт үү?** Зэргэлдээ талуудыг шалгая: $k_{AB} \times k_{BC} = \frac{1}{4} \times 4 = 1$, $-1$ биш. Иймд өнцгүүд нь тэгш өнцөг БИШ, тэгэхээр тэгш өнцөгт биш. **Ромб уу?** Зэргэлдээ талуудын уртыг шалгая: $$AB = \sqrt{16 + 1} = \sqrt{17}, \qquad BC = \sqrt{1 + 16} = \sqrt{17}.$$ Тэнцүү ✓, параллелограммын чанараар дөрвөн тал бүгд $\sqrt{17}$. **Дүгнэлт.** Квадрат биш **ромб**: дөрвөн тал тэнцүү, эсрэг орших талууд параллель, харин тэгш өнцөг байхгүй. **Диагоналиар давхар шалгая.** Ромбын диагоналиуд перпендикуляр байдаг. $k_{AC} = \frac{6-1}{6-1} = 1$, $k_{BD} = \frac{5-2}{2-5} = -1$ бөгөөд $1 \times (-1) = -1$ ✓
- `im1-u8-l2-we4` — **statement:** $P(1, 2)$, $Q(5, 4)$, $R(3, 8)$ оройтой гурвалжин тэгш өнцөгт гэдгийг харуулаад, талбайг нь олоорой.
  **solution:** **Гурван налалтыг бодъё.** $$k_{PQ} = \frac{4 - 2}{5 - 1} = \frac{2}{4} = \frac{1}{2},$$ $$k_{QR} = \frac{8 - 4}{3 - 5} = \frac{4}{-2} = -2,$$ $$k_{PR} = \frac{8 - 2}{3 - 1} = \frac{6}{2} = 3.$$ **Хос бүрийг перпендикуляр эсэхээр шалгая.** $$k_{PQ} \cdot k_{QR} = \frac{1}{2} \times (-2) = -1 \ \checkmark$$ Иймд $PQ \perp QR$ бөгөөд тэгш өнцөг нь $Q$ орой дээр. (Бусад хос: $\frac{1}{2} \times 3 = \frac{3}{2}$ ба $-2 \times 3 = -6$, аль нь ч $-1$ биш. Гурвалжин хамгийн ихдээ нэг тэгш өнцөгтэй байх ёстой тул $Q$ цорын ганц тэгш өнцөг гэдэг нь батлагдлаа.) **Талбай.** Тэгш өнцгийн хоёр талд орших катетууд нь суурь ба өндөр болно: $$PQ = \sqrt{16 + 4} = \sqrt{20}, \qquad QR = \sqrt{4 + 16} = \sqrt{20}.$$ $$\text{Талбай} = \frac{1}{2}\sqrt{20} \cdot \sqrt{20} = \frac{1}{2}(20) = 10.$$ **Пифагорын теоремоор шалгая.** Гипотенуз $PR = \sqrt{4 + 36} = \sqrt{40}$ бөгөөд $20 + 20 = 40$ ✓, тэгш өнцгийг өөр аргаар баталлаа. **Нэмэлт.** Катетууд тэнцүү тул энэ бол адил хажуут тэгш өнцөгт гурвалжин.

  **correction:** 2x − 3y = 12 тэгшитгэлийн налалт 2/3 болохоос 2 биш. Эхлээд y-ийг илэрхийлээрэй, 4-р бүлэгт хэлсэнтэй яг ижил.

- `im1-u8-l2-t1` — $y = -4x + 1$ ба $y = \frac{1}{4}x - 7$ шулуунууд параллель, перпендикуляр, эсвэл аль нь ч биш үү?

- `im1-u8-l2-t3` — $(6, 3)$ цэгийг дайрсан, $y = 2x + 9$ шулуунд перпендикуляр шулууны тэгшитгэлийг бичээрэй.

## Lesson 3 — Хэрчмийг харьцаагаар хуваах нь (`partitioning-a-segment`)

**concreteComparison**

Сумын төвөөс аймгийн төв хүртэл зам тавигдсан бөгөөд замын гуравны нэгт шатахуун түгээх станц барихаар болжээ. Яг хаана вэ? Дундаж цэг дээр ч биш, таамгаар ч биш: хэрчмийг өгсөн харьцаагаар хуваах (partitioning a segment) цэг өөрийн томьёотой бөгөөд тэр нь таны мэдэх дундаж цэгийг ерөнхийлсөн хэлбэр юм.

**objective**

Чиглэлтэй хэрчмийг (directed segment) өгсөн харьцаагаар хуваах цэгийг олох, дундаж цэгийг $1:1$ гэсэн онцгой тохиолдол гэж таних, харьцааг бүхэл хэрчмийн хэсгүүд гэж зөв ойлгох.

**concept**

1. **Нэг төгсгөлөөс замын тодорхой хэсгийг туулах нь.** $A$ цэгээс $B$ цэг хүртэлх замын $t$ хэсэгт орших $P$ цэгийг олохын тулд нийт өөрчлөлтийн $t$ хэсгийг $A$-ийн координат дээр нэмээрэй: $$P = \big(x_A + t(x_B - x_A), \ \ y_A + t(y_B - y_A)\big).$$ Зөрүүнүүд бол бүтэн зам, $t$ бол түүнээс хэдийг нь туулахыг заана.

2. **Харьцааг бутархай болгох нь.** $A$-аас $B$ рүү $m : n$ харьцаа гэдэг нь хэрчмийг $m + n$ тэнцүү хэсэгт хуваахад $P$ цэгээс өмнө $m$ хэсэг байна гэсэн үг. Иймд $t = \frac{m}{m + n}$. $1 : 3$ харьцаа $t = \frac{1}{4}$ өгнө: замын дөрөвний нэг, гуравны нэг БИШ. $1:3$ харьцааг «гуравны нэг» гэж унших нь энд хамгийн түгээмэл алдаа.

3. **Дундаж цэг бол хагасын тохиолдол.** $t = \frac{1}{2}$ гэж орлуулбал $x_A + \frac{1}{2}(x_B - x_A) = \frac{x_A + x_B}{2}$, өөрөөр хэлбэл дундаж цэгийн томьёо дахин гарч ирнэ. Өмнөх хичээлийн бүх зүйл бол энэ хичээлийн $1:1$ гэсэн онцгой тохиолдол юм.

4. **Чиглэл чухал.** Хэрчим энд ЧИГЛЭЛТЭЙ: $A$-аас $B$ рүү $1:2$ харьцаа, $B$-ээс $A$ рүү $1:2$ харьцаа хоёр өөр цэг өгнө. Бодлого аль төгсгөлөөс эхэлж байгааг уншаад, бодолтоо тэндээс эхлүүлээрэй. Үүнийг эсрэгээр нь хийвэл эсрэг чиглэлийн замд зөв байх цэг гарна.

5. **Хоёр хэсгийг хэмжиж шалгах нь.** $P$ цэгийг олсныхоо дараа $AP$ ба $PB$-г зайн томьёогоор бодоод, тэдний харьцаа асуусантай таарч байгааг шалгаарай. Энэ шалгалт хоёрхон мөр шаардах бөгөөд бутархайн алдаа, чиглэлийн алдаа хоёуланг нь барина.

**keyIdea**

Координат бүрээр $P = A + t(B - A)$ бөгөөд $A$-аас $B$ рүү $m:n$ харьцааны хувьд $t = \frac{m}{m+n}$. Дундаж цэг бол $t = \frac{1}{2}$.

**facts**

| title | latex | explanation |
|---|---|---|
| Хуваах цэгийн томьёо | `P = \big(x_A + t(x_B - x_A), \ y_A + t(y_B - y_A)\big)` | $A$ цэгээс эхэлж нийт өөрчлөлтийн $t$ хэсгийг авна. Координат бүрд тусад нь хэрэглэнэ. |
| Харьцаанаас бутархай | `m : n \ \Longrightarrow\ t = \frac{m}{m + n}` | Хэрчим $m + n$ хэсэгт хуваагдана. $1:3$ харьцаа $t = 1/4$ буюу дөрөвний нэгийг өгнө, гуравны нэгийг биш. |
| Дундаж цэг бол онцгой тохиолдол | `t = \tfrac{1}{2} \ \Longrightarrow\ P = \left(\tfrac{x_A + x_B}{2}, \tfrac{y_A + y_B}{2}\right)` | Хагасыг орлуулахад дундаж цэгийн томьёо яг гарна. |

**workedExamples**

- `im1-u8-l3-we1` — **statement:** $A(2, 3)$ цэгээс $B(11, 15)$ цэг хүртэлх замын гуравны нэгт орших цэгийг олоорой.
  **solution:** **Бутархай.** «Замын гуравны нэг» гэдэг нь шууд $t = \frac{1}{3}$. **Нийт өөрчлөлт.** $x_B - x_A = 11 - 2 = 9$ ба $y_B - y_A = 15 - 3 = 12$. **Эхний цэгээс эхэлж өөрчлөлт бүрийн гуравны нэгийг авъя.** $$x_P = 2 + \frac{1}{3}(9) = 2 + 3 = 5,$$ $$y_P = 3 + \frac{1}{3}(12) = 3 + 4 = 7.$$ Иймд $P = (5, 7)$. **Зайгаар шалгая.** $AP = \sqrt{9 + 16} = 5$ ба $AB = \sqrt{81 + 144} = \sqrt{225} = 15$. Үнэхээр $\frac{AP}{AB} = \frac{5}{15} = \frac{1}{3}$ ✓ **Үлдсэн хэсэг.** $PB = \sqrt{36 + 64} = 10$ тул $AP : PB = 5 : 10 = 1 : 2$: өмнө нь нэг хэсэг, хойно нь хоёр хэсэг. «Замын гуравны нэг» гэдгийн утга яг энэ.
- `im1-u8-l3-we2` — **statement:** $A(-3, 2)$ цэгээс $B(9, 8)$ цэг хүртэлх хэрчмийг $1 : 3$ харьцаагаар хуваах $P$ цэгийг олоорой.
  **solution:** **Харьцааг хөрвүүлье.** Хэрчим $1 + 3 = 4$ тэнцүү хэсэгт хуваагдах бөгөөд $P$ цэгээс өмнө $1$ хэсэг байна: $$t = \frac{1}{1 + 3} = \frac{1}{4}.$$ Замын ДӨРӨВНИЙ нэг, гуравны нэг биш. Харьцааны тэмдэглэгээ яг энэ алхамд төөрөгдүүлэхийг «урьдаг». **Нийт өөрчлөлт.** $9 - (-3) = 12$ ба $8 - 2 = 6$. **Томьёог хэрэглэе.** $$x_P = -3 + \frac{1}{4}(12) = -3 + 3 = 0,$$ $y_P = 2 + \frac{1}{4}(6) = 2 + 1.5 = 3.5.$ Иймд $P = (0, 3.5)$. **Хэсгүүдийн харьцааг шалгая.** $AP = \sqrt{9 + 2.25} = \sqrt{11.25}$ ба $PB = \sqrt{81 + 20.25} = \sqrt{101.25}$. Тэгвэл $\frac{PB}{AP} = \sqrt{\frac{101.25}{11.25}} = \sqrt{9} = 3,$ тэгэхээр $AP : PB = 1 : 3$ ✓, яг шаардсанаар.
- `im1-u8-l3-we3` — **statement:** $A(1, 6)$ цэгээс $B(13, -2)$ цэг хүртэлх хэрчмийг $3 : 1$ харьцаагаар хуваах цэгийг олоод, $1 : 3$ харьцааны цэгтэй харьцуулаарай.
  **solution:** **Гурав ба нэгийн хуваалт.** Дөрвөн хэсэг, $P$ цэгээс өмнө гурав нь: $$t = \frac{3}{3 + 1} = \frac{3}{4}.$$ Өөрчлөлт нь $13 - 1 = 12$ ба $-2 - 6 = -8$. $$x_P = 1 + \frac{3}{4}(12) = 1 + 9 = 10, \qquad y_P = 6 + \frac{3}{4}(-8) = 6 - 6 = 0.$$ Иймд $P = (10, 0)$: замын дөрөвний гурав, $B$ цэгт ойрхон. **Нэг ба гурвын хуваалт.** Одоо $t = \frac{1}{4}$: $$x = 1 + 3 = 4, \qquad y = 6 - 2 = 4,$$ тэгэхээр $(4, 4)$: замын дөрөвний нэг, $A$ цэгт ойрхон. **Харьцуулалт.** $3 : 1$ ба $1 : 3$ харьцаа нь дундаж цэгийн хоёр талд орших үнэхээр өөр хоёр цэг өгнө. Дундаж цэг нь өөрөө $t = \frac{1}{2}$ үед $(7, 2)$ бөгөөд хоёр хариу түүний хувьд тэгш хэмтэй байрлана ✓ **Аль тал руу гарахыг урьдчилан мэдэх нь.** Харьцааны ЭХНИЙ тоо бол эхлэх цэгт хамгийн ойр хэсэг. Эхний тоо их байвал $P$ цэг $B$ руу түлхэгдэнэ; бага байвал $A$ цэгийн ойролцоо үлдэнэ.
- `im1-u8-l3-we4` — **statement:** Ус дамжуулах хоолой $(0, 0)$ цэг дэх худгийн насосноос $(20, 15)$ цэг дэх усан сав хүртэл тавигдсан. Хоолойн уртын $60\%$-д хавхлага суулгах хэрэгтэй. Хавхлагын байрлал ба насос хүртэлх зайг олоорой.
  **solution:** **Бутархай.** $60\% = 0.6$ тул $t = \frac{3}{5}$. **Томьёог хэрэглэе.** Нийт өөрчлөлт нь $20$ ба $15$: $$x = 0 + \frac{3}{5}(20) = 12, \qquad y = 0 + \frac{3}{5}(15) = 9.$$ Хавхлага $(12, 9)$ цэгт байрлана. **Насос хүртэлх зай.** $$\sqrt{12^2 + 9^2} = \sqrt{144 + 81} = \sqrt{225} = 15.$$ **Бүтэн хоолойтой харьцуулж шалгая.** $$\text{нийт урт} = \sqrt{400 + 225} = \sqrt{625} = 25.$$ Мөн $\frac{15}{25} = \frac{3}{5} = 60\%$ ✓, хавхлага үнэхээр хоолойн жаран хувьд байна. **Энэ шалгалт яагаад чухал вэ.** Инженерт ЗАЙгаар жаран хувь хэрэгтэй бөгөөд томьёо яг үүнийг өгнө, учир нь хоёр координатын өөрчлөлтийн $60\%$-ийг авахад бүхэл шилжилт $60\%$ болж багасна. Хэрэв зөвхөн нэг координатын $60\%$-ийг авсан бол цэг хоолойноос бүр гадна гарах байсан.

**commonMistakes**

- **text:** 1:3 харьцааг замын гуравны нэг гэж унших.
  **correction:** 1:3 харьцаа хэрчмийг 1 + 3 = 4 хэсэгт хуваадаг тул замын ДӨРӨВНИЙ нэг. Хуваарь нь хоёр дахь тоо биш, НИЙЛБЭР.
- **text:** Буруу төгсгөлөөс эхлэх.
  **correction:** Хэрчим чиглэлтэй. A-аас B рүү харьцаа B-ээс A рүү харьцаатай ижил биш: бодлого аль төгсгөлөөс эхэлж байгааг уншаад, бодолтоо тэндээс эхлүүлээрэй.
- **text:** Зөрүүнүүдийн оронд координатуудыг t-ээр үржүүлэх.
  **correction:** x_A + t(x_B − x_A) байх ёстой, t·x_B биш. Бутархайг ӨӨРЧЛӨЛТӨД хэрэглээд, дараа нь эхлэх координат дээр нэмнэ.
- **text:** Бутархайг зөвхөн нэг координатад хэрэглэх.
  **correction:** Хоёр координат хоёулаа өөрийн өөрчлөлтийн ижил бутархайг авна. Зөвхөн нэгийг нь өөрчилбөл цэг хэрчмээс бүр гадна гарна.

## Lesson 4 — Координатаар геометрийн баримт батлах нь (`coordinate-proof`)

**concreteComparison**

«Тэгш өнцөгтийн диагоналиуд тэнцүү» гэх мэт өгүүлбэрийг нэг тэгш өнцөгт зураад хэмжиж шалгаж болох ч энэ нь дараагийн тэгш өнцөгтийн талаар юу ч батлахгүй. Харин түүнийг тоо биш үсгээр тэмдэглэж тэнхлэгүүд дээр байрлуулбал ганц тооцоо бүх тэгш өнцөгтийн асуудлыг нэг дор шийднэ. Координатын баталгаа (coordinate proof) танд яг үүнийг өгдөг.

**objective**

Дүрсийг координатын тэнхлэгүүд дээр байрлуулж, зай, дундаж цэг, налалтын томьёогоор тооцоолон энгийн геометрийн теоремыг батлах, мөн бүх тохиолдлыг хамрахын тулд хувьсагч ашиглах.

**concept**

1. **Дүрсээ тохиромжтой байрлуулаарай.** Дүрсийг тэнхлэгүүд дээр хаана ч байрлуулж болох тул алгебрыг хамгийн хялбар болгох байрлалыг сонгоорой: нэг оройг координатын эх дээр, нэг талыг $x$ тэнхлэгийн дагуу. Энэ бол хууран мэхлэлт биш. Өгүүлбэр дүрсийн тухай бөгөөд 7-р бүлэгт тогтоосноор хатуу биеийн хөдөлгөөн (rigid motion), өөрөөр хэлбэл дүрсийг гулсуулах, эргүүлэх нь түүнийг өөрчлөхгүй.

2. **Тоо биш, үсэг хэрэглээрэй.** $(0,0)$, $(6,0)$, $(6,4)$, $(0,4)$ оройтой тэгш өнцөгт нэг тэгш өнцөгтийн тухай нэг баримтыг л батална. $(0,0)$, $(a,0)$, $(a,b)$, $(0,b)$ оройтой бол БҮХ тэгш өнцөгтийн тухай нэг дор батална, учир нь $a$ ба $b$ дурын эерэг уртыг илэрхийлнэ. Бүх утга учир нь энэ ерөнхий байдалд оршино.

3. **Өгүүлбэрт тохирох багажийг сонгоорой.** Урт тэнцүү юу? Зайн томьёо. Хоёр тэнцүү хуваах, эсвэл дундаж цэг үү? Дундаж цэгийн томьёо. Параллель эсвэл перпендикуляр уу? Налалт. Координатын баталгааны ихэнх нь эдгээр гурвын нэгийг нэг хоёр удаа хэрэглэдэг.

4. **Жишээ загвар.** Тэгш өнцөгтийн диагоналиуд тэнцүүг батлахын тулд: түүнийг $(0,0), (a,0), (a,b), (0,b)$ дээр байрлуулна; хоёр диагоналийг зайн томьёогоор бодно; хоёулаа $\sqrt{a^2 + b^2}$ гэдгийг ажиглана; дүгнэнэ. Дөрвөн мөр, бүх тэгш өнцөгтөд хүчинтэй.

5. **Алгебр юуг харуулсныг хэлээрэй.** Координатын баталгаа эцсийн илэрхийллээр биш, өгүүлбэрээр дуусдаг. «Хоёр диагональ хоёулаа $\sqrt{a^2 + b^2}$ урттай тул дурын тэгш өнцөгтөд тэд тэнцүү» гэдэг нь баталгаа өөрөө бөгөөд дээрх алгебр бол түүний нотлох баримт.

6. **Хязгаараа мэдээрэй.** Координатын баталгаа координатаар байрлуулж болох дүрс шаарддаг бөгөөд урт, дундаж цэг, чиглэлийн тухай өгүүлбэрт хамгийн сайн ажилладаг. Тойрог, эсвэл тэгш өнцгөөс бусад өнцгийн хэмжээний тухай өгүүлбэрийг хожмын хичээлийн координатгүй (синтетик) аргаар батлах нь ихэвчлэн цэвэрхэн байдаг.

**keyIdea**

Дүрсээ тохиромжтой байрлуулаад, баталгаа бүх тохиолдлыг хамрахаар ҮСГЭЭР тэмдэглэж, зай, дундаж цэг эсвэл налалтаар тооцоолоод, юу харуулснаа өгүүлбэрээр хэлж дуусгаарай.

**facts**

| title | latex | explanation |
|---|---|---|
| Тохиромжтой байрлал | `\text{нэг орой } (0,0) \text{ дээр}, \ \text{нэг тал } x \text{ тэнхлэгийн дагуу}` | Тэгүүд алгебрыг богиносгоно. Хатуу биеийн хөдөлгөөн ямар ч урт, өнцгийг өөрчлөхгүй тул өгүүлбэрт нөлөөлөхгүй. |
| Тоо биш, үсэг | `(0,0), (a,0), (a,b), (0,b) \ \text{: бүх тэгш өнцөгт нэг дор}` | Тодорхой тоо нэг тохиолдлыг батална. Хувьсагч бүгдийг нь батална. |
| Өгүүлбэрт тохирох багаж | `\text{урт} \to \text{зай}; \ \text{хагаслах} \to \text{дундаж цэг}; \ \text{чиглэл} \to \text{налалт}` | Теорем юу гэж байгаад томьёогоо тааруулна. |

**workedExamples**

- `im1-u8-l4-we1` — **statement:** Дурын тэгш өнцөгтийн диагоналиуд тэнцүү урттай гэдгийг батлаарай.
  **solution:** **Тэгш өнцөгтийг байрлуулъя.** Нэг оройг координатын эх дээр, хоёр талыг тэнхлэгүүдийн дагуу тавья: $$A(0, 0), \quad B(a, 0), \quad C(a, b), \quad D(0, b),$$ энд $a > 0$, $b > 0$. Зэргэлдээ талууд нь перпендикуляр тэнхлэгүүд дээр орших тул ийм дурын эерэг $a$, $b$ тоонуудын хувьд энэ дүрс тэгш өнцөгт байна. **Диагоналиудыг бодъё.** $$AC = \sqrt{(a - 0)^2 + (b - 0)^2} = \sqrt{a^2 + b^2},$$ $$BD = \sqrt{(0 - a)^2 + (b - 0)^2} = \sqrt{a^2 + b^2}.$$ **Дүгнэлт.** Хоёр диагональ хоёулаа $\sqrt{a^2 + b^2}$ урттай тул $AC = BD$. $a$ ба $b$ нь дурын эерэг тоо байсан тул энэ **бүх** тэгш өнцөгтөд үнэн. **Тодорхой тохиолдлоор туршъя.** $a = 6$, $b = 8$ гэвэл хоёр диагональ хоёулаа $\sqrt{36 + 64} = 10$ ✓. Гэхдээ үүнийг жишээ биш, баталгаа болгож байгаа зүйл нь үсгүүд.
- `im1-u8-l4-we2` — **statement:** Дурын параллелограммын диагоналиуд бие биеэ хоёр тэнцүү хуваадаг гэдгийг батлаарай.
  **solution:** **Параллелограммыг байрлуулъя.** Нэг оройг координатын эх дээр, нэг талыг $x$ тэнхлэгийн дагуу тавья: $$A(0, 0), \quad B(a, 0), \quad C(a + c, \ d), \quad D(c, d).$$ Энэ үнэхээр параллелограмм: $\vec{AB}$ ба $\vec{DC}$ хоёулаа $(a, 0)$, $\vec{AD}$ ба $\vec{BC}$ хоёулаа $(c, d)$, өөрөөр хэлбэл эсрэг орших талууд тэнцүү бөгөөд параллель. **Диагональ бүрийн дундаж цэгийг олъё.** $(0,0)$ цэгээс $(a + c, d)$ цэг хүртэлх $AC$ диагональ: $$M_1 = \left(\frac{0 + a + c}{2}, \ \frac{0 + d}{2}\right) = \left(\frac{a + c}{2}, \ \frac{d}{2}\right).$$ $(a, 0)$ цэгээс $(c, d)$ цэг хүртэлх $BD$ диагональ: $$M_2 = \left(\frac{a + c}{2}, \ \frac{0 + d}{2}\right) = \left(\frac{a + c}{2}, \ \frac{d}{2}\right).$$ **Дүгнэлт.** $M_1 = M_2$: хоёр диагональ нэг ижил дундаж цэгтэй, бие биеэ хоёр тэнцүү хуваана гэдэг нь яг энэ. Энэ нь $a$, $c$, $d$ тоонуудын дурын сонголтод, иймд бүх параллелограммд үнэн. **Тоогоор шалгая.** $a = 6$, $c = 2$, $d = 4$ үед оройнууд $(0,0), (6,0), (8,4), (2,4)$. $AC$ диагоналийн дундаж цэг: $(4, 2)$. $BD$ диагоналийн дундаж цэг: $\left(\frac{6+2}{2}, \frac{0+4}{2}\right) = (4, 2)$ ✓, нэг ижил цэг.
- `im1-u8-l4-we3` — **statement:** Гурвалжны хоёр талын дундаж цэгүүдийг холбосон хэрчим гурав дахь талтайгаа параллель бөгөөд түүний хагас урттай гэдгийг батлаарай.
  **solution:** **Гурвалжныг байрлуулъя.** Нэг оройг координатын эх дээр, нэг талыг $x$ тэнхлэгийн дагуу тавья: $$A(0, 0), \quad B(2a, 0), \quad C(2b, 2c).$$ $a$, $b$, $c$ тоонуудын оронд $2a$, $2b$, $2c$ авах нь дундаж цэгүүдийг бутархайгүй болгодог түгээмэл арга бөгөөд дурын гурвалжныг ингэж бичиж болох тул бүрэн хууль ёсны. **Хоёр дундаж цэгийг олъё.** $AC$ талын дундаж цэг: $$M = \left(\frac{0 + 2b}{2}, \ \frac{0 + 2c}{2}\right) = (b, c).$$ $BC$ талын дундаж цэг: $$N = \left(\frac{2a + 2b}{2}, \ \frac{0 + 2c}{2}\right) = (a + b, \ c).$$ **Параллель үү?** $MN$ хэрчим $(b, c)$ цэгээс $(a+b, c)$ цэг хүртэл үргэлжлэх бөгөөд хоёр цэг хоёулаа $y = c$ тул $MN$ хэвтээ. $AB$ нь $(0,0)$ цэгээс $(2a, 0)$ цэг хүртэл үргэлжлэх бөгөөд мөн хэвтээ. Хоёр хэвтээ хэрчим параллель ✓ **Хагас урттай юу?** $$MN = |(a + b) - b| = |a|, \qquad AB = |2a - 0| = |2a|.$$ Тэгэхээр $MN = \frac{1}{2}AB$ ✓ **Дүгнэлт.** Дундаж шугам (midsegment) гурав дахь талтайгаа параллель бөгөөд яг түүний хагас урттай. $a$, $b$, $c$ дурын байсан тул энэ бүх гурвалжинд үнэн. **Тоогоор шалгая.** $a = 3$, $b = 1$, $c = 4$ үед гурвалжин $(0,0), (6,0), (2,8)$; дундаж цэгүүд $(1,4)$ ба $(4,4)$; $MN = 3$, $AB = 6$ ✓
