# Geometry strand — shared terminology

**Built 17 Sep 2026, before drafting any geometry topic.** Thirteen topics,
roughly 500 items, cite this file instead of re-deciding the same words
thirteen times. Each draft's own Terminology table lists only what it adds.

Authority order per `docs/MONGOLIAN.md`: ministry order А/492 → the printed
dictionary → the shipped corpus.

---

## The headline: geometry is far less grounded than algebra was

**Twenty of the seventy-five terms this strand needs are in the dictionary's
a–i range. Fifty-five are not** — and they are exactly the words Khas's own
CLAUDE.md lists as not yet covered: *line, midpoint, parallel, perpendicular,
polygon, prime, radius, ratio, rectangle, root, square, tangent, triangle,
vertex, volume*.

Two other things make this strand thinner than algebra:

1. **А/492 is a grade 10–12 standard.** Plane geometry (congruence, angle
   pairs, proof) is taught in grades 7–9, so the ministry is simply silent on
   most of it. It does cover coordinate geometry and trigonometry, and there
   it is decisive.
2. **The shipped grade 6–8 mirrors carry almost no plane-geometry
   vocabulary.** «биссектрис», «дундаж цэг», «тэнцүү гурвалжин» and
   «конгруэнт» are all **zero** in them. What did ship is the measurement
   vocabulary: «гадаргуугийн талбай» 22, «призм» 16, «масштабын коэффициент»
   12, «тойргийн урт» 12, «дэлгээс» 11.

The ЭШ question bank is the strongest source here, and it is strong:
«гурвалжин» 184, «тойрог» 120, «радиус» 125, «шүргэгч» 80, «пирамид» 75,
«параллелограмм» 60, «периметр» 59, «трапец» 54, «катет» 38.

**Practical consequence:** the geometry drafts will flag more coined terms
than the algebra ones did, and the flags will cluster in proof language and
angle-pair names. That is a property of the sources, not of the drafting.

## 2. Where the dictionary overrides the `mn-translation` skill glossary

The skill's geometry glossary calls itself *"canonical — do not improvise
synonyms"*. Three of its angle-pair entries **never actually shipped**, and
the dictionary prints something different:

| English | skill glossary | shipped uses | dictionary | adopted |
|---|---|---|---|---|
| complementary angles | нэмэлт өнцөг | **1** | **гүйцээлт хоёр өнцөг** | dictionary |
| adjacent angles | зэргэлдээ өнцөг | **0** | **залгаа хоёр өнцөг** | dictionary |
| supplementary angles | дүүргэгч өнцөг | **0** | *not in a–i* | skill's, flagged |
| vertical angles | эсрэг өнцөг | **0** | *not in a–i* | skill's, flagged |
| circumference | тойргийн урт | 12 | тойргийн урт | agree |

So the rule the skill states for itself does not survive contact with the
dictionary on two entries. Reported rather than decided quietly: the skill
file is Khas's to amend, and «гүйцээлт» versus «нэмэлт» is the kind of thing a
teacher will have an opinion about. **The drafts use the dictionary's wording**
per the authority order, and say so where they use it.

## 3. Ungrounded — flagged in every draft that uses them

None of these is in А/492, the dictionary's a–i range, or the corpus. Each is
built from grounded parts and defined on first use.

| English | proposed | built from |
|---|---|---|
| ray | **цацраг** | corpus 10, but as a *light* ray; the geometric sense is untested |
| supplementary angles | **дүүргэгч өнцөг** | the skill glossary, 0 shipped |
| vertical angles | **эсрэг өнцөг** | the skill glossary, 0 shipped |
| perpendicular bisector | **перпендикуляр биссектрис** | both halves grounded, the compound is not |
| corresponding angles | **харгалзах өнцөг** | «харгалзах» corpus 5 |
| interior angle | **дотоод өнцөг** | mirrors the dictionary's «гадаад өнцөг» |
| transversal | **огтлогч шулуун** | «огтлогч» ministry 1 |
| congruent | **тэнцүү** (figures) | dictionary lists «тэнцүү, ижил, конгруэнт, давхацдаг»; «конгруэнт» is 0 everywhere — see note |
| similar | **төстэй** | corpus 23, incl. the bank's own «Параллелограмм, төстэй гурвалжин» |
| similarity | **төстэй байдал** | from «төстэй» |
| proof | **баталгаа** | corpus 11 |
| postulate | **постулат** | dictionary prints «постулат (аксиом)» inside a sentence, not as a headword |
| converse | **урвуу өгүүлбэр** | dictionary p. 84 prints «урвуу хэллэг»; see note |
| translation (transformation) | **шилжүүлэлт** | 0 everywhere |
| reflection | **тусгал** | corpus 9 |
| dilation | **томсголт** | 0 everywhere |

**«тэнцүү» for congruent, and why not «конгруэнт».** The dictionary lists four
renderings and «конгруэнт» among them, but it scores zero in the ministry, the
bank and the mirrors, whereas «тэнцүү» has ministry 8 and corpus 399. Mongolian
school tradition, like the Russian it descends from, says *equal* triangles
rather than *congruent* ones. The risk is real and named here: «тэнцүү» also
means plain numeric equality, so every geometry draft says «тэнцүү гурвалжин»
with the noun attached rather than «тэнцүү» bare.

**«урвуу өгүүлбэр» versus the dictionary's «урвуу хэллэг».** The book renders
the sentence *"This new statement is called the converse of the conditional"*
as «…уг нөхцөлт хэллэгийн урвуу хэллэг гэж нэрлэдэг» (p. 84). «хэллэг» there
is the book's word for *statement* throughout. Our drafts use «өгүүлбэр» for
statement because «хэллэг» reads as *phrase/idiom* in ordinary Mongolian.
**This is a real conflict and it is listed in the review pile**, not settled
here.

## 4. Two ministry words this strand must NOT reuse

**Found 18 Sep 2026 while drafting `parallel-and-perpendicular`.** Both were
invisible from the English and neither would have shown up in a count. A term
scoring zero is a gap; a term scoring one *in another sense* is a collision,
and a collision is worse, because the count looks like permission.

| Word | А/492 uses it for | So this strand |
|---|---|---|
| **солбисон** | **skew lines** — «Огторгуй дахь хоёр шулууны харилцан байршлыг тодорхойлох (параллель, огтлолцох, солбисон)» | must not use it for *alternate* angles |
| **огтлогч** | a circle's **secant** — «Тойргийн хөвч, шүргэгч, огтлогчийн чанаруудыг хэрэглэх» | writes the full **«огтлогч шулуун»** for *transversal*, never the bare word, so `circles` keeps «огтлогч» |

**The four transversal pair names, decided once here.** Built to state their
own positions, which is what the lessons have to explain in English anyway:

| English | Mongolian | literally |
|---|---|---|
| corresponding angles | **харгалзах өнцөг** | corresponding (corpus 5, this sense) |
| alternate interior | **эсрэг талын дотоод өнцөг** | opposite-side interior |
| alternate exterior | **эсрэг талын гадаад өнцөг** | opposite-side exterior |
| same-side interior | **нэг талын дотоод өнцөг** | same-side interior |
| same-side exterior | **нэг талын гадаад өнцөг** | same-side exterior (asked in practice, taught nowhere) |

**«эсрэг талын …» always keeps «талын»**, because «эсрэг өнцөг» alone is
*vertical angles* from unit 1. Flagged in the review pile; every geometry
draft that uses these names should keep the full form.

## 5. Notation

- Point names stay **Latin**: $A$, $B$, $C$ — per `mn-translation` rule 2.
- $\triangle ABC$, $\angle ABC$, $\overline{AB}$, $\parallel$, $\perp$,
  $\cong$, $\sim$ render in KaTeX and stay as they are.
- Degrees: $90^\circ$, and the suffix hyphenates — $90^\circ$-тай — per voice
  reference §8.
- The ЭШ interval convention $]a, b[$ does not arise in this strand.
