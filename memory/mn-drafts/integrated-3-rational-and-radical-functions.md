## Lesson 1 — Рационал функц ба түүний асимптот (`rational-functions-and-asymptotes`)

**concreteComparison**

$12$ боорцгийг $n$ хүүхдэд тэнцүү хуваавал хүүхэд бүрд $\frac{12}{n}$ ногдоно. Хүүхэд олшрох тусам хувь нь багассаар тэг рүү ойртох боловч хэзээ ч тэг болохгүй. Харин $n$ тэг рүү ойртох тусам хувь нь хязгааргүй томорно. Хоёр төлөв хоёулаа арифметик дотор аль хэдийн байгаа бөгөөд график зөвхөн тэднийг зурж харуулдаг.

**objective**

Рационал функцийн (rational function) тодорхойлогдох мужийг олох, цоорхойг (hole) босоо асимптотоос (vertical asymptote) ялгах, мөн хэвтээ асимптотыг (horizontal asymptote) зэргүүдээс нь шууд унших.

**concept**

1. Хоёр олон гишүүнтийн харьцаа болох $f(x) = \frac{p(x)}{q(x)}$ хэлбэрийн функцийг рационал функц гэнэ. Түүний сонирхолтой бүх шинж нэг л баримтаас урган гарна: тэгд хуваах боломжгүй тул $q(x) = 0$ болгох $x$ бүр тодорхойлогдох мужаас хасагдана. Ийм утгыг хориотой утга (excluded value) гэдэг.

2. Мужаас хасагдсан гэдэг нь босоо асимптоттой гэсэн үг биш. Эхлээд үржигдэхүүнд задлаарай. Хэрэв нэг үржигдэхүүн хүртвэр, хуваарь хоёроос хураагдвал функц тэр цэгт тодорхойлогдохгүй ч хоёр талаас нь ойртох утгууд энгийн нэг тоо руу тэмүүлнэ: энэ бол ЦООРХОЙ. Харин үржигдэхүүн хуваарьт үлдвэл утгууд хязгааргүй өснө: энэ бол БОСОО АСИМПТОТ.

3. Үзүүрийн төлөв (end behaviour) бол зэргүүдийн уралдаан. Хуваарийн зэрэг их бол бутархай $0$ руу шахагдах тул $y = 0$ шулуун хэвтээ асимптот болно. Зэргүүд тэнцвэл тэргүүлэх коэффициентүүд (leading coefficient) шийдэж, асимптот нь тэдгээрийн харьцаа болно. Хүртвэрийн зэрэг их бол хэвтээ асимптот огт байхгүй: функц оргоод явчихна.

4. Үүнд утгын хүснэгт огт хэрэггүй. Үржигдэхүүнд задлах, хураах, зэргийг харьцуулах гурван алхмаас тодорхойлогдох муж, цоорхой, босоо болон хэвтээ асимптот бүгд гарч ирэх бөгөөд ноорог зурах нь эдгээр хэсгийг холбох л ажил болж үлдэнэ.

**keyIdea**

Аливаа дүгнэлт хийхээсээ өмнө үржигдэхүүнд задлаарай. Хураагдсан үржигдэхүүн цоорхой, хуваарьт үлдсэн нь босоо асимптот үүсгэнэ; хэвтээ асимптотыг график биш, зэргүүд шийднэ.

**facts**

| title | latex | explanation |
|---|---|---|
| Тодорхойлогдох муж | `q(x) \ne 0` | Хуваарийн тэг бүр цоорхой болох эсэхээс үл хамааран мужаас гарна. |
| Босоо асимптот | `x = a \text{, хэрэв } (x - a) \text{ нь } q(x) \text{-д үлдвэл}` | Хураасны ДАРАА ч үржигдэхүүн хуваарьт үлдсэн байх ёстой. |
| Цоорхой | `x = a \text{, хэрэв } (x - a) \text{ хураагдвал}` | Тэр цэгт тодорхойлогдохгүй ч ойролцоох утгууд төгсгөлөг тоо руу тэмүүлнэ. |
| Хэвтээ асимптот | `\deg p < \deg q \Rightarrow y = 0` | Хуваарь хүртвэрээсээ хурдан өсөх тул харьцаа тэг рүү шахагдана. |
| Зэрэг тэнцүү | `y = \frac{a_n}{b_n}` | Тэнцээг тэргүүлэх коэффициентүүд шийднэ. |
| Хүртвэр ялна | `\deg p > \deg q \Rightarrow \text{байхгүй}` | Утгууд хязгааргүй өсөх тул хэвтээ асимптот байхгүй. |

**workedExamples**

- `im3-u2-l1-we1` — **statement:** $f(x) = \dfrac{x + 3}{x^2 - 5x + 6}$ функцийн тодорхойлогдох мужийг олоорой.
  **solution:** **Хуваарийг үржигдэхүүнд задлана.** $x^2 - 5x + 6 = (x - 2)(x - 3)$. **Тэгтэй тэнцүүлнэ.** Хуваарь $x = 2$ ба $x = 3$ үед тэг болно. **Мужийг бичнэ.** Эдгээр хоёр утгаас бусад бүх бодит тоо: $x \ne 2$ ба $x \ne 3$. **Хүртвэр аль нэгийг нь аврах эсэхийг шалгана.** $x = 2$ үед хүртвэр $2 + 3 = 5 \ne 0$, $x = 3$ үед $6 \ne 0$. Аль ч үржигдэхүүн хураагдахгүй тул хоёулаа цоорхой биш, жинхэнэ босоо асимптот.
- `im3-u2-l1-we2` — **statement:** $g(x) = \dfrac{x^2 - 9}{x^2 - 2x - 3}$ функцийн бүх цоорхой ба босоо асимптотыг олоорой.
  **solution:** **Хоёуланг нь задлана.** $x^2 - 9 = (x - 3)(x + 3)$, $x^2 - 2x - 3 = (x - 3)(x + 1)$. **Нийтлэг үржигдэхүүнийг хураана.** $(x - 3)$ хоёуланд нь байгаа тул $x \ne 3$ үед $$g(x) = \frac{x + 3}{x + 1}.$$ **Хоёр төрлийн тасралтыг уншина.** Хураагдсан үржигдэхүүн $x = 3$ дээр ЦООРХОЙ, хуваарьт үлдсэн $(x + 1)$ нь $x = -1$ дээр БОСОО АСИМПТОТ өгнө. **Цоорхойн өндрийг олно.** Хялбарчилсан хэлбэрт $x = 3$-ыг орлуулбал $\frac{3 + 3}{3 + 1} = \frac{6}{4} = \frac{3}{2}$. Иймд график ердийн муруй бөгөөд зөвхөн $\left(3,\ \frac{3}{2}\right)$ цэг нь цоолсон мэт алга: функц тэнд тодорхойлогдохгүй ч ямар нэг гэнэтийн зүйл болохгүй.
- `im3-u2-l1-we3` — **statement:** Хэвтээ асимптотыг нь олоорой: а) $\dfrac{2x + 1}{x^2 - 4}$, б) $\dfrac{3x^2 - x}{5x^2 + 2}$, в) $\dfrac{x^3}{x^2 + 1}$.
  **solution:** **а) Зэргийг харьцуулна.** Хүртвэр $1$-р зэргийн, хуваарь $2$-р зэргийн олон гишүүнт: хуваарь ялах тул бутархай тэг рүү шахагдана, $y = 0$. **б) Тэнцээ.** Хоёулаа $2$-р зэргийнх тул тэргүүлэх коэффициентүүд шийднэ: $y = \frac{3}{5}$. Том оролтоор шалгаж үзье: $x = 100$ үед утга нь $\frac{30000 - 100}{50000 + 2} = \frac{29900}{50002} \approx 0.598$ буюу $0.6$-д аль хэдийн ойрхон. **в) Хүртвэр ялна.** $3$-р зэргийнхийг $2$-р зэргийнхэд хуваасан нь хязгааргүй өсөх тул хэвтээ асимптот БАЙХГҮЙ. **Гурвуулангийн цаадах дүрэм.** Эхийн цэгээс хол зайд зөвхөн тэргүүлэх гишүүд чухал; бага зэргийн гишүүн бүр харьцуулалтад анзаарагдахааргүй жижиг болно.

**commonMistakes**

- **text:** Хуваарийн тэг бүрийг босоо асимптот гэж үзэх.
  **correction:** Эхлээд хураагаарай. Хүртвэр, хуваарьт нийтлэг үржигдэхүүн асимптот биш, ЦООРХОЙ өгнө: график тэнд төгсгөлөг бөгөөд зөвхөн нэг цэг нь дутуу.
- **text:** Хэвтээ асимптотыг сул гишүүдээс унших.
  **correction:** x өсөх тусам зөвхөн ТЭРГҮҮЛЭХ гишүүд чухал. (3x^2 - x)/(5x^2 + 2) бутархайн асимптот нь 3/5 бөгөөд -x ч, +2 ч үүнд оролцохгүй.
- **text:** График хэвтээ асимптотоо хэзээ ч огтлохгүй гэж үзэх.
  **correction:** Дунд хэсэгтээ огтолж болно; асимптот зөвхөн хол зайн төлөвийг тодорхойлдог. Харин функц БОСОО асимптот дээр тодорхойлогдоогүй тул график түүнийг үнэхээр хэзээ ч огтлохгүй.
- **text:** Үржигдэхүүнийг хураасны дараа тэр цэг хасагдсан хэвээр гэдгийг мартах.
  **correction:** (x + 3)/(x + 1) болгон хялбарчлах нь зөвхөн x ≠ 3 үед хүчинтэй. Алгебр цаашид харуулахаа больсон ч цоорхой хялбарчлалтын дараа ч хэвээр үлдэнэ.

**tryIt**

- `im3-u2-l1-t1` — $h(x) = \dfrac{x - 1}{x^2 - 16}$ функцийн тодорхойлогдох мужийг олоорой.
  **solution:** $x^2 - 16 = (x - 4)(x + 4)$ нь $x = 4$ ба $x = -4$ үед тэг болно. Хүртвэр энэ хоёр цэгт хоёуланд нь тэгээс ялгаатай тул хоёулаа босоо асимптот бөгөөд муж нь $4$ ба $-4$-өөс бусад бүх бодит тоо.
- `im3-u2-l1-t2` — $f(x) = \dfrac{x^2 - 4}{x - 2}$ функц $x = 2$ дээр цоорхойтой юу, асимптоттой юу? Цоорхой бол өндрийг нь олоорой.
  **solution:** $x^2 - 4 = (x - 2)(x + 2)$ тул $(x - 2)$ хураагдаж, $x \ne 2$ үед $f(x) = x + 2$. Энэ бол асимптот биш, ЦООРХОЙ. Өндөр нь $2 + 2 = 4$, өөрөөр хэлбэл график нь $(2,\ 4)$ цэгийг нь авч хаясан $y = x + 2$ шулуун.
- `im3-u2-l1-t3` — $\dfrac{7x^2 + 3}{2x^2 - x}$ функцийн хэвтээ асимптотыг олоорой.
  **solution:** Зэргүүд $2$ дээр тэнцэх тул тэргүүлэх коэффициентүүд шийднэ: $y = \frac{7}{2}$.

## Lesson 2 — Рационал илэрхийллийг нэмэх, үржүүлэх, хуваах (`operations-on-rational-expressions`)

**concreteComparison**

$\frac{1}{6} + \frac{1}{4}$-ийг нэмэхэд ерөнхий хуваарь $24$ байх шаардлагагүй, $12$ хангалттай. Түүнийг олохын тулд $6 = 2 \cdot 3$, $4 = 2^2$ гэж задлаад анхны тоо бүрийг аль нэг хуваарьт хамгийн олон давтагдсан тоогоор нь авна. Рационал илэрхийлэл (rational expression) яг ийм замаар ажиллах бөгөөд зөвхөн $2$ анхны тооны оронд $(x - 1)$ мэт үржигдэхүүн орж ирнэ.

**objective**

Рационал илэрхийллийг үржүүлэх, хуваах, нэмэх, хасах, мөн эдгээр үйлдэл шаарддаг хязгаарлалтыг заах.

**concept**

1. Рационал илэрхийлэл бүхэл тоонуудын бутархай шиг яг адилхан ажилладаг, учир нь хоёулаа нэг л аргаар бүтсэн: нэмж, үржүүлж болох хоёр зүйлийн харьцаа. Рационал илэрхийллүүдийн нийлбэр, ялгавар, үржвэр, ногдвор дахиад л рационал илэрхийлэл байна. Рационал тоонуудын адил энэ систем дөрвөн үйлдлийн хувьд БИТҮҮ бөгөөд үүнийг битүү чанар (closure) гэнэ.

2. Үржүүлэх нь хөнгөн чиглэл: хүртвэрүүдийг хооронд нь, хуваариудыг хооронд нь үржүүлээд нийтлэг үржигдэхүүнийг хураана. Ганц сахилга бат бол ЭХЛЭЭД задлах явдал юм: тэгвэл та гишүүнийг биш, үржигдэхүүнийг хураана.

3. Хуваах гэдэг нь урвуу тоогоор (reciprocal) нь үржүүлэх юм. Нэмэлт анхаарах ганц зүйл: эргүүлж (flip) байгаа илэрхийлэл тэг байж болохгүй тул түүний хүртвэр өөрийн гэсэн хязгаарлалт нэмнэ. Энэ хязгаарлалт бичсэн хариунаас алга болох ч заавал дагуулж явах ёстой.

4. Нэмэхэд ерөнхий хуваарь хэрэгтэй бөгөөд хамгийн хэмнэлттэй нь хамгийн бага ерөнхий хуваарь (least common denominator) юм. Хуваарь бүрийг задлаад ялгаатай үржигдэхүүн бүрийг аль нэг хуваарьт хамгийн олон давтагдсан тоогоор нь авна. Бүх хуваарийг хооронд нь үржүүлсэн ч болно, гэхдээ тэгвэл дараа нь буцааж хялбарчлах шаардлагатай том илэрхийлэл гарна.

**keyIdea**

Үргэлж эхлээд задлаарай. Зөвхөн ҮРЖИГДЭХҮҮНИЙГ хураах эрхтэй, хамгийн бага ерөнхий хуваарийг үржигдэхүүнээс бүтээж, хязгаарлалтыг ч үржигдэхүүнээс уншина.

**facts**

| title | latex | explanation |
|---|---|---|
| Үржүүлэх | `\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}` | Дараа нь нийтлэг үржигдэхүүнийг хураана, нийтлэг гишүүнийг хэзээ ч биш. |
| Хуваах | `\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}` | Эргүүлээд үржүүлнэ; эргүүлсэн хүртвэр c ч тэгээс ялгаатай байх ёстой. |
| Нэмэх | `\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}` | Үргэлж зөв, гэхдээ хамгийн бага ерөнхий хуваарь ихэвчлэн bd үржвэрээс бага. |
| Хамгийн бага ерөнхий хуваарь | `\text{үржигдэхүүн бүр, хамгийн их зэргээр}` | Тоон бутархайтай яг адил, эхлээд хуваарь бүрийг задална. |
| Битүү чанар | `\text{рационал} \pm \times \div \text{рационал} = \text{рационал}` | Систем рационал тоонуудыг давтдаг тул дүрмүүд танил санагдана. |

**workedExamples**

- `im3-u2-l2-we1` — **statement:** Хялбарчлаарай: $\dfrac{x^2 - 4}{x^2 + 6x + 9} \cdot \dfrac{x + 3}{x - 2}$.
  **solution:** **Бүгдийг задлана.** $x^2 - 4 = (x - 2)(x + 2)$, $x^2 + 6x + 9 = (x + 3)^2$. **Нэг үржвэр болгон бичнэ.** $$\frac{(x - 2)(x + 2)}{(x + 3)^2} \cdot \frac{x + 3}{x - 2}$$ **Нийтлэг ҮРЖИГДЭХҮҮНИЙГ хураана.** $(x - 2)$ хураагдаж, квадратаас нэг $(x + 3)$ хураагдах тул $$\frac{x + 2}{x + 3}$$ үлдэнэ. **Хязгаарлалтыг бичнэ.** Анхны хуваариуд $x \ne -3$ ба $x \ne 2$ байхыг шаардана. Хялбарчилсан хариунд $x \ne 2$ харагдахгүй, тийм учраас л түүнийг заавал бичнэ.
- `im3-u2-l2-we2` — **statement:** Хялбарчлаарай: $\dfrac{x^2 - 1}{x + 4} \div \dfrac{x - 1}{x^2 - 16}$.
  **solution:** **Хоёр дахь бутархайг эргүүлээд үржүүлнэ.** $$\frac{x^2 - 1}{x + 4} \cdot \frac{x^2 - 16}{x - 1}$$ **Задлана.** $x^2 - 1 = (x - 1)(x + 1)$, $x^2 - 16 = (x - 4)(x + 4)$. **Хураана.** $(x - 1)$ ба $(x + 4)$ хоёулаа хураагдаж $$(x + 1)(x - 4)$$ үлдэнэ. **Хязгаарлалтыг цуглуулна.** Анхны хуваариуд $x + 4$ ба $x^2 - 16$-аас $x \ne -4$ ба $x \ne 4$; мөн бид $\frac{x - 1}{x^2 - 16}$-д ХУВААСАН тул энэ бутархай тэг байж болохгүй, энэ нь $x \ne 1$ хязгаарлалтыг нэмнэ. Олон гишүүнт хариу хаа сайгүй тодорхойлогдсон мэт харагдах ч тийм биш гэдгийг зөвхөн хязгаарлалт л тэмдэглэн үлдээдэг.
- `im3-u2-l2-we3` — **statement:** $\dfrac{3}{x - 2} + \dfrac{5}{x + 1}$-ийг нэмж, хязгаарлалтыг бичээрэй.
  **solution:** **Хуваариудыг задлана.** Тэд аль хэдийн задарсан бөгөөд нийтлэг үржигдэхүүнгүй тул хамгийн бага ерөнхий хуваарь нь тэдгээрийн үржвэр $(x - 2)(x + 1)$. **Бутархай бүрийг энэ хуваарьт шилжүүлнэ.** $$\frac{3(x + 1)}{(x - 2)(x + 1)} + \frac{5(x - 2)}{(x - 2)(x + 1)}$$ **Хүртвэрүүдийг нэмнэ.** $$\frac{3x + 3 + 5x - 10}{(x - 2)(x + 1)} = \frac{8x - 7}{(x - 2)(x + 1)}$$ **Хязгаарлалт.** $x \ne 2$ ба $x \ne -1$. **Тоогоор шалгана.** $x = 3$ үед анхны илэрхийлэл $\frac{3}{1} + \frac{5}{4} = \frac{17}{4}$, хариу нь $\frac{24 - 7}{(1)(4)} = \frac{17}{4}$ ✓
- `im3-u2-l2-we4` — **statement:** Хасаарай: $\dfrac{4}{x^2 - 9} - \dfrac{1}{x + 3}$.
  **solution:** **Хамгийн бага ерөнхий хуваарийг олохын тулд задлана.** $x^2 - 9 = (x - 3)(x + 3)$ бөгөөд хоёр дахь хуваарь $(x + 3)$ түүнд аль хэдийн багтсан тул хамгийн бага ерөнхий хуваарь нь хоёр хуваарийн үржвэр биш, $(x - 3)(x + 3)$. **Хоёр дахь бутархайг шилжүүлнэ.** Хүртвэр, хуваарийг нь $(x - 3)$-аар үржүүлбэл: $$\frac{4}{(x-3)(x+3)} - \frac{x - 3}{(x-3)(x+3)}$$ **Хүртвэрүүдийг хасна, хасах тэмдгийг хүртвэр БҮХЭЛД нь үйлчлүүлнэ.** $$\frac{4 - (x - 3)}{(x-3)(x+3)} = \frac{7 - x}{(x-3)(x+3)}$$ **Хязгаарлалт.** $x \ne 3$ ба $x \ne -3$. **Тоогоор шалгана.** $x = 0$ үед анхны илэрхийлэл $\frac{4}{-9} - \frac{1}{3} = -\frac{4}{9} - \frac{3}{9} = -\frac{7}{9}$, хариу нь $\frac{7}{(-3)(3)} = -\frac{7}{9}$ ✓

**commonMistakes**

- **text:** Үржигдэхүүний оронд гишүүнийг хураах.
  **correction:** (x + 2)/(x + 3) бутархайд юу ч хураагдахгүй: x-ууд бол ГИШҮҮД. Хүртвэр бүхэлдээ, хуваарь бүхэлдээ нийтлэг үржигдэхүүнтэй үед л хураах эрхтэй.
- **text:** Хоёр дахь хүртвэрийн зөвхөн эхний гишүүнийг хасах.
  **correction:** Хасах тэмдэг хүртвэр бүхэлд үйлчилнэ: 4 - (x - 3) = 7 - x, харин 4 - x - 3 = 1 - x биш. Эхлээд хаалтад хийгээд дараа нь хаалтаа нээгээрэй.
- **text:** Хялбарчилсан хэлбэр нууж буй хязгаарлалтыг хаях.
  **correction:** Үржигдэхүүн хураагдсан ч түүний хязгаарлалт хүчинтэй хэвээр. Хялбарчилсан илэрхийлэл зөвхөн анхны илэрхийлэл тодорхойлогдсон газарт л түүнтэй тэнцүү.
- **text:** Бүх хуваарийг үргэлж хооронд нь үржүүлэх.
  **correction:** Хууль ёсны боловч үрэлгэн. Эхлээд задлавал нэг хуваарь нөгөөдөө аль хэдийн багтсан байх нь элбэг бөгөөд ингэснээр хамгийн бага ерөнхий хуваарь хамаагүй жижиг гарч, дараа нь хялбарчлах ажил багасна.

**tryIt**

- `im3-u2-l2-t1` — Хялбарчлаарай: $\dfrac{x^2 + 5x + 6}{x^2 - 1} \cdot \dfrac{x - 1}{x + 2}$.
  **solution:** Задалбал $x^2 + 5x + 6 = (x + 2)(x + 3)$, $x^2 - 1 = (x - 1)(x + 1)$. $(x + 2)$ ба $(x - 1)$ хураагдаж $\frac{x + 3}{x + 1}$ үлдэнэ; хязгаарлалт нь $x \ne 1$, $x \ne -1$, $x \ne -2$.
- `im3-u2-l2-t2` — Нэмээрэй: $\dfrac{2}{x} + \dfrac{3}{x + 1}$.
  **solution:** Хамгийн бага ерөнхий хуваарь нь $x(x + 1)$. Шилжүүлбэл $\frac{2(x + 1) + 3x}{x(x+1)} = \frac{5x + 2}{x(x+1)}$; хязгаарлалт нь $x \ne 0$ ба $x \ne -1$. $x = 1$ үед шалгавал: $2 + \frac{3}{2} = \frac{7}{2}$ ба $\frac{7}{2}$ ✓
- `im3-u2-l2-t3` — Хялбарчлаарай: $\dfrac{x + 5}{x^2 - 4} \div \dfrac{x + 5}{x - 2}$.
  **solution:** Эргүүлээд үржүүлбэл $\frac{x + 5}{(x-2)(x+2)} \cdot \frac{x - 2}{x + 5}$. $(x + 5)$ ба $(x - 2)$ хураагдаж $\frac{1}{x + 2}$ үлдэнэ; хязгаарлалт нь $x \ne 2$, $x \ne -2$, $x \ne -5$ (сүүлийнх нь бид хүртвэр нь $x + 5$ болох илэрхийлэлд хуваасан учраас).

## Lesson 3 — Рационал тэгшитгэл ба тодорхойлогдох мужаас гадуурх шийд (`solving-rational-equations`)

**concreteComparison**

Хоёр цорго усны торхыг тус тусдаа $3$ ба $6$ цагт дүүргэнэ. Хамтдаа цагт $\frac{1}{3} + \frac{1}{6} = \frac{1}{2}$ торх дүүргэх тул ажил $2$ цагт дуусна. Үүнийг загварчлах тэгшитгэлд үл мэдэгдэгч хуваарьт байрлах бөгөөд бодолтын эхний алхам болох хуваарийг арилгах нь худал хариу үйлдвэрлэж чадах яг тэр алхам юм.

**objective**

Хуваарийг арилгаж рационал тэгшитгэл (rational equation) бодох, мөн нэр дэвшигч (candidate) шийдүүдийн аль нь тодорхойлогдох мужаас гадуурх шийд (extraneous solution) болохыг, яагаад гэдгийг тогтоох.

**concept**

1. Бутархайтай тэгшитгэл бодохдоо хоёр талыг хамгийн бага ерөнхий хуваариар үржүүлээрэй. Хуваарь бүр хураагдаж, таны бодож чаддаг олон гишүүнт тэгшитгэл үлдэнэ.

2. Гэвч хамгийн бага ерөнхий хуваариар үржүүлэх нь буцаах боломжтой алхам биш. Хуваарь хувьсагч агуулдаг тул зарим $x$-ийн хувьд ТЭГ болж болох бөгөөд тэгшитгэлийг тэгээр үржүүлбэл худал өгүүлбэр үнэн болж хувирна. Бүх механизм энэ л: эцэст нь гарсан олон гишүүнт тэгшитгэл анхны тэгшитгэлд хэзээ ч байгаагүй шийдтэй байж болно.

3. Ийм шийдийг тодорхойлогдох мужаас гадуурх шийд гэнэ. Энэ бол арифметикийн алдаа биш бөгөөд болгоомжтой байснаар түүнээс зайлсхийж чадахгүй: энэ нь аргын өөрийнх нь үр дагавар. Ганц хамгаалалт бол нэр дэвшигч бүрийг АНХНЫ тэгшитгэлийн тодорхойлогдох мужтай тулгаж, хуваарийг тэг болгосныг нь хаях явдал юм.

4. Энэ нь хаана хайхыг ч хэлж өгнө. Тодорхойлогдох мужаас гадуурх нэр дэвшигч байвал тэд яг хориотой утгууд дунд л байна. Иймд бодохоосоо өмнө ямар $x$ хориотой болохыг тэмдэглээд, тэдгээрийн аль нэгтэй таарсан нэр дэвшигчийг шууд хаяарай.

**keyIdea**

Хуваарийг арилгах нь нэр дэвшигч НЭМЖ л чадна, хэзээ ч хасахгүй. Тиймээс нэр дэвшигч бүрийг анхны тэгшитгэлийн мужтай тулгах ёстой: шалгалт бол аргын нэг хэсэг, ёс төдий үйлдэл биш.

**facts**

**workedExamples**

- `im3-u2-l3-we1` — **statement:** $\dfrac{1}{x} + \dfrac{1}{2} = \dfrac{3}{4}$ тэгшитгэлийг бодоорой.
  **solution:** **Хориотой утгыг тэмдэглэнэ.** $x \ne 0$. **Хамгийн бага ерөнхий хуваариар үржүүлнэ.** $4x$-ээр үржүүлбэл: $$4 + 2x = 3x$$ **Бодно.** $4 = x$, тиймээс $x = 4$. **Анхны тэгшитгэлээр шалгана.** $\frac{1}{4} + \frac{1}{2} = \frac{1}{4} + \frac{2}{4} = \frac{3}{4}$ ✓ бөгөөд $4 \ne 0$ тул шийд хүчинтэй. **Энд юу ч буруудаагүйн учир.** Ганц хориотой утга нь $0$ байсан бөгөөд $0$ нэр дэвшигч болж гараагүй тул энэ тэгшитгэлд мужаас гадуурх шийд гарах боломж байгаагүй.
- `im3-u2-l3-we2` — **statement:** $\dfrac{x}{x - 3} = \dfrac{3}{x - 3} + 2$ тэгшитгэлийг бодоорой.
  **solution:** **Хориотой утгыг тэмдэглэнэ.** Хуваарь $x = 3$ үед тэг болох тул $x \ne 3$. Үүнийг одоо бичээрэй, удахгүй хэрэг болно. **Хамгийн бага ерөнхий хуваариар үржүүлнэ.** $(x - 3)$-аар үржүүлбэл: $$x = 3 + 2(x - 3)$$ **Бодно.** $x = 3 + 2x - 6$, өөрөөр хэлбэл $x = 2x - 3$, эндээс $x = 3$. **Анхны тэгшитгэлээр шалгана.** $x = 3$ үед ХОЁР хуваарь хоёулаа тэг болж илэрхийлэл тодорхойлогдохгүй. Иймд энэ нэр дэвшигч тодорхойлогдох мужаас гадуурх шийд тул хаягдана. **Дүгнэлт.** Тэгшитгэл ШИЙДГҮЙ. Механизм ч тод харагдаж байна: $(x - 3)$-аар үржүүлсэн алхам яг $x = 3$ үед тэгээр үржүүлсэн тул юуг ч хангадаггүй утга алгебраас гарч ирсэн.
- `im3-u2-l3-we3` — **statement:** $\dfrac{2}{x - 1} + \dfrac{1}{x + 1} = \dfrac{4}{x^2 - 1}$ тэгшитгэлийг бодоорой.
  **solution:** **Задлаад хориотой утгыг тэмдэглэнэ.** $x^2 - 1 = (x - 1)(x + 1)$ тул $x \ne 1$ ба $x \ne -1$, хамгийн бага ерөнхий хуваарь нь $(x - 1)(x + 1)$. **Бүхэлд нь үржүүлнэ.** $$2(x + 1) + 1(x - 1) = 4$$ **Бодно.** $2x + 2 + x - 1 = 4$, тиймээс $3x + 1 = 4$, $x = 1$. **Шалгана.** $x = 1$ бол ХОРИОТОЙ утга: $x - 1$ ба $x^2 - 1$ хоёрыг тэг болгоно. Хаягдана. **Дүгнэлт.** Шийдгүй. Нэр дэвшигч яг хориотой утга дээр буусан бөгөөд мужаас гадуурх шийд буух ганц газар нь тэр.
- `im3-u2-l3-we4` — **statement:** Хоёр хоолой савыг тус тусдаа $4$ ба $12$ цагт дүүргэнэ. Хамтдаа хэдэн цагт дүүргэх вэ?
  **solution:** **Хурдыг (rate) бичнэ.** Нэг цагт эхний хоолой савны $\frac{1}{4}$-ийг, хоёр дахь нь $\frac{1}{12}$-ийг дүүргэнэ. Хамтдаа цагт савны $\frac{1}{t}$ хэсгийг дүүргэх бөгөөд энд $t$ нь бүх ажилд зарцуулах хугацаа: $$\frac{1}{4} + \frac{1}{12} = \frac{1}{t}$$ **Хориотой утгыг тэмдэглэнэ.** $t \ne 0$, энэ нь бодит утгаараа ч ойлгомжтой. **Зүүн талыг нэмнэ.** $\frac{3}{12} + \frac{1}{12} = \frac{4}{12} = \frac{1}{3}$. **Бодно.** $\frac{1}{3} = \frac{1}{t}$ тул $t = 3$ цаг. **Хариуг дүгнэнэ.** $3$ цаг нь аль ч хоолойн ганцаараа дүүргэх хугацаанаас бага: энэ төрлийн бодлого бүрд хийх ёстой эрүүл ухааны шалгалт энэ, хоёр хоолой нэгээсээ заавал түрүүлнэ.

**commonMistakes**

- **text:** Нэр дэвшигчийг анхны тэгшитгэлд биш, хуваарийг арилгасан тэгшитгэлд шалгах.
  **correction:** Хуваарийг арилгасан тэгшитгэл бол илүүдэл шийдийг ОЛЖ АВСАН тэгшитгэл тул түүнийг дуртайяа баталгаажуулна. Анхны тэгшитгэлд орлуулаарай.
- **text:** «Шийдгүй» гарвал алдаа гаргасан гэж дүгнэх.
  **correction:** Шийдгүй гэдэг бол хууль ёсны хариу. Бүх нэр дэвшигч хориотой бол тэгшитгэл үнэхээр шийдгүй.
- **text:** Ажлын бодлогод хурдын оронд хугацааг нэмэх.
  **correction:** 4 ба 12 цагт дүүргэдэг хоёр хоолой хамтдаа 16 ч, 8 ч цаг зарцуулахгүй. ХУРД нэмэгдэнэ: цагт 1/4 + 1/12. Хариу хурдан хоолойн ганцаараа дүүргэх хугацаанаас бага гарах ёстой.
- **text:** Хамгийн бага ерөнхий хуваарийг олохоосоо өмнө задлахаа мартах.
  **correction:** x² - 1 нь (x - 1)(x + 1) үржигдэхүүнүүдийг нууж байдаг. Задлахгүй бол зөв хамгийн бага ерөнхий хуваарийг ч, x = -1 хориотой утгыг ч алдана.

**tryIt**

- `im3-u2-l3-t1` — $\dfrac{6}{x} = \dfrac{2}{x} + 1$ тэгшитгэлийг бодоорой.
  **solution:** Хориотой утга: $x \ne 0$. $x$-ээр үржүүлбэл $6 = 2 + x$, тиймээс $x = 4$. Анхны тэгшитгэлд шалгавал: $\frac{6}{4} = \frac{3}{2}$, мөн $\frac{2}{4} + 1 = \frac{1}{2} + 1 = \frac{3}{2}$ ✓ $4 \ne 0$ тул шийд нь $x = 4$.
- `im3-u2-l3-t2` — $\dfrac{x}{x - 5} = \dfrac{5}{x - 5}$ тэгшитгэлийг бодоод юу болохыг тайлбарлаарай.
  **solution:** Хориотой утга: $x \ne 5$. $(x - 5)$-аар үржүүлбэл $x = 5$ гарах бөгөөд энэ нь яг хориотой утга. Тодорхойлогдох мужаас гадуурх шийд тул тэгшитгэл ШИЙДГҮЙ. Тэнцэхийн тулд хоёр талыг хоёуланг нь тодорхойлогдохгүй болгодог яг тэр утга шаардлагатай тул хоёр тал хэзээ ч тэнцэхгүй.
- `im3-u2-l3-t3` — Нэг будагчин өрөөг $6$ цагт, нөгөө нь $3$ цагт будна. Хамтдаа хэдэн цагт будах вэ?
  **solution:** Хурд нэмэгдэнэ: $\frac{1}{6} + \frac{1}{3} = \frac{1}{6} + \frac{2}{6} = \frac{3}{6} = \frac{1}{2}$, өөрөөр хэлбэл цагт өрөөний хагас, тиймээс ажил $2$ цагт дуусна. Энэ нь хурдан будагчийн $3$ цагаас бага, яг байх ёстойгоороо.

## Lesson 4 — Язгуурт функц ба язгуурт тэгшитгэл (`radical-functions-and-equations`)

**concreteComparison**

$A$ талбайтай квадратын тал нь $\sqrt{A}$. Талбай сөрөг байж чадахгүй тул оролт хязгаарлагдана; тал сөрөг байж чадахгүй тул гаралт ч хязгаарлагдана. Графикийн хэлбэрийн хоёр тал хоёулаа энэ ганц өгүүлбэрээр аль хэдийн шийдэгдсэн.

**objective**

Квадрат язгуурт функцийн (square-root function) тодорхойлогдох муж ба утгын мужийг (range) тодорхойлох, язгуурт тэгшитгэлийг (radical equation) квадрат зэрэгт дэвшүүлж бодох, мөн квадрат зэрэгт дэвшүүлэхэд үүсэх, анхны тэгшитгэлийг хангахгүй гадны шийдийг хаях.

**concept**

1. $\sqrt{x}$ нь зөвхөн $x \ge 0$ үед тодорхойлогдох бөгөөд СӨРӨГ БИШ язгуурыг буцаана. Иймд $y = \sqrt{x}$ функцийн тодорхойлогдох муж $x \ge 0$, утгын муж $y \ge 0$ бөгөөд график нь эхийн цэгээс эхэлсэн, хажуугаараа хэвтсэн хагас парабол.

2. Шилжүүлэлт парабол дээр байсантай яг адил ажиллана. $y = \sqrt{x - h} + k$ функцэд язгуурын доорх илэрхийлэл сөрөг биш байх ёстой тул тодорхойлогдох муж $x \ge h$, гаралт $k$-аас эхлэх тул утгын муж $y \ge k$.

3. Язгуурт тэгшитгэл бодохдоо язгуурыг тусгаарлаад (isolate) хоёр талыг квадрат зэрэгт дэвшүүлээрэй. Энд өмнөх аюул шинэ хувцастай буцаж ирнэ: квадрат зэрэгт дэвшүүлэх нь буцаах боломжгүй алхам. $a = b$ бол $a^2 = b^2$, харин $a^2 = b^2$ бол зөвхөн $a = \pm b$ гэж хэлж чадна. Тиймээс квадрат зэрэгт дэвшүүлсэн тэгшитгэлийг хангах боловч анхныхыг хангахгүй шийд гарч ирж болно.

4. Энэ бол бүлгийн гол санааг хоёр дахь удаагаа харж байгаа хэрэг. Тэг байж болох хуваариар үржүүлэх, квадрат зэрэгт дэвшүүлж тэмдгийг арилгах хоёр хоёулаа нэр дэвшигч НЭМЖ л чаддаг нэг чиглэлтэй алхам. Хоёр тохиолдолд засвар нь адилхан: нэр дэвшигч бүрийг анхны тэгшитгэлд буцааж орлуулаад, тэсэж үлдсэнийг нь л авна.

**keyIdea**

Квадрат зэрэгт дэвшүүлэх нь хуваарийг арилгахтай адил нэг чиглэлтэй алхам. Шийд хэзээ ч алддаггүй ч шинээр зохиож чаддаг тул анхны тэгшитгэлд шалгах нь заавал хийх алхам юм.

**facts**

| title | latex | explanation |
|---|---|---|

**workedExamples**

- `im3-u2-l4-we1` — **statement:** $f(x) = \sqrt{x - 4} + 1$ функцийн тодорхойлогдох муж ба утгын мужийг олоорой.
  **solution:** **Тодорхойлогдох муж.** Язгуурын доорх илэрхийлэл сөрөг биш байх ёстой: $x - 4 \ge 0$, тиймээс $x \ge 4$. **Утгын муж.** $\sqrt{x - 4}$ хамгийн багадаа $0$ тул $f(x)$ хамгийн багадаа $0 + 1 = 1$: $y \ge 1$. **Эхлэлийн цэг.** График $(4,\ 1)$ цэгээс эхэлж, баруун тийш улам удаашран өснө. **Нэг цэгээр шалгана.** $x = 8$ үед $f(8) = \sqrt{4} + 1 = 3$: мужид багтаж, хамгийн бага утгаас дээгүүр байна, хүлээсэн ёсоор.
- `im3-u2-l4-we2` — **statement:** $\sqrt{2x + 3} = 5$ тэгшитгэлийг бодоорой.
  **solution:** **Язгуур аль хэдийн тусгаарлагдсан.** Хоёр талыг квадрат зэрэгт дэвшүүлбэл: $$2x + 3 = 25$$ **Бодно.** $2x = 22$, тиймээс $x = 11$. **Анхны тэгшитгэлд шалгана.** $\sqrt{2(11) + 3} = \sqrt{25} = 5$ ✓ **Энэ удаа яагаад аюулгүй байсан бэ.** Баруун тал $5$ сөрөг биш тул квадрат зэрэгт дэвшүүлсэн тэгшитгэл анхныхтайгаа санал нийлж, гадны шийд гарах боломжгүй байв.
- `im3-u2-l4-we3` — **statement:** $\sqrt{x + 6} = x$ тэгшитгэлийг бодоорой.
  **solution:** **Хоёр талыг квадрат зэрэгт дэвшүүлнэ.** $$x + 6 = x^2$$ **Нэг тал руу шилжүүлээд задлана.** $x^2 - x - 6 = 0$, тиймээс $(x - 3)(x + 2) = 0$ бөгөөд нэр дэвшигчид нь $x = 3$ ба $x = -2$. **Эхний нэр дэвшигчийг шалгана.** $x = 3$ үед $\sqrt{3 + 6} = \sqrt{9} = 3$ ✓ **Хоёр дахь нэр дэвшигчийг шалгана.** $x = -2$ үед $\sqrt{-2 + 6} = \sqrt{4} = 2$, харин баруун тал $-2$. $2 \ne -2$ тул энэ нэр дэвшигч ТЭНЦЭХГҮЙ. **Дүгнэлт.** Зөвхөн $x = 3$. **Илүүдэл хаанаас гарсан бэ.** Квадрат зэрэгт дэвшүүлэх нь тэмдгийг устгасан: $2$ ба $-2$ ижил квадраттай тул $x = -2$ квадрат зэрэгт дэвшүүлсэн тэгшитгэлийг хангах боловч анхны тэгшитгэл сөрөг биш язгуурыг сөрөг тоотой тэнцүүлэхийг шаардана.
- `im3-u2-l4-we4` — **statement:** $\sqrt{3x + 1} + 5 = 2$ тэгшитгэлийг бодоорой.
  **solution:** **Язгуурыг тусгаарлана.** $5$-ыг хасвал: $$\sqrt{3x + 1} = -3$$ **Зогсоод уншина.** Квадрат язгуур хэзээ ч сөрөг байдаггүй тул үүнийг ямар ч $x$ хангахгүй. Тэгшитгэл ШИЙДГҮЙ бөгөөд үүнийг квадрат зэрэгт дэвшүүлэхээс өмнө харж болно. **Квадрат зэрэгт дэвшүүлбэл юу болох байсан бэ.** $3x + 1 = 9$, тиймээс $x = \frac{8}{3}$; буцааж орлуулбал $\sqrt{9} + 5 = 8 \ne 2$. Нэр дэвшигч анхны тэгшитгэлийг хангахгүй гадны шийд болж, дүгнэлтийг урт замаар баталгаажуулна.

**commonMistakes**

- **text:** Язгуурыг тусгаарлахаас өмнө квадрат зэрэгт дэвшүүлэх.
  **correction:** √(x+1) + 3 илэрхийллийг квадрат зэрэгт дэвшүүлбэл x + 1 + 6√(x+1) + 9 гарна: язгуур үлдэж, тэгшитгэл улам дордоно. Эхлээд язгуурыг нэг талд нь тусгаарлаарай.

  **correction:** Тэд ижил биш. √(9 + 16) = 5, харин √9 + √16 = 7. Язгуур нэмэх үйлдэл дээр задардаггүй, зөвхөн үржүүлэх үйлдэл дээр задарна.
- **text:** Квадрат зэрэгт дэвшүүлсэн тэгшитгэлээс гарсан бүх нэр дэвшигчийг үлдээх.
  **correction:** Квадрат зэрэгт дэвшүүлэх нь нэр дэвшигч нэмж л чадна. Тус бүрийг АНХНЫ тэгшитгэлд буцааж орлуулаад, тэнцэхгүйг нь хаяарай.

  **correction:** Язгуур тодорхойлолтоороо сөрөг биш тул тусгаарласан язгуур сөрөг тоотой тэнцвэл бодлого тэр дороо дуусна.
